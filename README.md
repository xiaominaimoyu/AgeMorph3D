# AgeMorph3D AI 协作任务文档存档

本分支是 AgeMorph3D 项目截至 **2026-11-21** 的 AI 协作规划与审查文档存档。

- 内容为方案、审核记录、同意书草稿、界面截图等**草稿与过程材料**，不是最终论文正文。
- 本分支为独立存档分支，**不并入 `main`**，与主线没有共同历史。
- 目录说明：
  - `plans/`：总体后续任务规划与数据集方案；
  - `tasks/`：各任务产出（Blueprint / Forge / Radar / Metric / Muse / Runner / Grok 等说明、校验脚本、审查记录与前端检查截图）。
- 本存档不含数据集本体、压缩包、缓存，也不含口令或密钥。AgeDB 等受许可限制的数据只在用户本机处理。
