# 岁月镜 AgeMorph3D

本地运行的跨年龄三维人脸重建与可视化项目。目标流程为：上传照片或摄像头拍照 → 人脸检测与三维重建 → 调节 20—70 岁的年龄形变 → 导出三维模型与效果图。

**当前已实现照片检测、canonical 静态人脸网格、GLB 编码与有界内存资产发布链路。** 后端可在无权重时启动；显式配置清单后异步核验、加载并自检，健康状态来自实际结果。检测与重建模型均通过严格加载时，照片接口返回对应照片的静态结果；现有研究清单仍为 `license_status=unresolved`，严格服务入口会报告许可错误，真实服务 G1 尚未通过。实时姿态、年龄能力、训练集获取（仅完成研究用途小样获取）、预处理和训练仍待后续阶段。界面的演示模型是程序化生成的头部，用于检查三维操作、年龄插值和导出；它不是上传照片的重建结果，也不是训练模型对个人未来容貌的预测。

2026-10-19基础服务模块已通过限定范围的阶段验收；结果、证据与传输层边界见[基础服务验收报告](docs/基础服务验收报告.md)，实施顺序与条件见[后端任务计划](docs/后端任务计划.md)。静态链路的当前实现和真实研究证据见 [B2/B3 开发记录](docs/B23真实静态链路开发记录.md)，实时算法与年龄能力仍待后续验收。

本次模型开发的运行方式、真实输出、资产来源/哈希、原始 204 点索引处理及尚未通过的出口见 [B0 模型验证与复现](docs/B0模型验证与复现.md)。本机模型和推理结果位于 `data/`、`output/`，不随源码发布；BFM 本地研究授权已由用户确认，候选资产的完整条款仍分别记录。原始 `BaselFaceModel.tgz` 因体积超过普通文件与 LFS 限制，改以 [Release 附件](https://github.com/xiaominaimoyu/AgeMorph3D/releases/tag/assets-bfm-2009) 分发，哈希与许可边界见[模型资产台账](docs/model-assets.md)。2026-10-20 已单独获取官方 SAM 预训练权重与 FG-NET 研究镜像小样；SAM 已在独立环境跑通 batch=1 二维推理（稳定前向约 0.12 s、峰值显存约 2.7 GB），FG-NET 仅完成解码/检测/68 点一致性研究检查（292 张中 290 张单人脸并重建成功）、未用于训练，两者都不改变服务许可门槛和年龄能力状态，来源/哈希/限制见[年龄模型与校准样例获取记录](docs/年龄模型与校准样例获取记录.md)，SAM 环境见 [SAM 独立环境配置](docs/SAM独立环境配置.md)。

第2阶段已实现静态/年龄资产契约、结果级能力、源年龄和模型生命周期，历史验证见 [B1 协议与生命周期开发记录](docs/B1协议与生命周期开发记录.md)。第3阶段已接入真实适配器和成功资产路径；全局 `reconstruction` 仅在严格检测/重建模型均 ready 时开启，年龄与实时能力继续关闭。现有研究清单在当前服务中仍使四项能力为 false，离线研究不会改变该门槛。

静态网格保留身份、表情和顶点顺序，轴向为右手 Y-up、正面 +Z；按源网格 bbox 高度统一归一化到 1，并记录可逆的中心/比例。它是非人体米制标定的展示对象；输出为无纹理的开放人脸表面，无 UV、年龄目标或完整后脑。相机仿射块经 SVD 提取纯旋转，原始图像平移不冒充米制位移。GLB 仅存于进程内存，默认 TTL 1800 秒、总量 512 MiB、128 项、单项最多 64 MiB，读取期间保留租约；取消或关闭后不发布迟到结果。

## 本地启动

使用 Node.js 22.18+ 或更新的 LTS 版本及 npm；本次验证环境为 Node.js 24.14.1。单元测试使用 Node 原生 TypeScript 转换功能。前端采用原生 TypeScript、Vite 和 Three.js，无 React/Vue。具体版本以 `frontend/package-lock.json` 为准。

```powershell
cd frontend
npm ci
npm run dev
```

浏览器打开终端显示的本地地址。演示模式不需要后端、模型权重或数据集；首次安装 npm 依赖需要网络。运行时不依赖远程字体、图片或云端人脸服务。

```powershell
npm run build
npm test
npm run test:e2e
```

浏览器测试直接使用本机安装的 **Google Chrome 和 Microsoft Edge**，通过 Playwright 的 `chrome` / `msedge` 通道运行。运行机器需要先安装这两个浏览器，无需额外安装 Playwright Chromium。截图、下载样例及失败跟踪输出到 Git 已忽略的 `output/frontend-verification/`。

`build` 检查类型并生成生产构建；`test` 运行单元测试；`test:e2e` 运行浏览器交互测试。测试结果以本次实际命令输出为准，测试通过不代表真实模型精度或实体摄像头兼容性已验收。

2026-10-18 本地验证：生产构建通过，单元测试 **30/30**，Chrome/Edge 浏览器测试 **26/26**；开发环境和生产构建均完成浏览器复验。详细证据与尚待实机验收的项目见 [实施路线与前端交付](docs/实施路线与前端交付.md#本次验证记录)。

第3阶段已由真实 CPU 模型从成年人人像生成 38,365 顶点、76,073 面、1,838,792 字节的静态 GLB。Chrome/Edge 实际查看器分别完成离线研究资产加载、导出和重新加载，顶点、法线、索引保持一致；这使用独立本地资产预览服务，不验证严格服务的真实模型成功推理，也没有新增 UI 本地 GLB 导入控件。真实输入变体、自动化回归和证据路径以 [B2/B3 开发记录](docs/B23真实静态链路开发记录.md) 为准，G1 继续受许可与进一步真实身份检查约束。

## 前端使用方式

开发者可按[稳定浏览器流重验入口](docs/稳定浏览器流重验入口记录.md)显式准备/冻结/运行合成传输门槛；当前Chrome/Edge仍有原始请求失败，尚未进入稳定版真实研究服务验收。该脚本不随普通单测自动运行。

- **演示模式**：查看程序化头模，调节 20—70 岁，使用对照视图、视角、材质和光照选项；可导出 PNG 和 GLB。导出的仍是演示模型。
- **照片与摄像头**：可选择本地照片或开启摄像头预览、拍照。相机需要浏览器许可和安全上下文（`localhost` 可用）；关闭相机后释放设备。选入照片本身不代表已进行人脸检测或三维重建。
- **本地服务模式**：按 [后端启动说明](backend/README.md) 启动服务，再连接默认 `http://127.0.0.1:8000`。界面显示每个模型的实际状态，只在加载期间限时刷新，按服务及结果能力启禁操作；严格检测/重建模型均 ready 时可上传单人照片重建、查看和导出静态网格。现有研究清单仍被许可门槛阻止；实时检测和年龄纹理尚不可用。
- **清除工作内容**：开始新会话或清除照片后，不应继续展示上一张照片的个人重建结果。照片与摄像头帧不应写入浏览器持久存储。

当前前端资产接入约定为：成功响应明确 `asset_mode`、结果能力、源年龄和拓扑标识。`static` 自包含 GLB 不含形变目标；`age_morph` 要求合法命名目标 `age_20`、`age_45`、`age_70`。静态结果不虚构年龄能力，未知源年龄显示未知；无人脸和多张人脸分别返回可解释的 422 错误。完整字段和校验见 [接口契约](docs/api.md)。

## 实施顺序

1. **前端**：完成可运行的本地交互、演示形变、导出、错误状态、响应式和自动化验证。
2. **后端**：实现 FastAPI 接口与契约验证，再接入预训练检测、重建和年龄形变；先固定一种网格拓扑。
3. **获取训练集**：核验官方来源、许可、允许用途和访问条件，再下载并记录版本与哈希。
4. **数据集预处理**：年龄过滤、标注转换、质量检查、去重和按身份划分，形成可复现的数据清单。
5. **训练与评测**：先跑预训练基线，再做检测微调、可选 5 点训练和年龄方向回归；记录效果、资源开销和回退条件。

每阶段的产物和出口条件见 [实施路线与前端交付](docs/实施路线与前端交付.md)。原项目计划与设计稿保留作背景资料；新路线按当前请求的实施顺序组织，不把计划条目当作已经实现的功能。

训练和数据处理目录在对应阶段建立。模型、数据集、日志、构建产物及真实凭证不进入源码仓库；原有 `.gitignore` 保留。后端本批范围、验证和剩余事项见 [后端开发记录](docs/后端开发记录.md)。

前端入口为 `frontend/src/main.ts`，界面与样式分别为 `layout.ts`、`style.css`；三维视口与示例网格为 `viewer.ts`、`demo-head.ts`；年龄插值为 `age.ts`；本机 HTTP、摄像头和 WebSocket 封装为 `services.ts`，数据类型为 `contracts.ts`。`frontend/tests/` 包含可复现的单元和浏览器测试。

三维交互与导出基于 [Three.js OrbitControls](https://threejs.org/docs/pages/OrbitControls.html) 和 [GLTFExporter](https://threejs.org/docs/pages/GLTFExporter.html)；构建方式参见 [Vite 官方说明](https://vite.dev/guide/)。

## 使用边界

研究目标是统计意义上的年龄变换，适用目标年龄为 20—70 岁。演示与评测只使用获得相应授权的成年人的照片。人脸数据在本机处理；当前前端仅允许访问本机服务，未来改变数据传输范围需重新明确设计和授权。

BFM、FLAME、预训练权重及各数据集有各自的许可和访问条件。仓库中引用某项目或数据集不代表已经取得下载、再分发或训练授权；对应阶段先核验，再使用。
