# 岁月镜 AgeMorph3D — 前端设计系统说明

> 版本 v1.0 ｜ 2026-10-18 ｜ 配套实现：`design/index.html`

---

## 一、视觉主张：**「坐标系中的岁月」— 工程蓝图 × 时间刻度**

### 主张陈述

本设计的视觉语言不是"一个好看的网页"，而是把项目本身的工作原理翻译成界面：

**这个系统做的事，本质上是把「时间」变成「参数」。**
年龄滑块 `w ∈ [0,1]`、形状参数 `β`、逐顶点位移、morph target 权重——项目在数学上就是一条被参数化的时间轴。因此设计把**刻度、坐标、参数读数**提升为全站视觉母题：

- **深色视口**（近黑蓝 `#0A0E1A`）＝ three.js 渲染画布的本色，让人联想到 WebGL 视口与工程仪器，而非营销落地页；
- **一条青→琥珀的时间渐变**（`#35D3C0` → `#E8A04C`）＝ 20→70 岁的年龄轴，是全站**唯一**的彩色强调元素，出现在刻度尺、滑块、里程碑标记上；
- **等宽数字 + 细刻线 + 交叉准星**＝ 工程图纸/仪表气质，呼应毕设的工程规范语境（接口冻结、验收标准、payload < 1 KB）。

### 与项目主题的契合点

| 设计决策 | 项目依据 |
|---|---|
| 年龄刻度尺作为 Hero 主视觉，可拖动 | 系统核心交互就是"拖动年龄滑块（20—70 岁）实时预览"（任务书 D3 验收项） |
| 深色画布 + 线框等高线人脸 | 三维网格、morph target、UV 纹理的可视化隐喻，即产品的实际渲染形态 |
| 青（20 岁端）→ 琥珀（70 岁端）渐变 | 年龄轴的两极；渐变方向在所有组件中严格保持"左青右珀"，建立时间方向感 |
| 等宽字体排印所有数字与参数 | 项目文档中大量参数（β/ψ/pose、NME、FPS、MAE），mono 数字是工程师的母语 |
| 横向时间轴呈现 30 周计划 | 设计母题与内容同构——连项目排期都是一条"刻度尺" |
| "本地处理 · 数据不出本机"作为页脚信条 | 项目三条边界之一是合规卖点，设计上给它仪式感的收尾位置 |

### 自检（对照通用默认的排雷）

- ❌ 没有用暖奶油底+衬线大标题+陶土色（文艺杂志套路）——与工程项目语境不符；
- ❌ 没有用"近黑底+荧光绿终端风"（开发者工具套路）——改用近黑**蓝**底 + **双色时间渐变**，绿色被完全排除；
- ❌ 没有用 SaaS 卡片墙 + 圆角阴影套件——所有区块用**蚀刻细线 + 准星标记**分隔，信息以规格表（spec sheet）形态呈现；
- ❌ 没有用 01/02/03 装饰性编号——编号只出现在真实序列上（流水线 M1→M3、周计划 W1→W30）；
- ✅ 唯一"用力点"是 Hero 的可交互年龄刻度尺，其余区块保持安静的仪器感。

## 二、配色系统

| 角色 | 色名 | Hex | 用途与逻辑 |
|---|---|---|---|
| 背景（视口） | Ink Viewport | `#0A0E1A` | 主背景。近黑深蓝，模拟 WebGL 渲染视口与蓝图底纸 |
| 面板 | Panel | `#111828` | 规格表、读数条等次级承载面，与背景仅差一档明度，靠细线而非阴影分层 |
| 刻线 / 边框 | Etch Line | `#233047` | 所有分隔线、表格线、准星。低亮度蓝灰，像蚀刻进面板的痕 |
| 文字（主） | Readout | `#E9EEF6` | 标题与正文。冷调白，深色视口上的高对比读数 |
| 文字（次） | Dim Label | `#8B96AC` | 标签、注释、单位。仪器上的丝印小字 |
| 强调 · 时间起点 | Youth Cyan | `#35D3C0` | 20 岁端。冷青，渐变左极；同时承担链接/hover 色 |
| 强调 · 时间终点 | Age Amber | `#E8A04C` | 70 岁端。暖琥珀/铜，渐变右极；用于里程碑与关键标记 |
| 强调渐变 | Time Gradient | `linear-gradient(90deg, #35D3C0, #E8A04C)` | 全站唯一彩色元素：年龄轴、滑块填充、进度刻度 |

**色彩逻辑**：克制到只剩一组双色渐变。深色底承担"工程视口"的场域感，渐变承担"时间"的叙事；除此之外不允许第三种彩色出现（成功/错误状态用语义化的青/琥珀深浅变体表达，不引入红绿）。

**对比度**：`#E9EEF6` on `#0A0E1A` ≈ 15.8:1（AAA）；`#8B96AC` on `#0A0E1A` ≈ 6.1:1（AA）；渐变仅用于装饰与大面积填充，不承载小字号正文。

## 三、字体系统

| 角色 | 字族 | 字重 | 说明 |
|---|---|---|---|
| 展示标题（拉丁/数字） | **Space Grotesk** | 500/700 | 几何无衬线，字腔方正，带仪器表盘气质；用于 AgeMorph3D 字标、区块标题 |
| 标题（中文） | Noto Sans SC / PingFang SC / Microsoft YaHei | 700 | 与 Space Grotesk 几何感匹配的黑体 |
| 正文 | Noto Sans SC / PingFang SC / Microsoft YaHei | 400/500 | 行高 1.75，段宽 ≤ 68 字符 |
| 读数 / 刻度 / 参数 | **JetBrains Mono** / ui-monospace | 400/500/700 | 一切数字、年龄、指标、单位、代码片段的专属字体——mono 数字是本设计的"方言" |

**字号层级**（桌面基准，移动端整体缩至 0.85 档）：

| 层级 | 规格 | 用途 |
|---|---|---|
| Display | 64 / 1.05 / -0.02em | Hero「岁月镜」字标 |
| H1 | 40 / 1.15 / -0.01em | 页面级标题（英文 wordmark） |
| H2 | 28 / 1.25 | 区块标题 |
| H3 | 17 / 1.4 / +0.04em / 大写(拉丁) | 区块眉题（kicker） |
| Body | 16 / 1.75 | 正文 |
| Small | 13 / 1.6 | 注释、图注 |
| Readout | 20–32 / 1.1 / tabular-nums | 大号参数读数（30 FPS、< 1 KB 等） |

**排印规则**：所有数字默认 `font-variant-numeric: tabular-nums`；年龄永远写成 `20 → 70` 的箭头式；单位与数字之间空半格（`30 FPS`）。

## 四、版式系统

### 栅格与间距

- 12 列流体栅格，内容最大宽 **1180 px**，两侧安全边距 24 px（移动端 20 px）；
- **8 px 间距基线**：组件内间距 8/16/24，区块间距 96/128；
- 不用卡片阴影堆叠，区块之间用 1 px 蚀刻线（`#233047`）+ 左上角 **12×12 交叉准星**标记分隔——每个区块像图纸上的一个图幅。

### 关键区块

1. **Hero（全高）**：左侧巨型字标 + 一句话使命；右侧/下方是**贯穿整宽的年龄刻度尺**——20 到 70 的蚀刻刻度，可拖动滑块，滑块拖动时右侧线框人脸等高线实时形变、读数以 mono 大字跳动。下方一排关键读数（30 FPS / <1 KB / ≤5 s / 本地处理）。
2. **三条边界**：三行蚀刻条目（非卡片），每行一条"做/不做"的对仗陈述，行首准星标记。
3. **系统流水线**：M1 检测 → M2 重建 → M3 年龄变换 + 纹理 → 可视化，横向真实序列（此处编号正当），节点间用渐变连线；下方区分"实时线 / 离线线"双泳道。
4. **技术栈规格表**：对齐毕设文档的 spec sheet 形态——左列层名（丝印小字），右列 mono 字体锁定版本，行间细线。
5. **量化指标**：读数墙。每个指标一个 mono 大数字 + 小字标签，等宽数字制造仪表阵列感。
6. **30 周时间轴**：横向刻度尺（与 Hero 母题呼应），5 个阶段为刻度区间，里程碑用琥珀色菱形标记。
7. **交付物与合规**：清单式排列 + 页脚信条「人脸数据不出本机」。

### 响应式策略

- ≥1024 px：12 列，Hero 双栏（字标 | 线框脸），时间轴横向；
- 640–1023 px：Hero 单栏堆叠，指标墙 2 列，流水线允许换行；
- <640 px：所有栅格转单列，Display 缩至 44 px，时间轴转纵向刻度（刻度尺旋转 90° 的语义不变）；
- 触控目标 ≥ 44 px；滑块在移动端加大拇指区。

### 动效原则

- 非用户触发的动效只有一处：Hero 载入时刻度尺的渐变从左向右"扫"一次（1.2 s，单次）；
- 其余动效全部响应用户动作：滑块拖动 → 读数与线框实时插值；hover → 准星标记变为青色；
- `prefers-reduced-motion` 时禁用扫描与过渡。
