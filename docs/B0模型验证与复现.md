重建探针本次 5 次耗时约 3.85—5.28 ms，含 ROI/BGR 预处理、CPU 回归和 BFM 网格计算，不含照片解码、模型加载、GLB 或网络。模型与 NPZ 加载约 248 ms。检测计时含 resize、模型与 NMS，具体数值以各次报告为准，不能与另一份仅测算子的 `yolo-research/cpu-poc.json` 混用。小样例不证明重建精度、跨身份泛化或实时设备帧率。

样例为 scikit-image v0.25.2 的 [astronaut](https://scikit-image.org/docs/0.25.x/api/skimage.data.html#skimage.data.astronaut)，其文档说明 NASA 来源和 public domain 状态。本次仅作本地教育研究样例，不作训练数据，不暗示 NASA 或照片中人物认可本项目；源年龄明确为 `unknown`。

## 运行现有本机样例

以下 PowerShell 命令从项目根目录执行。模型和样例已放在 `data/`，探针输出放在 `output/`；两者都由现有 `.gitignore` 忽略。源码中的清单仅含元数据，不能放在原位置直接运行，因为资产路径限定在清单目录内。

```powershell
Set-Location 'D:\project file\AgeMorph3D'
uv --cache-dir output\uv-cache sync --project backend --locked --extra inference --python 3.11
Copy-Item backend\model-manifests\yolov5n05-face.research.json data\models\yolov5n05-face\manifest.json
Copy-Item backend\model-manifests\3ddfa-v2.research.json data\models\3ddfa-v2\manifest.json

.\backend\.venv\Scripts\python.exe -m agemorph3d.model_probe `
  --manifest data\models\yolov5n05-face\manifest.json `
  --image data\samples\astronaut.png `
  --output-dir output\backend\b0\detector-probe `
  --research-allow-unresolved --save-overlay --runs 5

.\backend\.venv\Scripts\python.exe -m agemorph3d.model_probe `
  --manifest data\models\3ddfa-v2\manifest.json `
  --image data\samples\astronaut.png `
  --bbox 175.90365600585938 53.15315628051758 99.02249145507812 127.23995971679688 `
  --output-dir output\backend\b0\reconstructor-probe `
  --research-allow-unresolved --save-overlay --save-geometry --runs 5
```

第二条探针使用第一条实际输出的 `bbox=[x,y,width,height]`。换照片时必须采用新照片的实际框，不得复用这四个数。`--save-overlay` 会保存含人物照片的叠加图；`--save-geometry` 会保存本地重建数组，均默认关闭。不带研究开关时，未完成许可核验的清单在加载前被拒绝，返回失败报告和退出码 1。

探针不接受动画、坏图或错误 MIME，沿用服务的 10 MiB/1600 万像素边界。模型清单要求 HTTPS 来源、具体版本/条款、文件大小和 SHA-256；拒绝目录穿越、外部符号链接、缺失或篡改文件。ONNX 以有界字节加载，禁止读取未登记的 external data。报告不包含照片字节或库异常中可能出现的私有输入。

## 重新准备 3DDFA 的 NPZ

常规推理不加载 pickle。已有本机 NPZ 可直接使用。需要从已取得、已核验的官方旧格式重新构造时，转换器先核验所有三个源哈希，再使用固定 NumPy global 白名单读取，拒绝 object 数组、任意类、尾随对象、错误维度和不明确的面索引基。它是受限旧资产读取器，不宣称能安全处理任意不可信 pickle。

以下命令用于尚无转换产物的资产目录；存在同名输出时工具会拒绝覆盖。

```powershell
.\backend\.venv\Scripts\python.exe -m agemorph3d.prepare_tddfa `
  --bfm data\models\3ddfa-v2\bfm_noneck_v3.pkl `
  --bfm-sha256 89ac96480eddc331120f2c8401737c55a5fcc97b10f8a64574e63976c3d246ca `
  --tri data\models\3ddfa-v2\tri.pkl `
  --tri-sha256 0562a594d8369f7d1c86306522ff76fd3a2c81cf90ba9443893c1191ad0abbb8 `
  --stats data\models\3ddfa-v2\param_mean_std_62d_120x120.pkl `
  --stats-sha256 090d7150f77cb66c29ddae21e4508fbde59123dcd1dea7facc24a7ed06d1c795 `
  --output-dir data\models\3ddfa-v2
```

转换产物版本为 `agemorph3d-3ddfa-npz-v2`。`conversion.json` 记录源/输出哈希和实际变换，压缩文件在完整生成后发布。真实输出数组已与受限读取的上游数组逐项精确比较。

## 坐标、拓扑与本次发现

照片先执行 EXIF 方向纠正，再转 RGB。YOLO 使用固定 640 方形 letterbox、114 padding、RGB/NCHW `/255`；后处理采用 `obj*class`、0.5 置信度和 0.45 IoU 的 NMS。框与全部五点使用相同的实际取整 resize/padding 逆变换，不镜像。五点顺序在本次正面样例中为图像左眼、右眼、鼻、左嘴角、右嘴角；上游眼中心/眼角定义及侧脸可见性仍需正式冻结，不能以此样例代替点位精度评价。

3DDFA 使用 BGR、官方 ROI 扩展和越界零填充，`(x-127.5)/128`；回归输出先按配套 mean/std 还原。身份与表情已应用到 `u + w_shp @ shape + w_exp @ expr`，按 Fortran 语义还原 XYZ。网格输出明确为 `bfm_model_raw`，没有应用相机投影，也没有冒充已验 canonical。原始轴中 X 左右、Y 上下、Z 深度的数值检查与眼/鼻/下巴一致；物理单位与最终 glTF 归一化语义仍留给下一阶段冻结。

投影前 12 个数是含尺度的 `3×4` 仿射块，不是正交旋转矩阵。回投影执行官方 120px 坐标和 ROI 变换；它仅用于样例检查，不作为对外 pose。独立 `tri.pkl` 是该裁剪模型的重建拓扑，不能用字典内另一套三角面替换。

本次拓扑标识 SHA-256 为 `cc449ed7efa2860bed64be0a7e29ad8944912148c69f938ff768c8766d65e7cb`，按版本化小端编码记录顶点数、面序和 204 个坐标索引；形状/表情基由 NPZ 哈希另行固定。

| 实际证据 | 发现 | 实施处理与下一步 |
|---|---|---|
| 源 keypoints 的第 44 组为 `[37149,37150,36263]` | 一组 XYZ 并非同一顶点，不能全部压成 68 个顶点 ID | v2 原样保留 204 坐标索引，稀疏点逐坐标重组；转换报告记录异常，不修补上游数据 |
| `UV` 为 `[53215,2]`，`indices` 有 38365 个互异元素 | 可按官方方法构造裁剪 UV 数组，但不能因此认定它也是完整 BFM 的逐顶点映射 | 已核对 UV 数值；可见性、纹理、法线和接缝仍未验收 |
| 完整 BFM `shapePC` 为 199 维，`age_shape/age_tex` 属性为 200 项；直接用现有 UV 裁剪索引取完整均值，与 3DDFA 均值差异显著 | 当前没有建立完整 BFM 属性到最终裁剪基的可靠映射；属性也没有证明逐岁尺度 | 不把属性数组直接加到 40 维 shape；后续验证坐标/裁剪/基映射、源年龄和年尺度 |
| 独立真模型探针成功，服务仍为原有无模型模式 | 离线执行证据不等于 lifespan、GLB 或浏览器闭环 | 下一阶段接真实加载/自检状态、结果级能力、源年龄和静态模式，再推进 B2/B3 |
