# B1 协议与生命周期开发记录

日期：2026-10-19。本轮按 B0 后的第2阶段实现模型生命周期和前后端 v1.2 契约。真实照片到 canonical GLB 的发布链路仍属于 B2/B3；本轮不宣布完整 G0、G1、G2 或 G3 通过。

本文保留第2阶段的实现和463项回归批次。后续B2/B3已经接入静态成功链路、GLB与缓存，见 [B23 真实静态链路开发记录](B23真实静态链路开发记录.md)；现有清单仍有许可门槛，不能将离线样例与浏览器技术验证视作G1通过。

## 已实现的行为

服务从 `AGEMORPH_DETECTOR_MANIFEST`、`AGEMORPH_RECONSTRUCTOR_MANIFEST` 读取显式清单路径。默认不配置模型，仍可在没有 NumPy/OpenCV/ONNX Runtime 的环境启动基础 API。配置清单后在原有单线程 executor 中执行严格资产核验、实例构造、CPU 算子自检；健康接口可读取 `loading`，不会被加载阻塞。

| 状态 | 实际条件 |
|---|---|
| `missing` | 未配置模型，或所配清单文件不存在 |
| `loading` | 已开始核验/加载/算子自检，实际线程仍在执行 |
| `ready` | 该模型的严格清单、实例和算子自检全部通过，实例由生命周期持有 |
| `error` | 条款、格式、哈希、依赖、实例或自检失败；健康信息仅含固定脱敏原因 |

`ready` 是单个模型算子的状态；四项服务 `capabilities` 表示端到端功能。B1 尚无 GLB 发布/实时推理，因此四项仍为 false，不因两个模型实例可用就开放成功端点。年龄形状和纹理模型尚未接入，分别保持 missing。

加载期间请求与初始化共享准入，处理槽位被占用时返回429，不积压等待队列。单次请求仍沿用现有 HTTP/WS 超时；调用方取消或超时不会提前释放实际线程槽位。初始化没有伪造硬超时，关闭先禁止新任务与迟到模型发布，再等待底层线程结束、清理实例。取消一个关闭等待者不取消实际清理。已开始的 CPU/C++ 算子不承诺被强制中断。

## 冻结的成功契约

详细字段及示例见 [api.md](api.md)。健康版本为 `1.2`，前端兼容读取 v1.1/v1.2 的完整健康能力；成功响应必须采用新的显式契约，不猜测旧响应的资产模式。

成功重建保留 `mesh_id/shape/expr/pose/texture_url?`，新增必填 `topology_id`、`asset_mode`、结果级 `capabilities` 和 `source_age`。`static` 与 `age_morph` 必须和本次形状能力一致；年龄纹理可与形状独立，但任何绝对年龄能力都需要已知源年龄，纹理还需要有效基础纹理 URL。校准标识和声明本身不证明年龄效果已验收。

源年龄必须明确记录 `value/method/calibration_id`。unknown 为两个 null，不能变成30/45岁；user 有20—70数值而校准标识为 null；estimated 必须有年龄值和校准标识。上传接口接受可选 `source_age` 普通十进制文本，省略为未知。前端服务方法已可显式传入；界面本轮未新增源年龄输入，不会用演示目标年龄代填。

前端查看器根据明确模式加载：静态网格不需要 morph，也拒绝任何非空 morph 属性；年龄模式仍要求三个合法命名目标，损坏资产不降级。纯静态显示原始重建和源年龄，未知时显示未知，禁用年龄和对照。年龄模式的重置/对照使用真实源年龄（包括小数），演示仍为30岁。静态导出使用 original 文件名，根元数据不添加 age/ageAnchors/displayAge，保留资产模式、源年龄和拓扑标识；年龄纹理目标用 texture_age 分开记录。

健康只在存在 loading 时每500ms、单飞刷新，整体最长30秒；达到稳定状态即停止。重连、断开和 pagehide 中止请求/计时器，旧响应不能覆盖新连接。刷新不会重置已经加载的模型，不对稳定缺失/失败进行后台重试。

已知小边界：页面从浏览器 bfcache 返回时，先前 loading 的刷新不会自动续接，可通过重新检查连接恢复；pagehide 的请求取消与资源释放已落实。

## 复现和下一阶段

从项目根目录安装并执行：

```powershell
uv --cache-dir output\uv-cache sync --project backend --locked --extra inference --python 3.11
Set-Location backend
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\ruff.exe check src tests
.\.venv\Scripts\ruff.exe format --check src tests
.\.venv\Scripts\python.exe -m agemorph3d
```

另一个终端在 `frontend/` 运行 `npm test`、`npm run build`、`npm run test:e2e`。模型清单配置方法见 [后端启动说明](../backend/README.md)。不要把研究清单状态改成 verified 来让健康灯变绿；应先取得并登记实际适用条款。

下一阶段仍是 B2/B3：落实 canonical 轴向/单位与纯旋转，接真实单人/无人/多人处理、身份表情已应用的 GLB、TTL/容量缓存和取消后不发布迟到资产，再用真实照片完成 Chrome/Edge 导出及再导入。拓扑标识在本轮是协议元数据，尚未证明实际 GLB 顶点序/形状基的对应。B6 实体相机及 B4/B5 年龄校准、UV/纹理效果继续分阶段验收。
