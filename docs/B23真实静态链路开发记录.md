## 已接入的行为

`POST /api/reconstruct` 仍沿用 v1.2：有界接收图片、真实解码并纠正EXIF，在同一个工作线程中执行YOLO检测、3DDFA回归、身份/表情几何和GLB编码。零人脸为422/NO_FACE，多人为422/MULTI_FACE，必须恰好一人才继续。模型或几何失败为固定脱敏错误，失败后可以重新提交；没有用演示网格补成功。

检测/重建均严格加载、自检成功且服务未关闭时，健康能力 `reconstruction=true`；年龄形状、年龄纹理、实时仍为false。重建模型自检新增完整canonical/GLB与纯旋转检查。清单、哈希、许可、provider和实例校验继续执行；正式loader没有研究开关。

成功结果为static、年龄能力均false、texture_url=null，源年龄原样保留unknown或明确用户值。身份40维与表情10维已经应用到网格。前端消费已有静态路径，显示原始重建、禁用无能力的年龄控件并导出original文件名；本轮未新增本地GLB文件导入控件。

## canonical、拓扑和尺度

保留原始38365个顶点的顺序与76073个面的顺序，原模型X不变、Y向上、正面+Z。canonical为 `q=(v-bbox_center)/bbox_height`，等比归一化并记录源中心、源高度和比例，保持身份/表情比例且可还原源坐标。源拓扑SHA-256为 `cc449ed7efa2860bed64be0a7e29ad8944912148c69f938ff768c8766d65e7cb`；每面固定从 `[a,b,c]` 改为 `[a,c,b]`，建立外向面积加权单位法线，版本标识为 `tddfa-bfm-canon-v1-` 加源哈希。

单位没有凭原始数值猜测。glTF标准以米解释场景线性单位，而本项目输出的是高度1的归一化展示物体，不能解释为真实人脸高1米，也不能用来做人体米制测量。GLB的 `coordinate_metadata` 明确dimensionless、source_units=unverified和metric_scale_verified=false。当前输出是开放面部，没有完整后脑、UV或纹理。

投影3×3块经SVD/polar分解提取正交旋转，显式拒绝反射与奇异/严重病态块，保证RᵀR≈I、det(R)≈1；记录原仿射投影、尺度/剪切残差及ROI。相机图像平移不作为空间米制平移，API的t为三个0，含义为未估计米制平移。R未烘入canonical网格，HTTP前端不重复施加它。

上游固定提交的 [similar_transform](https://github.com/cleardusk/3DDFA_V2/blob/1b6c67601abffc1e9f248b291708aef0e43b55ae/utils/tddfa_util.py)用于投影后的图像Y/ROI转换；[pose.py](https://github.com/cleardusk/3DDFA_V2/blob/1b6c67601abffc1e9f248b291708aef0e43b55ae/utils/pose.py)将输入定义为仿射相机。本轮采用SVD保证纯旋转，没有把上游图像转换施加到canonical几何。原模型轴向和绕序另以本地实际网格与正侧面检查确认；这些源码不是原始单位的独立证明。GLB结构、对齐和单位说明以 [Khronos glTF 2.0规范](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)为依据。

## 缓存、发布和资源

资产为不可变的进程内GLB字节，128位随机标识，仅已登记ID可通过 `/api/assets/{mesh_id}/mesh.glb` 读取。默认TTL1800秒、总量512MiB、128项、单项64MiB；三个可配置环境变量见 [后端README](../backend/README.md)。TTL从发布时开始，访问不续期。满时淘汰未被读取固定的LRU项，不能容纳时429/BUSY；过期/未知/淘汰/重启后的ID为404。

读取租约固定资产至ASGI发送结束，失败或取消也释放；过期后拒绝新读取，已开始的读取可以完成。原图、裁剪和服务生成GLB不落盘，因此无需发布临时文件或重启删除磁盘产物。关闭清除缓存，阻止新读取/发布；已有租约可结束。

实际CPU工作返回未发布结果，事件循环仅在请求仍有效、服务未关闭且HTTP绝对截止时间未过时原子发布。取消、断连、超时和关闭不会发布迟到网格；已观测到的断开以499/CANCELLED终结。原生算子继续运行直至实际结束，工作槽在此之前保持忙状态。即使推理先完成而事件循环恢复时已过截止时间，也会返回504并丢弃结果。

## 复现

从项目根目录安装推理依赖，再使用新的输出目录执行：

```powershell
Set-Location 'D:\project file\AgeMorph3D'
uv --cache-dir output\uv-cache sync --project backend --locked --extra inference --python 3.11
.\backend\.venv\Scripts\python.exe -m agemorph3d.static_probe --detector-manifest data/models/yolov5n05-face/manifest.json --reconstructor-manifest data/models/3ddfa-v2/manifest.json --image data/samples/astronaut.png --output-dir output/backend/b23/repro-static --research-allow-unresolved
$env:AGEMORPH_RESEARCH_MESH = (Resolve-Path output/backend/b23/repro-static/mesh.glb).Path
$env:AGEMORPH_RESEARCH_RESULT = (Resolve-Path output/backend/b23/repro-static/result.json).Path
Set-Location frontend
node tests/static-mesh-research.mjs
```

本机已有样例来自B0登记的公开成年人人像astronaut，来源与哈希见 [B0记录](B0模型验证与复现.md)，年龄未知。CLI输出mesh.glb、result.json、report.json，已有这些文件时拒绝覆盖；重复运行须使用新的结果目录。省略研究开关会严格核验，现有清单因许可未完成而失败。研究开关不进入正式服务、不会改写清单或开启健康能力。

项目常规检查从backend运行 `.\.venv\Scripts\python.exe -m pytest -q`、`.\.venv\Scripts\ruff.exe check src tests`、`.\.venv\Scripts\ruff.exe format --check src tests`；frontend运行npm test和npm run build。完整接口与缓存错误见 [api.md](api.md)。
