2026-10-23整理，实验记录日期为2026-10-22。隔离研究显示模块已实现并完成本机验证：滑块事件直接采样共同UV纹理，源点与邻域统一使用BLEND；退出研究模式恢复原材质和普通纹理元数据。Chrome、Edge各98个条件及导出再导入通过。这个出口是显示工程验证，年龄形状、纹理质量、身份与G3仍未签收。

## 修正的问题与实现

[首轮BLEND实验](BLEND连续显示与源龄锚点研究.md)保留了“精确源点原始MASK、邻域BLEND”的策略。同图仅切换材质就能复现源点跳变。本批在查看首轮开发结果后选择新的[显示协议](research-texture-display-v1.json)，先保存决策依据，再冻结源码和输入；不是独立年龄评价，也没有事后添加质量通过阈值。

[纯采样器](../frontend/src/research-texture.ts)接受共同UV、同尺寸、二值alpha的原始源/SAM条件锚点，执行线性光预乘alpha混合，量化采用ties-to-even。目标显示条件保留20—70内小数，拒绝静默取整、超出实际锚点的外推、同类重复年龄和未知源的默认源龄。SAM条件锚点必须是整数；小数显示插值不表示运行过小数条件SAM。锚点总像素上限1600万，数量上限64。

已知研究源龄必须有唯一原始源锚点，原始源覆盖同龄SAM锚点。精确命中时返回原RGBA缓冲引用，不进行颜色重算；调用方须在时间线使用期间保持输入像素不变。其他采样返回新的像素数组。8个研究源龄来自既有文件名标签，2个未知源不设原始绝对年龄锚点；全部API `SourceAge`继续为unknown。

[查看器](../frontend/src/viewer.ts)新增显式`setResearchDisplayTexture(frame | null)`入口，仅适用于已加载的静态网格。它复制采样像素到自有纹理，所有条件统一使用直通alpha BLEND、`alphaTest=0`、`depthWrite=false`，源点也遵循同一策略。切换不重新加载网格。研究状态只写入`research_display`，不会把研究条件写成API源龄；进入时暂存并隐藏普通`texture_age`，退出时恢复其原有值或缺省状态。

```typescript
const timeline = createResearchTimeline(anchors, knownResearchSourceLabel);
viewer.setResearchDisplayTexture(sampleResearchTexture(timeline, 42.5));
// 退出研究显示，恢复进入前的map和透明/深度材质状态。
viewer.setResearchDisplayTexture(null);
```

原始GLB/PNG文件继续单独持有且字节不变；统一BLEND画面及其导出是显示衍生物，不承诺与原始MASK画面一致，也不把重序列化后的GLB称为原文件。研究导出带有显示条件/源标签/衍生物标记。原普通纹理请求会被研究更新取消；恢复、普通纹理覆盖、模型或demo替换、销毁均清理研究状态与自有资源。

生产`main.ts`、控件、API契约和服务没有接入该入口。当前滑块页面由[隔离浏览器脚本](../frontend/tests/research-texture-display.mjs)临时提供，用于验证实际DOM输入事件到采样器、查看器和导出的路径，不是生产产品入口。

## 测量与结果

复用10个源、37个已注册SAM atlas和首轮98个冻结条件；没有新模型推理、训练或保留组评价。每个浏览器加载每源原始GLB一次后，通过range输入事件逐例更新，校验事件次数、未重载网格、采样RGBA与Python参考一致、实际画面非空、几何/UV不变、GLB导出再导入的材质和元数据。98个条件包含每源20/70边界、8个精确源点及区间/源龄邻域。

Chrome `155.0.8059.85`、Edge `155.0.4283.62`均使用软件WebGL，各98例通过，合计196份导出PNG全部持久保存，另保存8份代表性GLB。两者均无页面异常或外部HTTP请求。8个已知源另外测量四个epsilon、前/侧视角、黑/白背景，分别比较左邻→源点与源点→右邻。

| epsilon（年） | 每浏览器比较数 | 画面完全相同次数 | 最大归一化RGB通道RMS | 最大单通道差异 |
|---|---:|---:|---:|---:|
| 0.1 | 64 | 0 | 0.00533511 | 0.21960784 |
| 0.01 | 64 | 46 | 0.00117786 | 0.17647059 |
| 0.001 | 64 | 64 | 0 | 0 |
| 0.0001 | 64 | 64 | 0 | 0 |

两个浏览器的上述统计相同。RMS与最大通道差异是分别在全部比较中取最大值，可能来自不同源/视角，不应混成同一个案例。它们测量的是色调映射后的8位sRGB画面。小步长的零差异包含RGBA8量化平台，只能支持本批采样未再出现首轮材质切换阶跃，不能推出普遍数学连续性。退出统一BLEND、恢复原始MASK后，同图材质控制仍有非零差异：每浏览器32次比较的RMS范围为0.00137382—0.02161004；这是保留原始渲染策略的预期区别。

独立审核用Pillow直接解码输入atlas与196份导出内嵌PNG，核验逐文件指纹，不经过浏览器canvas：

| 导出分组 | 数量 | 原始RGBA完全一致 | 有RGB变化 | alpha/未知区域 |
|---|---:|---:|---:|---|
| 精确原始源点 | 16 | 16 | 0 | 全部精确，未知RGBA全零 |
| 其余采样 | 180 | 72 | 108 | 全部精确，未知RGBA全零 |
| 合计 | 196 | 88 | 108 | 全部精确，未知RGBA全零 |

108份变化均出现在含部分alpha的导出，最大RGB通道误差为1字节。黑/白背景线性光合成的最大通道误差均为`0.0038060111807822206`，最大RMS为`0.000858452594180879`。这些是实测量化误差，未设为视觉质量通过标准。浏览器canvas域相等不能代替这项原始PNG核验；PNG压缩字节和衍生GLB字节也不要求与原文件相同。

普通纹理延迟请求被研究更新以`AbortError`取消；普通纹理45→研究30→研究导出没有过时`texture_age`→退出恢复45，检查通过。材质/map恢复、模型替换、demo替换、自有texture销毁事件、canvas backing store归零、重复dispose及画布移除均通过。脚本在finally关闭自有浏览器/Vite/资产服务，两个loopback端口复查无监听。未测堆、显存峰值或长时负载。

前端61项测试通过，其中新增纯采样器14项；TypeScript检查与Vite构建通过。此前同批后端完整回归1280项通过，含新增离线BLEND工具17项测试；其后未改Python源码，不重复运行。后端仍有1条既有Starlette/httpx弃用警告。

## 复现与使用限制

从项目根目录运行，使用已安装的本地依赖、研究资产和匹配的冻结源码；输出目录必须是新的，工具拒绝覆盖。当前源码匹配本批21个pin；未来源码变化时应在独立副本恢复[本批源码快照](../output/research/interactive-texture-20261022/source-snapshot)，或另冻结新方案，不改旧计划冒充原实验。首轮18个浏览器pin含旧`viewer.ts`，与本批是两个独立版本。

```powershell
Push-Location frontend
try {
  npm test
  npm run build
} finally { Pop-Location }

$env:AGEMORPH_RESEARCH_DISPLAY_REPORT = Join-Path (Get-Location) 'output/research/blend-display-20261022/atlas-display/report.json'
$env:AGEMORPH_RESEARCH_DISPLAY_REPORT_SHA256 = (Get-FileHash -LiteralPath $env:AGEMORPH_RESEARCH_DISPLAY_REPORT -Algorithm SHA256).Hash.ToLowerInvariant()
$env:AGEMORPH_RESEARCH_DISPLAY_PLAN = Join-Path (Get-Location) 'output/research/interactive-texture-20261022/browser-plan.json'
$env:AGEMORPH_RESEARCH_DISPLAY_OUTPUT = Join-Path (Get-Location) 'output/research/interactive-texture-reproduction/browser'
node frontend/tests/research-texture-display.mjs

.\backend\.venv\Scripts\python.exe output/research/interactive-texture-20261022/audit_raw_export_pngs.py `
  --browser-report output/research/interactive-texture-reproduction/browser/research-texture-browser.json `
  --output output/research/interactive-texture-reproduction/raw-export-png-audit.json
```

滑块验证通过程序设置`range.value`并派发DOM `input`事件，没有测试真实指针拖动或键盘操作；`asBase=true`普通纹理分支仅做源码核查，没有单独浏览器用例。固定相机、软件WebGL和有限开发样例不覆盖所有深度排序、遮挡、接缝、设备或硬件性能；本轮不签收视觉连续性或图像质量。

另查看了Chrome保存的`official-866`和`astronaut`两张研究页截图：滑块与面部纹理可见，模型仍有口部空洞和脸片裁切边界。这只是两张画面的抽查，不能作为纹理完整性或年龄效果签收；其余截图仅核验文件指纹。

静态几何、已有atlas混合、真实年龄变化和身份保持须分别评价。后续按[G3计划](G3分项验收与后续开发计划.md)先补允许用途的资产/评价器、独立数据和预先冻结质量阈值，再决策形状路线与真实SAM→UV服务。当前`/api/aging`仍返回`MODEL_NOT_READY`，全局及结果年龄能力没有开放。
