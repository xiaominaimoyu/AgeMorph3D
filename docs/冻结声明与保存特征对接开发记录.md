## 2. 重放声明与读取范围

先核对 P04 报告/包版本、运行源码、输入 pins、闭合资格标志和相互引用，再复用 P04/P03/K5 的元信息、分组及候选约束重新核对。冻结包必须与原计划、完整 K5、显式 assignments、依据包和报告逐行/汇总相符；有待审、跨用途或身份/派生拆组的包不能进入对接。重放不写新的 P04 输出，不把 consistent 变成实际冻结授权。

K1 闭包仍为保存拟合报告、N0清单、事前冻结记录、N0协议、数据manifest及检测/重建manifest。复用原核心检查身份用途/确定性分组、全校准原照片请求、模型/基/拓扑/顶点、参数维度、图像自有投影/原源坐标、有限系数及保存失败分母。不能通过选少数成功映射绕过 K1 全输入校验，不能额外夹带研究保留组结果。

当前 K1 适配仅支持原校准研究组、FGNET式20—70精确标签和原照片保存拟合。对其他数据/模型需要另有格式适配与用途依据；本工具不把未知/区间年龄转成精确年龄，不把已有校准样本移为 development、train 或 test。

所有读取仍为有界元信息：计划最多512 KiB，单件最多4 MiB，共享读取器最多64份/累计32 MiB。声明中的图片、NPZ、基、参数统计、权重、拓扑和拟合artifact均不打开；其SHA仍是历史声明，`historical_declarations_unread` 保持，不据此证明二进制、真实三维或身份质量。

## 3. 显式映射、失败和数值

不按文件名相似度、ID前缀或年龄猜映射；不同 K5/K1 ID 必须逐行登记。映射覆盖全部 K5 行，不能漏项、乱序、引用不存在 ID 或重复复用同一个 K1 结果。null 是显式无保存结果，不删除该样本。

| 逐行检查 | 不满足时保留的状态 |
|---|---|
| 有明确保存结果映射 | `NO_SAVED_FEATURE_MAPPING`，原未知/区间标签保持 |
| 原照片、无父级派生 | `ORIGINAL_PHOTO_REQUIRED` |
| 原图 path/bytes/SHA 声明、subject、用途分别匹配 | 原图声明、身份或用途不符的稳定错误码，不填身份、不迁移用途 |
| 年龄 kind/value/lower/upper 精确相符 | `AGE_DECLARATION_MISMATCH`；不借 K1 精确标签补未知值或区间中点 |
| 保存拟合成功 | `SOURCE_FIT_FAILED`，另保留原 `source_error_code`，例如 NO_FACE |

输出 K5 原顺序不变，`features.record_indices` 指向本批 records，`feature_row_index` 指向紧凑有效矩阵；K1源行索引及其原记录另存。shape40/expr10/3×4投影原样复制，不重排维度、不标准化、不去身份、失败不补零。投影仅为附属数据，`projection_is_learning_feature=false`，不能当年龄方向；原坐标/尺度不解释为毫米或校准年份，不写入服务 SourceAge。

报告同时保留本批 requested/joined/failed、完整 K1 `source_summary` 和未映射源请求的 ID/状态/错误。即使本批只映射源包子集，源包的失败分母也不缩小。历史 K5 processing/NO_FACE 与新的保存结果对接状态分别记录，不把旧失败改写成成功。

写入前核对全部已读元信息 pin 和九份运行源码。若输入或源码变化，保留完整行及其前一状态/错误、原 K1 错误和 source_summary，撤下全部有效索引与矩阵，报告 inputs_stable=false；不输出仍可误取的本批有效特征。

## 4. 输出及资格

输出只允许新的 `output/research/` 后代，拒绝覆盖、路径越界及链接/reparse。生成一个 `report.json`，包括精确输入 pins、原K5/assignment/映射、K1来源记录、矩阵/索引、binding、原声明审计和完整分母。

退出0表示全请求对接成功且输入稳定；退出1表示有保存失败、无映射、声明不符或末检变化，完整报告仍写出；退出2表示计划/初始pin/P04/K1契约、绑定或输出预算拒绝，不创建输出目录。

本批所有正式数据、训练、生产、服务、独立评价、人工核验、冻结授权和G3标志保持false。`statistics_fitted/standardized/identity_centered=false`；即使出现声明中的 train 用途，也不能由此调用训练或统计拟合。P04官方/人工来源仍为自述，包/报告都不构成正式资格签收。
