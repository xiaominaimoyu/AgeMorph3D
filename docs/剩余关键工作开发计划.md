输入使用现有 `output/research/age-stage3-20261021/` 下已曝光校准原图拟合报告，并绑定N0清单、事前冻结记录、协议、数据与模型manifest；实际入口以开始实施时核对的路径和SHA为准。完整请求集合必须与N0校准用途一致，不能只挑成功或有利样本，不能掺入SAM生成图或研究保留组。N0的`previously_viewed`仅代表2026-10-20的历史状态；本批校准资料后来已用于研究拟合和评分，必须披露。

输出拟为一个版本化JSON数据包，包含：逐请求原图/身份/研究用途/标签及来源、历史曝光、拟合状态与错误、有效特征行索引；有效原生shape40矩阵及expr10/投影附属元数据。形状未标准化、未去身份，投影不作为年龄学习特征；失败的特征索引为空，不填零。标签类型区分exact/interval/unknown，当前FGNET适配只消费其原有文件名精确标签，不能转写服务源龄或将区间中点伪作精确年龄。

输入JSON读取有大小上限、路径限制和前后指纹检查；输出仅进新的忽略目录且拒绝覆盖。模型、图像、NPZ的二进制SHA若本批不读取验证，只能标为历史声明，不能宣称重新验证。输出保持`research_only=true`及`training_use/production_eligible/service_ready/g3_complete=false`，没有开放开关。

验证依次为：合成正常/失败样例与跨组、错基、损坏/篡改、未知/区间标签负例 → 既有70原图请求的只读JSON集成 → 逐行系数/分母/用途复核 → 必要后端回归与静态检查。前端/模型/物理摄像头未改时不重复整套浏览器/设备测试。成功标准是特征数据接口可靠，不是新年龄方向或G3质量通过。
