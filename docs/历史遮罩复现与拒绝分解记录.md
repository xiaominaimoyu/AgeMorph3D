## 构造和归因规则

[mask_replay_probe.py](../tools/mask_replay_probe.py)以保存的目标自有68点连续XY构造候选。多边形坐标使用`np.rint`后转int32；不把每个越界顶点单独夹到边缘，而由固定图像光栅裁剪。拒绝非法维度、非有限/溢出坐标和取整后退化凸包。

| 中间层 | 固定构造 |
|---|---|
| H | 0—26点凸包，`fillConvexPoly`、LINE_8、shift0 |
| E | H经一次9×9全1核腐蚀，中心anchor，常量边界255 |
| M | 60—67点凸包经一次7×7全1核膨胀，中心anchor，常量边界0 |
| base | E且不在M内 |
| B | 审查记录中的半开矩形；只支持本12目标已记录的类型/范围 |
| occluded / allowed | 分别为base与B交集、base减B |

004a63的带起点直接由连续眉点`floor(min(Y17..26))-18`核对，止点固定650；其他8目标必须没有额外排除。凸包用的取整不能提前施加到带阈值，否则部分目标会偏1像素。四个区间仍是`[373,650)`、`[376,650)`、`[370,650)`、`[366,650)`，横向覆盖全宽，但最终候选遮挡只在base内生效。

像素原因按固定优先级形成互斥分区：凸包外、H内且E外的腐蚀环、E内口部排除、base内审查候选带、allowed。它们是候选构造阶段的标签，不是真实物理遮挡或解剖分割。

先比较全部12组旧mask。任一组不一致或失败，所有目标都不得输出已核验UV原因分解。本次全部相等后，才读取已核验对应向量，对原分类5的texel检查四个双线性邻像素，仅精确权重大于0的像素参与。原因位分别为凸包外1、腐蚀2、口部4、候选带8，按位或得到1—15种互斥组合；区域沿用旧四个重叠区域和全域对照，不能将区域相加。

单一texel可跨多个像素阶段。位8对应旧`reviewed_occluder_only`，1—7对应旧`other_ineligible_only`，9—15对应旧`mixed_contributors`。组合数之和必须与原区域mask拒绝数相等，完整requested仍保留其他分类。背面、出图、自遮挡和UV外不被改记成mask效果，未知区没有填补。
