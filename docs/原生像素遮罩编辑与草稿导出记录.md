# 原生像素遮罩编辑与草稿导出记录

更新：2026-10-26。独立编辑页面、灰度遮罩核心和研究会话下载入口已实现；29项新增单测、完整前端203项及构建通过。最终v5冻结运行已在实际Chrome和Edge各通过14项工程检查，保存产物独立复核通过；本结论仅覆盖合成输入的编辑器工程。

本工具制作未提交的研究草稿，不自动注册纹理或授予人工、纹理、身份、年龄、G3及生产资格。原有[只读遮罩工作台](本地遮罩审查工作台开发记录.md)保持只读；真实SAM会话和稳定浏览器研究服务资格另行验收。

## 从当前研究阶段制作遮罩

在项目根目录打开PowerShell，启动已有前端依赖下的本地页面：

```powershell
Set-Location frontend
npm.cmd run dev -- --host 127.0.0.1
```

打开Vite实际打印的本机地址，并进入 `/research/session.html` 或 `/research/mask-editor.html`。端口以终端输出为准；下面流程要求已有可用的独立[研究服务与会话](本机研究会话与HTTP验证记录.md)，不会由编辑器启动模型或服务。

1. 在研究会话页建立或载入源会话，暂存一个明确的整数生成条件。会话页已核对目标PNG原字节和拟合文件指纹后，才启用“下载编辑绑定JSON”和“下载当前目标PNG”。这两个文件属于当前暂存阶段。
2. 打开独立编辑器，选择上述绑定JSON和目标PNG，点击载入核对。编辑器重算PNG的SHA-256并检查1024×1024原生尺寸；起始没有多边形，允许区与遮挡区均为零。
3. 显式选择“允许区”或“遮挡区”，逐点绘制多边形，按Enter或封闭按钮完成；Escape取消未封闭点列，撤销移除最后一个多边形。缩放仅改变显示大小。以当前图像中有观测依据的区域为准，不能把眼镜、未知位置或源图观测自动当作皮肤放行。
4. 填写记录者、显式选择AI或人工来源、观察依据及版本，再准备导出。页面分别提供允许遮罩PNG、遮挡遮罩PNG和草稿JSON三个下载动作；编辑或改变记录后，旧导出准备状态失效。
5. 返回仍有效的当前会话，在原审核流程中手动上传两张PNG，并完整填写原页面所需的记录字段，再显式提交注册。草稿JSON不是 `ReviewInput` 或服务注册回执，不能直接提交，也不能重建已丢失或过期的阶段。

阶段可因TTL或LRU提前失效。离线编辑和导出不会续期；若服务拒绝阶段，需要重新暂存并核对当前图像和指纹，不能只靠相同年龄条件或旧文件名复用审核。该人工操作流程不等于已经完成新的真实SAM会话验证。

## 三项指纹的含义

绑定使用独立版本 `agemorph3d-mask-editor-v1`，保留 `stage_id`、整数 `target_condition` 及三项指纹，不包含会话ID、服务地址或凭证。

| 字段 | 编辑器实际核验范围 |
| --- | --- |
| `source_fingerprint` | 研究源上下文的指纹声明，不是普通源照片文件SHA；离线页面不重新读取源资产验证它 |
| `generated_sha256` | 当前目标PNG原始字节的SHA-256；载入和导出时重算并比对 |
| `fit_sha256` | 当前目标拟合文件的指纹声明；会话下载桥接前已由SDK核对，离线编辑器不读取拟合资产 |

离线绑定不是签名、授权证明或阶段活性证明。源与拟合声明的真实性、当前会话归属及阶段是否仍可注册，最终仍由原研究服务验证。

## 原生像素与导出规则

规则在[协议](mask-editor-v1.json)中明确，当前开发修订号为2。初版协议在实现前保存；契约复核补充了拒绝全图允许区，旧协议快照保留，没有为通过测试自动修改像素。

| 项目 | 当前规则 |
| --- | --- |
| 输入预算 | 绑定JSON非空且不超过16KiB；目标PNG非空且不超过4MiB，1024×1024、8位非交错RGB或RGBA，核CRC、解压预算和原字节SHA |
| 坐标 | 左上角为原点，向右为x、向下为y；顶点在闭区间 `[0,1024]` 内，不按CSS尺寸取整或隐式裁边 |
| 像素覆盖 | 以 `(x+0.5,y+0.5)` 像素中心判定，内部使用奇偶规则；边上使用绝对叉积容差 `1e-9` 和闭线段范围 |
| 几何预算 | 最多64个简单非退化多边形，每个3—128点，总计不超过4096点；拒绝非有限、越界、重复、自交和零面积输入 |
| 三态组合 | 各类多边形先取并集，再从允许区减去遮挡区；遮挡始终优先，绘制顺序不改变该规则，未标注像素在两图中都为零 |
| 输出PNG | 两张1024×1024二值L8、color type 0、8位、非交错PNG，仅有IHDR/IDAT/IEND；像素为0或255、两图互斥 |
| 导出限制 | 不允许空允许区或整张图全部允许；通过显式灰度扫描线编码并回读，Canvas抗锯齿和RGBA导出器不作为遮罩数据 |

草稿包含原生坐标规则、多边形、记录者/来源/方法/版本、像素计数、绑定及两张PNG的SHA、字节数。导出在第一个异步等待前复制调用方状态，后续编辑不会改变已经产生的快照。状态为 `draft_unsubmitted`，即使记录来源选择人工，`human_review_completed` 和全部质量、服务、G3、生产标志仍为false；`research_only` 为true。

## 清除与异步资源

换任一输入、重新载入、载入失败、显式清除或离页会清空当前图像、多边形、未封闭点列、记录字段、遮罩及下载URL。页面不使用localStorage、IndexedDB、cookie、远程图片或自动恢复来保存照片和草稿。

单调变化的操作代次阻止旧解码或压缩结果回填；载入和导出各自限制并发，ImageBitmap及下载URL有明确关闭/撤销路径。会话页的 `clearReview` 同时清除下载用PNG字节并禁用两个桥接按钮。源码与类型检查已核对这些路径；最终真实导航以旧文档独立nonce的HTTP接收事件确认原生URL撤销、ImageBitmap关闭及尾部双空，不以执行上下文销毁代替显式释放。

观察器只向临时loopback接收端发送≤4096字节的封闭合成资源事件。原生API成功返回后才发送，接受入队和服务端实际接收分别记录；旧文档序列必须从1到尾部完整，且撤销/关闭的对象必须与导航前相同。产品请求继续逐项检查为本机GET且不访问服务API，不把受控遥测当作产品照片上传。两浏览器接收端均无拒绝，旧文档尾部URL/bitmap均零，浏览器、上下文、预览和接收服务已关闭；控制台自身仍残留1/1，仅作为观察丢失的对照。

[最终保存产物独立审计](../output/research/mask-editor-20261026/artifact-audit-v5.json)用NumPy稠密射线判定及Pillow/CRC回读核对两浏览器、三缩放、两mask共12张PNG的12,582,912个像素，二值、互斥、未知区、草稿三指纹与导出SHA一致。该数量是重复导出的完整栅格检查，不是独立样本量；审计显式要求最终总报告与每浏览器均passed。研究会话的下载桥接本轮经过源码和类型检查，没有重跑真实SAM会话或替代服务显示的稳定浏览器资格。
