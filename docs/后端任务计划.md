## 3. 环境与最小架构

维持一个回环服务、单 Uvicorn worker、lifespan 管理的单模型实例、事件循环外推理和有界准入。先验证 3DDFA/BFM CPU 最小样例，再测试实际 GPU provider；不得用显卡可见或 provider 列表代替推理成功。算法依赖独立锁定，不修改系统 Python；只有实际依赖冲突或显存隔离需要得到证明后才拆独立算法进程。候选原生环境连续 2 个有效工作日无进展时，记录失败并评估本机 WSL2 路径。

## 5. 已冻结契约与下一批接入

现行 v1.2 已实现健康状态、静态 HTTP 成功路径、资产发布及前端模式；WS 成功推理仍待接入：

- `GET /api/health`：保留 `models/device/version/api_version/capabilities`。严格加载、自检产生模型状态和实际 backend/provider；HTTP 200 只表示服务存活。检测/重建均 ready 才开放 `reconstruction`，年龄/实时仍 false；现有研究清单未达到 ready。
- `POST /api/reconstruct`：保留 `image` 和 `mesh_id/shape/expr/pose/texture_url?`，可选上传 `source_age`；成功必需模式、结果能力、源年龄和拓扑。严格模型对 ready 时返回200静态结果，无人/多人分别422 `NO_FACE`/`MULTI_FACE`；未就绪503，忙/容量不足429。当前真实清单仍因许可返回503，不能以合成服务验证替代。
- `GET /api/assets/{mesh_id}/mesh.glb`：返回对应已发布的 canonical 自包含 GLB；身份/表情已应用，Y-up、正面+Z，bbox高度1、非人体米制标定，新拓扑版本包含绕序变化。当前无 UV/纹理；未登记/过期404，读取租约保留至发送结束，不挂载文件目录。
- `POST /api/aging`：保留 `mesh_id/age` 和现有 `shape_aged/texture_url?` 语义。当前 UI 的操作是纹理生成，成功必须有真实纹理；纯年龄形状随 GLB 交付。源年龄未知或尺度未校准时，不伪造绝对目标年龄。
- 现有前端本地 GLB/PNG 导出保留；服务端 `/api/export/gltf`、`/api/export/image` 不进入首个真实闭环。

请求限制和错误约定延续当前实现与 [api.md](api.md)：JPEG/PNG/WebP、单图片 ≤10 MiB/1600 万像素，multipart 总量/字段限额，真实解码和 MIME 检查，应用层稳定错误码与字符串 `detail`，应用层错误响应对合法 Origin 可读。默认回环、明确本地 Origin、无凭据、Host 与 WS Origin 分别验证。400/413/415/422/429/503/504 的测试通过不能替代成功推理与资产链路。

本轮实测发现的传输边界必须在 B1/G0 收口：Uvicorn 到达连接上限 16 时可在 ASGI 前返回纯文本 503，没有 JSON/CORS/no-store，浏览器现为通用连接失败提示；超过 2 MiB 的 WS 消息由协议层直接以 1009 关闭，没有 JSON 终结 `error`。下一批明确这两层的承诺，验证连接预算与过载可读提示；不能把应用层统一错误说明扩展为所有传输层失败都已统一。详细复现以基础服务验收报告为准。

## 6. 实时、缓存和性能验收要求

WS 客户端仍用 JPEG 二进制、最长边 640、最多 10 FPS、单帧等待。服务端对进入应用的 ≤2 MiB 帧递增 `seq`，每帧只发一条 `face_state` 或 `error` 终结消息；`status` 不算确认。协议层拒绝的超大帧按关闭码另验。`NO_FACE/MULTI_FACE` 接入后是可继续错误，其余严重错误明确关闭。`bbox=[x,y,width,height]`、五点都对应收到的原 JPEG，固定眼中心/眼角、左右和镜像定义；不能把 ROI 坐标直接返回。用 UTF-8 实际编码验证 ≤1024 B，不重复传完整 shape/expr。

HTTP 当前正文接收、图片校验与静态重建共享25秒预算，发布前复查绝对截止时间；WS工作默认6秒。后续根据真实模型测量调整，仍为前端30秒HTTP/8秒单帧等待留出返回时间。慢纹理任务不能阻塞事件循环或积压实时队列。必要时先设计新异步协议，不能静默等待数分钟。

资产已采用进程内不可变字节缓存，默认 TTL1800秒、总量512MiB、128项、单项64MiB。随机不可预测 `mesh_id`；成功等待并检查连接/截止时间/关闭状态后原子发布。读取租约占用容量直至发送结束或异常退出，TTL不因访问延长；空间不足时逐出未固定的 LRU，无法容纳返回429。未知/过期标识404，进程退出清空；不使用任意文件目录、服务临时 GLB 或数据库。原图/裁剪只在有界内存短暂保留。取消后丢弃迟到结果，原生算子实际结束前继续占用工作槽；配置与回归见 B2/B3 记录。
