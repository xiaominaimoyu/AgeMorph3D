## 实现范围

建立 `backend/`：Python 3.11 独立虚拟环境、`pyproject.toml`、`uv.lock`、FastAPI app factory、lifespan、单进程回环启动入口、请求/错误 schema，以及 HTTP/WS 路由。服务当前四项模型为 `missing`，四项能力为 `false`；有效推理请求明确返回未就绪，未引入正式运行的合成结果替身。

图片只接受实际可解码的 JPEG/PNG/WebP，检查格式和 MIME、字节、像素、动画与 EXIF。原始图片保留在受请求大小约束的内存 spool，不保存原图文件。JSON 字段严格校验，错误只返回可读字符串 `detail` 和稳定 `code`。模型资产路由尚不发布文件，不挂载磁盘目录。

HTTP/WS 分别校验 Host 与 Origin，CORS 不开启凭据。中间件超限/超时和 HTTP 500 对合法来源保留 CORS 错误可读性。HTTP 请求正文接收与图片工作线程等待共享25秒预算，WS工作默认6秒。单工作线程无等待队列，忙时429；超时或调用方取消后，槽位直到实际线程完成才释放。WS内的预期及非预期失败均返回一次受1024字节限制的终结错误并关闭，不回显原始异常内容。

前端 `contracts.ts/services.ts/main.ts` 接入 v1.1 健康协议，展示模型 `state/backend/provider/detail`。只有完整且正确类型的能力字段允许操作；旧版或非法协议保持禁用。重新连接时清空旧能力、取消任务和停止实时流，迟到健康结果不能覆盖已经断开的连接。

本批没有修改 `.gitignore`，没有执行 Git 操作，没有下载权重或训练集，没有训练模型。原有前端演示与年龄渲染保留；静态本人重建模式尚未实现。
