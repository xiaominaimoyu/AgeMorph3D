## 4. 非阻断边界与后续处理

1. **连接达到Uvicorn上限时的响应不经过应用。** 正式入口设置`limit_concurrency=16`。16个连接实测触发ASGI之前的纯文本503，不带应用的`detail/code`、CORS或`no-store`。跨端口浏览器可能只能显示通用连接失败，不能保证读取HTTP503说明。该路径安全失败，未造成错误能力启用，作为当前本机单用户阶段的非阻断限制记录。完整G0收口时应明确传输层响应契约、连接预算与前端过载反馈。
2. **超过2 MiB的WS消息由协议层关闭。** 发送2,097,153字节时实际关闭代码为1009，没有JSON终结error，因为帧尚未交给应用。“每帧一条终结回复”只适用于交付给应用的帧，不能把TestClient中的应用层超限测试视为真实协议层行为。后续联调需验证前端对1009的可读提示及恢复。
3. **测试依赖有1条弃用提示。** Starlette当前TestClient提示httpx兼容路径将弃用，现有测试全部通过；没有过滤此警告。下次维护测试依赖时先验证推荐客户端兼容，再更新开发依赖与锁文件，不在本轮验收中无依据升级生产依赖。

以上边界已交给 [后端任务计划](后端任务计划.md) 和 [后续任务清单](后续任务清单.md) 跟踪。本轮没有通过调整测试、放宽校验或假造成功结果消除问题。
