## 3. 输入契约与退出码

预检计划schema为`agemorph3d-training-preflight-v1`，字段精确为：`schema_id, plan_id, draft, manifest, freeze, feature_join_report, reviews, reserve_bytes`。draft/manifest/feature_join_report均采用相对路径、bytes、sha256三项pin；缺少保存特征可用null。freeze为null或`{report: pin, packet: pin}`。若提供P05，必须同时绑定其原始P04报告/冻结包，完整重放并核对准确的K5路径/pin，不能只比较样本数或内容哈希。

当前P05仍只对接既有研究K1，不能借本预检绕过其用途约束形成正式训练特征。合成正例中的“保存特征全成功”只验证元信息对接；真实正式数据及完整特征流程仍未完成。

reviews最多9份，对应`model_purpose,data_purpose,R11,R12,R13,R14,P04_human_freeze,E01_execution_protocol,P06_quality_budget`。每份schema为`agemorph3d-training-entry-review-v1`，字段为`schema_id,gate_id,state,origin,reviewer,scope,evidence`：

- state为pending或recorded；origin为human/official/synthetic/ai/unknown，reviewer为标识或null，evidence为JSON/Markdown pin或null。缺少人类/官方自述、复核者或材料时该入口blocked；重复gate、旧scope、错误哈希和越界文件直接拒绝。
- scope精确绑定draft、manifest、protocol、freeze、feature_join_report五项。更换草案、协议、冻结依据或保存特征后，旧评审材料不能静默复用。`recorded_declaration`只说明材料结构与自述齐全，工具不验证签字者真实身份或许可正文，不授予训练资格。
- 记录R11/R12是原数据入口；记录R13/R14是可行性/欠项，不新增“G3必须成功”的条件。合成和AI材料只能验证契约，不能冒充真实人工依据。

从项目根运行：

```powershell
backend/.venv/Scripts/python.exe -m training.preflight --help
backend/.venv/Scripts/python.exe -m training.preflight `
  --plan output/research/training-preflight-20261030/probe-v1/current-research-plan.json `
  --plan-sha256 <该计划文件当前SHA256> `
  --output-dir output/research/t01-recheck-new-version
```

示例中的输入保存在本机忽略目录，克隆仓库不自带。不要在旧输出目录重跑；先核对计划指纹并使用新版本目录。退出0仅为`declarations_consistent`，不授权训练；退出1为blocked或末检invalidated，仍保存报告；退出2为输入被拒绝，不创建新输出。当前真实和三份合成运行均预期退出1。

只读预算沿用单文件4 MiB、计划512 KiB、最多64份/32 MiB元信息及5000条K5记录；输出只能写新`output/research/`目录，不覆盖、不接受链接/reparse。JSON/Markdown报告各最多4 MiB，并检查reserve与输出空间。输入和12个生产依赖源码末检变化时撤下统计/审计，保留全记录快照和原缺项，追加变化阻断；依赖文件不等于图片/权重二进制完整性。
