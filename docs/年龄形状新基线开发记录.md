## 方法和实现

在新结果产生前写入[协议](age-shape-baseline-v1.json)，冻结21个源码/输入指纹，见[run-freeze-v1.json](../output/research/age-shape-baseline-20261028/run-freeze-v1.json)。协议SHA为`ddade108d7587f326250efea27e1dafa3e4406452d4808bd3a0028e901a459bc`。这70张校准资料及旧N3结果早已用于研究，本轮明确披露曝光；“新协议先冻结”不能把资料重新变成独立盲测。

[数学核心](../preprocessing/age_shape_baseline.py)对同一身份的年龄与原生shape40分别中心化，每个有异龄观测的身份总照片权重为一，拟合：

```text
x_ij = age_ij - mean_age_i
y_ij = shape_ij - mean_shape_i
d(alpha) = sum_i mean_j(x_ij * y_ij)
           / ((1 + alpha) * sum_i mean_j(x_ij^2))
```

这是相对于年龄方差总量的无量纲正则，网格固定为`0、0.1、1、10`。因为只有一个年龄预测量，正则只缩放该40维方向；没有引入复杂非线性方法。各身份年龄跨度仍有不同杠杆，不能称为各身份斜率完全等权。表情和投影不参与学习，原生系数不标准化。

13个有异龄配对的身份做外层留一；每个外层训练集合再按身份留一选择正则强度，并只用该训练集合拟合最终方向、年龄覆盖和位移包络。2个只有单龄照片的身份保留记录，但不贡献斜率或扩大覆盖。原BFM完整方向的标量也按每个外层训练集合重新拟合，未借用全量旧系数。内层各正则、外层三路线均分别记录全部请求、失败与共同有效配对。

几何代理由实际核验的BFM前40维形状基及完整已映射年龄方向组成，通过41×41 Gram矩阵计算原始源canonical框架下的中性几何RMS。它重建的是float64系数几何，不是旧实验保存的float32中性顶点；本轮三路线共用新口径，不把旧报告数字混入比较。BFM有±50原生强度限制；新方向的位移不得超过训练折已观察的最大同人位移，越界拒绝而不裁剪。

[CLI](../tools/age_shape_baseline.py)先从7份原始JSON重建K1数据包，拒绝派生包改系数后重算哈希的情况；再核对BFM基、原年龄方向的二进制SHA及实际顶点/面/关键点顺序。总计读取9份JSON和2份NPZ；不读取照片、研究保留组结果或70份拟合NPZ，不运行检测/重建/SAM模型。输入前后复核，新输出目录拒绝覆盖。

## 实际结果

70个原图请求、15个身份，13个身份提供314个有向异龄请求。每条路线的完整分母均为314；两条变化路线各有10条`OUTSIDE_FOLD_COVERAGE`，主要涉及留出047后训练覆盖上限48而其目标含55岁。共同有效集合为304对，13身份均在。

| 路线 | 全请求 | 成功 | 共同304对的身份宏平均中性RMS |
|---|---:|---:|---:|
| 不变化 | 314 | 314 | 0.006011560283920002 |
| 原BFM方向、折内重拟合尺度 | 314 | 304 | 0.006024243313840702 |
| 身份中心化正则方向 | 314 | 304 | 0.006004725865549050 |

新方向相对静态仅降低约**0.1137%**；这是已曝光校准资料的几何代理比较，不是年龄MAE、真实三维精度、身份准确率或独立泛化收益。改善非常小，没有据此建立新的质量阈值或宣布统计显著性。

全量内层选择`alpha=1`；13外层中12折选择1，留出033的折选择10。各折与全量方向的几何余弦约为0.8632—0.99994，方向一致性诊断为正；不要求40个分量都为正。BFM全量尺度约0.02501143692，但其各折正号诊断仍失败。协议下`exploratory_preference=identity_centered_ridge`仅表示本轮研究候选排序，`production_route_selected=null`、`quality_accepted=false`。

三路线对70个真实系数源的同龄请求共**210次**精确返回原始对象/字节。新方向的20/25/37.5/45/55/58/70及源龄网格共548请求，408成功、140超覆盖拒绝；另以真实系数注入unknown源龄的70次边界请求全部拒绝，这不是70个真实未知源龄受试者。详见[原始源检查](../output/research/age-shape-baseline-20261028/real-anchor-checks.json)。没有生成GLB、打开年龄控件或修改生产处理器的`static_fallback`。
