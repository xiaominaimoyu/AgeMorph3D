## 实现及使用

新增[离线模块](../preprocessing/age_features.py)和[50项合成回归](../backend/tests/test_age_features.py)，仅用Python标准库。`build_feature_dataset`接收已读取的研究元数据并返回独立数据对象；`export_dataset`负责读取绑定的JSON、核对指纹和新目录导出。命令从项目根目录运行，使用已有Python3.11后端环境：

```powershell
& 'backend/.venv/Scripts/python.exe' -B -m preprocessing.age_features `
  --report output/research/age-stage3-20261021/calibration/report.json `
  --report-sha256 ffa395b5c25bf72a1222fc637b91d136da772be6697445e9070c342269fa49c5 `
  --output-dir output/research/age-features-repro-v1
```

`--report-sha256`必须与将要消费的报告一致；输出目录必须不存在，并位于当前工作区的`output/`或`data/`。复现时更换新目录，不覆盖旧结果。元数据输入单份最多8 MiB，研究库存/拟合请求上限5000条；重复JSON键、非有限系数、路径越界、指纹冲突、请求缺失及不匹配的用途/基/拓扑声明均拒绝。输入在写入前后再次核对，末检失败撤销本次结果。

只读JSON闭包为7份：原照片拟合报告、N0清单、事前冻结记录、N0协议、数据manifest、检测与重建manifest。校验N0身份用途及其确定性规则、事前记录、模型ID和权重/基/参数统计声明，以及每条成功拟合的拓扑SHA/顶点数和原始源坐标语义。未打开照片、NPZ、权重、生成图或研究保留组结果；这些二进制的SHA只核对历史声明是否一致，输出明确标记`historical_declarations_unread`，不能当作本轮重新验证了几何或资产内容。

## 数据包接口

输出为`dataset.json`，schema版本1，包含：

| 字段 | 含义 |
|---|---|
| `records` | 完整原图请求，含sample/subject、研究用途、原图声明、研究年龄、曝光史、状态/错误及有效特征行索引 |
| `features.shape` | 有效请求的原生shape40系数；未标准化、未去身份，保留原顺序与精确数值 |
| `features.record_indices` | 每个有效特征行对应的`records`索引；失败的`feature_row_index=null`，不填零、不删除失败请求 |
| `features.expression/projection` | expr10及3×4投影附属数据；投影不作为年龄学习特征，不能将姿态当作年龄方向 |
| `binding` | 模型manifest、基/参数统计声明、拓扑和维度、坐标/参数空间语义及验证范围 |
| `verified_json_inputs` | 本轮实际读取并核对的7个JSON路径、字节数和SHA |
| `summary` | 全部请求/成功/失败/身份数和错误计数 |

`research_age`区分exact/interval/unknown，未知保持空值，区间不生成中点年龄。当前FGNET适配只消费原有20—70整数文件名标签，标记未独立核验，不写入服务SourceAge。N0的`previously_viewed`存为`n0_previously_viewed`历史值；本轮数据另明确`subsequent_research_calibration_exposed=true`，不会将后来已用于校准/评分的资料重新称为盲测。

整个数据包保持`research_only=true`，`training_use/production_eligible/service_ready/g3_complete/years_calibrated/independent_external_evaluation=false`。原研究用途不重划为train/val/test。
