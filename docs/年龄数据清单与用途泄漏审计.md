# K5年龄数据清单与声明级用途审计

日期：2026-10-29。按[剩余计划](剩余关键工作开发计划.md)推进P01/P03/P04的工程前置，新增[标准库核心与CLI](../preprocessing/dataset_manifest.py)、[版本化契约](dataset-manifest-v1.json)及[合成测试](../backend/tests/test_dataset_manifest.py)。本批是年龄数据元信息接口和审计，不包含WIDER框/关键点转换、正式下载、解码、划分、统计拟合或训练；K1的20–70研究特征契约和生产接口均未修改。

## 数据接口与边界

顶层固定`schema_id/schema_version/task/manifest_id/origin/datasets/records`，当前任务为`age_morph_20_70`。`origin`为原始元数据文件的声明指纹或null；数据集记录版本、具体用途登记、身份复核、模型训练重叠和近重复复核。除未收口状态外，每项声明均要求证据文件指纹，但本工具不打开这些证据、核授权真伪或认证观察者。

每条请求保留唯一sample、数据集、图片声明指纹、本地subject、可空跨源关联、父样本、原始/裁剪/生成/渲染类型、用途、年龄及来源、接触史、处理状态和失败原因。字段严格核验，拒绝额外通过标志、重复ID、布尔数值、非有限值、失效/循环父链以及非规范相对路径；失败/排除不从清单删除，也不补零。

| 信息 | 具体语义 |
|---|---|
| 年龄 | 原标签允许有限0–120岁的精确数值或区间；未知三值均null。另行诊断任务20–70范围，范围外/跨界区间仍保留，不取中点或默认45岁 |
| 标签来源 | `filename_research/dataset_annotation/user_statement/unknown`与数值分开；镜像文件名标签不是独立出生记录，也不会写入API源龄 |
| 身份 | subject按数据集命名空间区分；跨数据集同号不自动合并。只有明确提供的`linked_subject_id`连接跨源组，这仍是声明，不能证明实际同人或异人 |
| 派生关系 | 原图没有parent，crop/generated/render要求父记录存在。父子/同身份/显式跨源关联的连通组不能跨已指定用途；不自动修复或重分配 |
| 重复 | 按声明SHA分组，报告跨用途重复、相同SHA大小冲突和同一路径内容冲突。当前未重哈希图片，不能把声明一致称为实际无重复；同用途重复也保留并计数 |
| 接触史 | `preprocessing/model_selection/result_inspection`各自记录yes/no/unknown。声明的正式test中出现yes或unknown会报告；旧`previously_viewed=false`不成为当前未接触证明 |
| 处理 | `not_checked/ok/failed/excluded`，后两者必须有原因。状态是输入声明，schema校验不证明图片可解码或模型成功 |

`development/calibration_research/evaluation_research_holdout`与`train/validation/test/unassigned`分别保留。缺正式三组、用途/身份/近重复资料未齐、训练重叠不清、正式项身份/年龄/处理未核、生成/渲染被当年龄验证真值等均列为具体finding和样本编号。没有样本筛除或阈值选择。

审计只检查调用方提供的清单；不能据此证明未列样本不存在、近重复已经排除或模型训练数据没有同人。完整原始取得台账、独立数据、跨源身份审核与冻结流程仍需补齐。输入SHA绑定本次文件内容，不是对清单作者或法律状态的认证。

## 使用

从项目根目录、现有Python3.11环境运行。下面SHA为本批已核对的旧N0元数据指纹；输出目录必须全新：

```powershell
& 'backend/.venv/Scripts/python.exe' -B -m preprocessing.dataset_manifest `
  --n0-manifest output/research/age-protocol-20261020/verified/manifest.json `
  --sha256 f511c773e8fc3d44ec007d390d1e89be93275df1e4cbf56773a14a79d9d02019 `
  --output-dir output/research/dataset-manifest-n0-reproduction
```

审计已符合新契约的其他清单时改用`--manifest`，显式提供实际SHA，原`origin`声明保留。例如从刚才输出重新核验：

```powershell
$ageManifestFile = 'output/research/dataset-manifest-n0-reproduction/manifest.json'
$ageManifestSha = (Get-FileHash -LiteralPath $ageManifestFile -Algorithm SHA256).Hash.ToLowerInvariant()
& 'backend/.venv/Scripts/python.exe' -B -m preprocessing.dataset_manifest `
  --manifest $ageManifestFile --sha256 $ageManifestSha `
  --output-dir output/research/dataset-manifest-generic-reproduction
```

实际工作须先审阅并冻结清单，再使用相同指纹运行；不要边修改清单边重算指纹冒充同一版。CLI只读所选JSON和本轮生产者源码，不追随图片、模型或其他证据声明。原始数据和生成的manifest/audit留在Git忽略目录。

| 退出码 | 含义 |
|---|---|
| 0 | schema和声明审计完成、无finding；仍不授予正式数据/独立性/训练/服务资格 |
| 1 | 审计报告已完整生成，存在具体finding；本批真实N0和generic复核均预期为1 |
| 2 | 输入无效、SHA错误、格式/预算/路径等失败，不发布本轮报告 |

输入及单份输出JSON均限制16 MiB，最多100000记录/128数据集；拒绝重复键及NaN/Infinity，有界读取，输出在目录创建前检查预算。发布拒绝覆盖，输入/生产者在写入前后复核；失败仅删除本次创建文件，其他文件不删。所有结果`formal_dataset_ready/training_authorized/independent_evaluation/service_ready/production_enabled/g3_complete`始终false。
