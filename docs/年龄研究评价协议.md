# 年龄研究评价协议 v1（N0）

冻结日期：2026-10-20。协议标识 `agemorph3d-age-research-v1`，机器配置为 [age-evaluation-v1.json](age-evaluation-v1.json)。本阶段冻结评价方法、身份用途与同龄对照，不开展生成图重建、路线选择、UV 注册、训练或服务接入。第 2—6 阶段仍按[后续实施计划](FFHQ桥接后的后续实施计划.md)分别验收。

## 1. 使用范围与既往接触

现有 FG-NET 成人清单 `data/datasets/fgnet/adult-20-70.csv` 为 292 张、55 个身份，年龄来自研究镜像文件名，未独立核验出生记录。全部 292 张已参加解码/检测研究，其中 290 张成功图参与过经验关键点对应计算。因此所有身份均记录 `historical_preprocessing_exposed=true`；本协议的保留组只用于后续年龄研究，不能称为从未接触的外部测试，也不能用经验对应后的 NME 证明独立关键点精度。

已人工查看或用于桥接选样的身份 `003/004/005/006/012/013/057/062/067/082` 整体固定为开发组，包括其全部成人照片和今后派生图。原有失败 `013A21`、`067A23` 保留，不通过删除失败或改变检测阈值提高成功率。`official-866`、`astronaut` 只用于开发链路检查，源年龄继续为 `null`，不依据人物身份或外貌猜测年龄。

模型/数据的本地登记继续为 `research-only-unresolved`，本协议不扩大既有研究用途，不证明正式评价或再分发许可。AgeDB 尚未取得；正式独立评价组目前为空。以后取得新数据时，先登记来源、条款和标签证据，完成跨来源身份、精确重复与近重复检查，再冻结用途，之后才能查看评价结果。

## 2. 身份分组规则

统计与划分的单位都是身份。同一身份的所有年龄、原图、裁剪、网格、生成图和纹理继承同一用途，禁止按照片随机拆分。

| 用途 | 冻结规则 | 允许用途 |
|---|---|---|
| `development` | 上述已查看的 10 个 FG-NET 身份；另加两个技术示例 | 实现、观察失败、调试与选择评价方法 |
| `calibration_research` | 其余 45 个身份按 `sha256("agemorph3d-n0-v1:" + subject_id)` 升序排列，取前 15 个 | 后续研究校准和阈值制定，不能用来报告独立测试成绩 |
| `evaluation_research_holdout` | 上述排序的其余 30 个 | 协议和质量阈值补充冻结后的年龄研究比较；披露全量历史预处理接触 |
| 正式独立评价 | 当前 0 个 | 等待符合用途且完成跨来源身份/近重复核验的新数据 |

该划分只使用身份编号和固定种子，不依赖年龄效果、模型成绩或图像观感。离线工具输出全部身份与逐图用途、年龄分布、样本数和哈希。精确字节重复不得跨组；近重复与跨来源身份核验尚未完成，不能以精确哈希校验替代。研究保留组若被用于调参，应撤销其保留用途说明并建立新版协议，不继续称为保留评价。

## 3. 源年龄与同龄对照

严格区分服务 `SourceAge` 和研究标签。镜像年龄放在研究字段，不能冒充用户填龄、独立估计结果或已校准的输出年龄。生产契约仍使用 `value=null, method="unknown", calibration_id=null` 表示未知；未知源龄不开放绝对年龄能力，不补 30/45 岁默认值。

每个有源龄的成功桥接样例保留三种条件：不变换原图、`SAM(s)`（目标条件等于源标签）、`SAM(t)`（其他目标条件）。同龄生成本身可能改变脸型、头发与背景；先测其漂移，再讨论其他目标年龄。20/45/70 是生成器条件，不是生成结果的年龄真值。原照片及其 FFHQ 裁剪都绑定哈希，原图支持 mask 只表示原照片完整取样支持，不表示遮挡已经识别。

| 源样例 | 研究源龄 | 同龄对照 |
|---|---:|---|
| `fgnet-003a38` | 38 | 补生成目标 38 |
| `fgnet-004a63` | 63 | 补生成目标 63 |
| `fgnet-005a35` | 35 | 补生成目标 35 |
| `fgnet-006a55` | 55 | 补生成目标 55 |
| `fgnet-012a27` | 27 | 补生成目标 27 |
| `fgnet-057a25` | 25 | 补生成目标 25 |
| `fgnet-062a45` | 45 | 复用既有目标 45；重新核对输入、权重和输出哈希 |
| `fgnet-082a27` | 27 | 补生成目标 27 |
| `official-866`、`astronaut` | 未知 | 不建立同龄任务；保留原有目标条件图作为技术样例 |
| `fgnet-013a21`、`fgnet-067a23` | 21、23 | 保留 `NO_FACE`；同龄任务阻塞，不伪造成功 |

本次只支持精确整数源标签的同龄条件。遇到小数源龄时保留原值，登记 `FRACTIONAL_SAME_AGE_UNSUPPORTED`；第 5 阶段决定策略之前不得静默取整。所有 SAM 命令显式传 `--target-ages`。补生成沿用既有独立 `data/envs/sam`、同一 checkpoint 和确定性噪声配置，模型进程逐个运行；不改后端环境与服务状态。

## 4. 后续比较与指标

以下冻结计算与报告方法；数值质量门槛尚无依据，保持未制定。不得预填年龄 MAE 或身份余弦阈值，也不得在此阶段宣称 G3 质量通过。取得适当评价器后，先在开发/研究校准组制定门槛、核验用途并登记版本，再补充冻结协议，最后打开研究保留组的年龄结果。

| 分项 | 冻结方法与证据边界 |
|---|---|
| 同龄漂移 | `SAM(s)` 对不变换原图；分别记录图像外观、拟合中性几何、姿态和表情变化；不将它们合并成年龄效应 |
| 真实跨龄 | 同一身份成年照片间不同标签年龄的全部有向配对；相同标签照片只能作重复拍摄/同龄参考；先在身份内部平均，再跨身份等权汇总 |
| 年龄 | 标签来源、目标条件与独立估计分别存储。没有独立获准且经本域检查的评价器时，不报告年龄 MAE/准确率，趋势仅作有来源的定性研究 |
| 身份 | 同人与异人对照，匹配年龄/质量条件；按身份汇总。身份评价器需单独核验，SAM 自身损失模型分数不能直接冒充独立身份准确率 |
| 几何 | 顶点有限性、同拓扑/点序、固定源坐标中的中性几何 RMS 与最大顶点位移；单位为源 canonical 展示单位，不是毫米或三维真值误差 |
| UV | 第 4 阶段记录可见覆盖、未知区、外部遮挡、接缝和 GLB 往返；生成像素与原照片观测区分开 |
| 连续性 | 第 5 阶段检查源龄重置、相邻年龄变化、20/45/70 边界及往返漂移；查看器插值与模型条件连续性分别判断 |
| 性能 | 冷加载、热推理、对齐、重新拟合、UV 和端到端分开记录，研究探针时间不代替服务延迟 |

第 2 阶段起，所有目标和对照统一使用**未变换源网格**的 canonical 中心与缩放；不允许各目标独立归一化或通过逐目标 Procrustes 对齐消除真实差异。主几何比较固定为源/同龄/目标均使用中性表情，原拟合表情系数和姿态另报。保存模型哈希、拓扑哈希、点序和基版本；不一致则报失败。生成图必须使用自己的检测与投影，源图逆矩阵不能直接解释生成图。

两条候选形状路线分别报告：`V_source + fit(SAM(t)) - fit(SAM(s))` 和 `V_source + (f(t)-f(s))*BFM_direction`，此处只冻结对照方法，不选择路线。`f` 尚未校准；3DDFA 拟合属于几何代理，没有真实三维跨龄真值时不能称三维精度验收。

## 5. 统计、失败与版本

各分项先在身份内汇总，再对身份等权取平均，并给出中位数和逐身份分布。95% 不确定区间按身份整组 bootstrap，固定种子 `20261020`、2000 次重采样；不足两个有效身份时不计算区间。该统计尚未执行，不把本阶段清单当作年龄效果报告。

按 `20–29/30–39/40–49/50–59/60–69/70` 报身份、图像和年龄覆盖。现有子集最高 69 岁，没有 70 岁真值；高龄稀疏，不由本子集声称完整 20—70 年龄范围均已校准。多张照片的身份不得支配平均值。

每个请求都保留记录，按失败阶段统计 `BAD_INPUT/HASH_MISMATCH/IDENTITY_CONFLICT/NO_FACE/MULTI_FACE/LANDMARK_INVALID/MODEL_OR_TOPOLOGY_MISMATCH/POSE_OR_EXPRESSION_INVALID/SAM_FAILED/SOURCE_AGE_UNKNOWN/FRACTIONAL_SAME_AGE_UNSUPPORTED/UV_OR_OCCLUSION_FAILED/RESOURCE_FAILED`。成功质量与全请求失败率分别报告，同时列分子/分母；未知源龄和小数条件不适用也单列，不能静默删除。

冻结记录绑定协议文件、成人 CSV、既有桥接与管线报告、原图、模型清单、裁剪、mask、坐标和生成输出的 SHA-256。源文件或配置变化应生成新协议/新输出目录，保留旧结果，不覆盖历史报告。质量评价器和阈值的后续补充也需新版本与生效时间，不可看完保留组结果再修改。

## 6. 复现与阶段出口

在项目根目录运行。该工具仅核查数据、建立清单，不加载模型或执行推理；输出目录必须不存在。

```powershell
.\backend\.venv\Scripts\python.exe tools/age_protocol.py `
  --output-dir output/research/age-protocol-repro `
  --frozen-inputs output/research/age-protocol-20261020/freeze.json `
  --require-controls
```

本轮补同龄输出使用 `tools/sam_probe.py`，每个样例明确传标签年龄，例如：

```powershell
.\data\envs\sam\Scripts\python.exe tools/sam_probe.py `
  --sam-root data/third_party/SAM `
  --checkpoint data/models/sam/sam_ffhq_aging.pt `
  --image output/research/ffhq-bridge-20261020/fgnet-003a38/aligned.png `
  --target-ages 38 `
  --output-dir output/research/age-protocol-20261020/same-age/fgnet-003a38
```

本轮事前冻结记录为 [freeze.json](../output/research/age-protocol-20261020/freeze.json)，在 7 个新增同龄条件推理之前写入；记录协议、成人清单、历史报告和生成脚本的哈希以及身份用途。正式复现需传 `--frozen-inputs`，核对输入与分组仍与事前记录一致；不传此参数只能建立新的开发快照，不能作为本版冻结结果的复验。
