# 年龄评价器保存分数偏差校准

2026-10-27。本轮已实现[离线校准CLI](../tools/age_calibration_probe.py)，完成冻结保存分数运行、独立算术审计和完整后端回归。开发组拟合的唯一加性偏移为 **−3.7323269827128494**；固定用于校准组后，原照片研究标签域的身份均权MAE由5.097降至3.260。历史分数已查看，标签未独立核验；这不是盲测、独立人群准确率或生成/渲染域校准，`years_calibrated=false`，质量阈值仍null，G3与生产能力保持关闭。

## 实现与冻结方法

按[机器协议](age-calibration-v1.json)只读取已保存的MiVOLO报告、旧计划/验证收据、旧评价协议和N0元数据，不打开照片、裁剪、权重或保留组预测，不调用旧模型评价器。源码复用现有身份校准工具中的纯标准库指纹/有界读取助手，该助手也列入已加载源码核验。没有新增依赖，也不修改服务、API SourceAge、查看器或模型配置。

唯一拟合方法在新计算前固定：先在开发组每个有效身份内计算`prediction − 文件名年龄标签`的平均值，再对有效身份等权平均，取负作为offset。它对应身份均权平方误差的常量加性校正，不比较多种方法或用校准组选择参数。校正值为`prediction + offset`，不取整、不裁到20—70；开发组评价明确为样本内，校准组只用该固定offset。

原始与校正结果使用相同有效记录。每个组的all及六年龄段分别报告请求/有效/失败、可评价/有效身份、身份均权MAE和偏差，以及`RMSE = sqrt(mean(各身份MSE))`；不能平均各身份RMSE。加性校正不提供新的年龄形状，也不解决同人预测年龄差或生成条件的真实年龄语义。

## 失败分母与完整性

条件MAE只平均成功样例，失败不填零。另给“全部请求MAE下界”：每身份已知绝对误差之和除该身份全部请求数，再对全部可评价身份等权；全失败身份只在这个下界中贡献0，不进入条件均值。开发组原始/校正下界分别为4.800332/3.721037；因仍有缺失，上界为null。完全无请求时上下界均null，成功完整时上下界相等。

输入预测的绝对值工程拒绝界为1e6，派生offset单独留出标签范围；这是避免异常数值/溢出的工具边界，不是已验证的科学年龄范围，不能据它为缺失误差提供有限上界。

精确输入闭包为六类JSON元数据加CLI、测试及本地标准库助手三份源码，共9项。每次读取和末检均以声明长度加一字节为界；拒绝重复JSON键、非有限数（包括指数溢出）、巨整型、错误换算、输入/计划/运行时漂移。元数据角色在读取前要求JSON，模型和照片路径不会作为后代依赖递归打开。

旧verification必须绑定旧报告和计划；旧计划及报告inputs必须绑定选定协议/N0。工具逐条核对原图与N0的路径、指纹、身份、组别、标签和初末来源检查，保留完整队列。重复/跨组身份、跨组相同图像SHA以及任意角色中匹配保留组路径或SHA的记录均拒绝，包括别名路径伪装的生成记录。这里复验所选历史元数据关联，不声称重做旧图片解码、模型推理或递归核验所有上游产物。

源码加载时的CLI及助手hash与冻结值分别比较。统计、序列化和待发布文件写入后再次检查输入、计划与Python运行时，全部通过才发布新report.json；拒绝已有输出目录，失败不留下成功报告。
