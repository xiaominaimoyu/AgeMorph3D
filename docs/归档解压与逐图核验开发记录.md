| 计划字段 | 约束与用途 |
|---|---|
| `schema_id/plan_id` | 固定 `agemorph3d-archive-preparation-v1` 与有限ASCII标识；严格字段、重复键及计划原始JSON哈希检查 |
| `archive` | 项目相对path、准确bytes/sha256与`format=zip/tar/tar_gz`；仅`data/datasets/`或`output/research/`内的只读文件，最大256 MiB，流式核对完整哈希 |
| `acquisition_receipt` | 准确path/bytes/sha256；须匹配取得工具的成功收据和唯一对应的已校验、只读归档记录。记录一致不判断用途许可 |
| `metadata_manifest` | 准确path/bytes/sha256；通过现有K5契约，最多32条显式图像记录，文件路径须准确指向本次输出的`files/<member>` |

## 2. 归档、图像与K5如何衔接

先完整预检成员，后创建新的 `output/research/` 目录。路径拒绝穿越、绝对路径、反斜线、Windows保留名/非法字符和大小写冲突；文件/目录前缀冲突也拒绝。ZIP在构造标准库成员对象前检查中央目录字节与成员数量；TAR对整个解压流计数，扩展头读取也受上限约束。链接、设备、稀疏和扩展TAR头不进入输出，不恢复归档权限、所有者和时间。ZIP只接受stored/deflate，不支持ZIP64、多磁盘、加密或自解压前缀；TAR只接受基本普通文件/目录，不支持PAX/GNU长名。真实资源如超出这些限制，需根据具体发行包评审适配，不能直接放宽上限来宣称已验证。

不调用 `extractall()`，按原始成员顺序有界流式读取。原始文件先写独立stage，核对实际长度，再以不覆盖的方式发布只读文件，完整SHA-256写入inventory；目录也保留清单行。ZIP的CRC错误及后续单文件失败不会抹掉其他成员，TAR尾部非零数据、gzip尾部校验等同样核对。结构预检失败在创建输出前拒绝；处理开始后的失败保留stage与报告，不自动删除或修补旧证据。

每条K5记录必须精确绑定一个归档普通文件。常见图像扩展的未绑定成员会拒绝；其他未绑定文件只生成字节清单，不宣称已解码。图像实际格式仅接受单帧JPEG/PNG，按真实头部与像素上限检查，先verify再重新打开load；损坏、动画、未知格式/模式、无效方向及超量均逐条登记。32条请求中失败的记录不删除、不填成功像素。解码未运行人脸、身份、年龄、姿态或遮挡模型。

原始字节始终保留在 `files/`，不覆写方向或颜色。另在 `normalized/` 写入RGB/RGBA PNG，保留透明度，不缩放；创建全新图像，去除源EXIF、ICC与文本元信息。转换是确定性工程格式处理，没有完成颜色校准。JPEG到PNG保存的是解码后的像素，原JPEG字节另存；标准化产物不能冒充原始文件。

全部8种EXIF方向输出 `original_to_normalized` 3×3矩阵，定义为原始栅格整数像素中心到方向校正栅格的映射，尺寸交换亦记录。例：2×3原图的方向6得到3×2，矩阵为 `[[0,-1,2],[1,0,0],[0,0,1]]`。本批没有标注转换，后续框/关键点必须据其源坐标定义使用矩阵，不能只旋转图片后沿用旧坐标。[Pillow EXIF API](https://pillow.readthedocs.io/en/stable/reference/ImageOps.html)、[图像校验/加载说明](https://pillow.readthedocs.io/en/stable/reference/Image.html)

`prepared-manifest.json`通过原K5契约：生成派生manifest_id，仅将已进行原始读取/尝试的记录 `exposure.preprocessing` 记为yes；年龄及来源、未知/区间/范围外标签、身份、用途、派生链、原file pin、model_selection/result_inspection和历史processing均保持。标准化文件pin和方向结果另在 `report.json`。历史 `failed/NO_FACE` 即便本次可解码也不改成ok；新坏图则由独立解码结果报告，不能只消费K5副本而忽略本批报告。K5的旧 `binary_integrity_verified=false` 仍是其声明级审计范围；实际字节核对按本报告逐文件/逐图结果判断，不改写旧核心。

`metadata-audit.json`保留用途/独立性等发现。所有正式数据、训练、独立评价、服务、生产与G3标志保持false，`permission_assessment/full_quality_assessment=not_performed`。解码和文件完整性工程通过不授予完整预处理质量。标准库行为核查入口：[Python 3.11 ZIP](https://docs.python.org/3.11/library/zipfile.html)、[TAR](https://docs.python.org/3.11/library/tarfile.html)。
