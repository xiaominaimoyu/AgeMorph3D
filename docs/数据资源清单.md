更新：2026-10-29。对应 D01 / K5；机器可读目录见 [data-resources-v1.json](data-resources-v1.json)。本批完成官方资料调查、用途匹配及取得/存储方案，**D01 整体仍部分完成**：具体用途登记、实际归档版本、精确体积与正式数据准入尚未齐备。没有下载图片、数据压缩包或模型，没有申请密码、正式划分或训练。

## 1. 本轮选定什么

先保留现有 YOLO / 3DDFA / BFM 推理依赖和 FGNET 研究资料；新增资源按任务取得，不为凑齐清单下载全部数据。最低工程组合为：WIDER FACE 检测候选 + AFLW2000-3D 重建评价候选 + 现有 FGNET 已曝光的同人跨龄工程资料。前两者尚未取得，组合也未通过正式数据入口。模型资产按[独立台账](model-assets.md)及[具体缺项](模型资产诊断与严格服务缺项记录.md)核验，不混入数据授权结论。

**正式同人跨龄主训练资源尚未选定。** K2 的同身份相对回归需要可信人物编号及同人不同年龄观测；UTKFace 官网文件名未给人物编号，FFHQ-Aging 是年龄组标签，两者不能直接替换这类训练输入。这是根据资源格式和[当前算法](年龄形状新基线开发记录.md)作出的项目判断；若改做横断面回归或区间任务，必须另冻协议并披露身份与标签限制，不能沿用 K2 的纵向含义。[UTKFace 格式与标注说明](https://susanqq.github.io/UTKFace/)、[FFHQ-Aging README](https://github.com/royorel/FFHQ-Aging-Dataset/blob/master/README.md)

AgeDB 优先核查同人/高龄材料与访问条件，暂为候选。若其进入训练、超参数选择或评价器校准，对应用途不能同时称作外部未见测试；按身份预注册隔离，且核对重建器、生成器和评价器的训练来源。无法核实重叠时明确限制，不能把换了数据源直接写成独立。FGNET 已有历史接触与研究使用，不再作为新外部盲测。

## 4. 存储预算和取得顺序

2026-10-29 15:57:36 +08:00 的 D 盘只读快照为可用 **76,776,435,712 字节，约 71.50 GiB**。预算先保留 **20 GiB** 系统/工作余量，单轮小样派生产物上限暂定 **10 GiB**；两者都是计划约束，没有预分配磁盘，也不是统计质量门槛。扣除这两项后约 41.50 GiB 可供候选的归档、原始、标注和临时解压使用；它不是已确认的可容纳数据规模。

总需求按 `归档 + 解压原始 + 标注/元数据 + 派生结果 + 临时空间 + 预留` 相加。压缩率和图片大小未实测时保留未知，不填 0，不按图片数量直接推断磁盘可行。派生上限包括预处理、缓存和后续渲染；每次新实验仍应单独核算，不挤占已有冻结证据。
