## 4. 工具与重现

实现为 [data_quality.py](../preprocessing/data_quality.py)，回归为 [test_data_quality.py](../backend/tests/test_data_quality.py)。复用K5声明审计、P04/P05/K1校验，未修改已有核心或增加依赖。

```powershell
& 'backend/.venv/Scripts/python.exe' -m preprocessing.data_quality --help
$p06Plan = 'output/research/data-quality-20261029/probe-v1/research-metadata-plan.json'
$p06Sha = (Get-FileHash -LiteralPath $p06Plan -Algorithm SHA256).Hash.ToLowerInvariant()
& 'backend/.venv/Scripts/python.exe' -m preprocessing.data_quality `
  --root . --plan $p06Plan --plan-sha256 $p06Sha `
  --output-dir 'output/research/data-quality-20261029/manual-example-v2'
```

计划schema为 `agemorph3d-data-quality-report-v1`，仅含 `schema_id/plan_id/manifest/feature_join_report/reserve_bytes`。manifest是完整K5 pin；feature_join_report为null时只报清单元信息，不能将未提供解释为0个特征成功/失败。非空时绑定稳定、固定版本的P05报告，并重放完整输入角色/记录/矩阵/双分母；清单必须是P04/P05引用的同一准确快照，拒绝跨cohort混合。

计划最多512 KiB，单件元信息最多4 MiB，最多64份/累计32 MiB，每批清单最多5000行。只读JSON/Markdown/受绑定源码，不读取图片、数组或模型二进制。输出只允许新 `output/research/` 后代，拒绝链接/reparse、越界与覆盖；预留为0—64 GiB整数，另计两份最多各4 MiB的输出。

输出 `report.json` 与 `report.md`，包括完整K5快照/历史和保存错误、精确/区间/未知及范围外分布、用途/身份/曝光声明、原审计发现、可用的保存工程覆盖和显式未测项。Markdown对版本/路径等文本转义。

退出0为 reported，表示工程报告写出，允许包含失败和准入待办；退出1为 invalidated，末检输入或源码变化，撤下statistics及声明审计、Markdown统计表，保留完整历史快照行与变化路径；退出2为初始契约/pin、P05重放、路径或预算拒绝，不创建新输出目录。所有资格标志保持false。
