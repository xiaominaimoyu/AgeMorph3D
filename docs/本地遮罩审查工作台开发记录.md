# 本地遮罩审查工作台开发记录

记录日期：2026-10-24。本批交付12个目标的只读离线审查页面和索引，联动生成图、旧mask、构造阶段、区域及UV/原源canonical对应。第二轮真实Chrome验证12/12目标、100组检查通过；全部原图/数组的独立嵌入审计通过。工作台工程可用，逐图视觉审查和G3质量仍未签收。

## 打开和使用

用本机浏览器打开[工作台索引](../output/research/mask-workbench-20261024/pages/index.html)，选择目标。无需启动服务；每个页面自包含原PNG、标签和坐标，正常操作不访问外部网络。13页共82,130,053字节，单页约6.7—7.1MB；它们含本地研究图像和数组，保留在Git忽略目录。

1. 选择不叠加、旧允许区、旧候选排除带或构造阶段，调整透明度。可切换连续/取整68点、四个重叠区域以及适应窗口/1×/2×显示；缩放只改变显示，不改原生坐标。
2. 点击UV texel查看原七类分区、原生face owner与a/b/c权重、目标投影XYZ、原源canonical XYZ及正权像素贡献。图像点击选择3个原图像素内最近的既有可见UV中心，属于近似查找。UV外/不唯一处显示null并清除旧对应；背面/出图/自遮挡不被解释为mask效果。
3. 填写观察后明确添加当前点快照，填写审查者，再下载JSON。草稿只在当前页面内存，**切换目标或关闭前先下载**；没有自动持久化。下载记录保留来源和数值，但`review_complete`、`human_review_completed`及质量/生产/G3标志始终false，不自动修改mask或触发注册。

目标年龄是既有生成条件，文件名年龄是研究标签；API源龄全部unknown/null。候选带和保守拒绝不是物理遮挡真值，原源canonical是源高度归一坐标，不能当米制或相机标定结果。

## 实现与冻结

[导出器](../tools/mask_review_workbench.py)复用已通过的[mask等价候选](历史遮罩复现与拒绝分解记录.md)，要求全部12目标及独立审计精确关联，再核对旧mask和贡献计数。144个输入与12份相关源码/测试在导出前冻结；每个PNG嵌入原字节，7组向量使用原little-endian C-order字节，float64坐标没有降为float32。分类和阶段以有界RLE保存。

[独立页面模块](../frontend/research/mask-review.mjs)与[模板](../frontend/research/mask-review.html)没有接入生产入口。页面CSP仅授权精确模块SHA，禁止连接和外部资源；JSON中的小于号等已转义，观察文本使用文本节点。页面无需监听端口、fetch、浏览器持久存储或模型推理。下载Blob URL回收、pagehide释放监听和选择状态；切换目标进行整页导航。

导出器在完整输入字节快照上准备全12页，先后核验源码、输入、计划和运行环境。任一目标准备失败就不发布整批页面，漂移使12条请求全部失效并只清理本次创建的页面；旧输出拒绝覆盖。前瞻计划和源码快照先于真实导出，浏览器证据脚本另在实际交互前冻结。

独立脚本未导入项目实现，逐页校验CSP/来源/导航、48个PNG嵌入、84组原向量、12份分类RLE和12份独立重建阶段RLE，全部精确相等。144输入及页面初末无漂移。这证明传输和绑定，不构成遮挡或年龄质量验收。
