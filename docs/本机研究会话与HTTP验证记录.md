# 本机研究会话与HTTP验证记录

更新日期：2026-10-25。按[前瞻服务协议](research-aging-service-v1.json)，独立研究服务已接通已有真实处理器、会话缓存与worker。生产`app.py/runtime.py`、模型资格及G3出口保持。用户提供本人现有照片及拍摄时年龄用于本机验证；确切路径、年龄、原图、生成图、GLB与详细报告只保存在被忽略的本机研究目录，本文不复制个人输入信息。

## 实现与边界

`backend/src/agemorph3d/research_aging_service.py`拥有处理器、已有`AgingSessionCache/Coordinator`、最多四项会话/阶段映射和四个资产发送槽。源构建与目标重拟合共用一个原生处理门，源构建的检测/重建模型仍由调用者拥有。不会为结果再建一份大字节缓存；注册的完整provenance直接返回，GLB按hash绑定它。

公开等待者超时/取消后，实际任务继续持原生门及源租约，直到模型工作真正结束；完成后必须通过关闭、TTL、取消与HTTP断线检查才能发布结果。`PUBLICATION_GUARD`从HTTP请求传入实际写入边界，避免仅在路由等待结束后才检查连接。Coordinator通过无字节复制的缓存委托在`remember`前再检查，原有冻结协调器及缓存未改。

阶段索引使用`(session_id, stage_id)`：两个相同输入会话可能命中同一原生stage，但不能覆盖彼此的明确归属。发送原图或条件资产期间持源租约；发送stage预览/拟合还持原生暂存租约，TTL/LRU不能提前释放仍在发送的字节。关闭拒绝新工作，已有发送继续计费到真实完成/取消，再释放租约。相同条件的重复审核若生成不同结果，返回`409 RESULT_CONFLICT`，不会出现响应称新结果而资产URL仍返回旧结果；完全相同的重试保持幂等。

`backend/src/agemorph3d/research_aging_app.py`只提供`/research`路径，不暴露生产API或OpenAPI/docs。复用本机Host/Origin及私有响应头控制，默认总body12MiB、普通JSON16KiB，每个解码审核PNG4MiB。照片使用原始JPEG/PNG/WebP body和可选严格十进制`source_age`查询，不经multipart临时文件。省略源龄仍unknown，绝对年龄先拒绝unknown；精确源龄返回原始字节，其他小数拒绝。

核心流程是创建会话、请求绝对年龄或整数条件、收到`REVIEW_REQUIRED`后查看新PNG/fit、提交三指纹及显式二值互斥mask、读取已注册资产，随后可请求缓存或源龄重置。健康状态持续标注research，所有生产和质量标志关闭。模型权重和数据许可不会因用户提供本人照片或HTTP通路成功而得到补齐。

## 回归中发现并修复的问题

39项服务与70项HTTP回归覆盖共享原生门、TTL、超时/取消、四槽资产发送、跨会话归属、审核冲突及关闭。测试使用受控合成组件，不声称真实模型结果。

测试先复现Python3.11的`wait_for`与完成/取消同轮调度窗口，精确绑定Coordinator原生wrapper完成回调后，旧路径会在已取消请求中记入成功结果。新服务在真正写入前检查原请求状态。两项实际Service的ASGI回归又复现了返回499后仍`publish/remember`的情况，新增HTTP发布检查后通过；首次红日志和修复后日志分别保留，没有改期望来接受旧行为。

最终完整后端**1945项通过**，保留一条既有Starlette弃用警告；新增源码/测试及真实入口通过显式后端Ruff/格式检查。生产前端没有修改，本批不宣称新增浏览器或连续显示验收。

## 本人输入的真实HTTP运行

真实入口为`tools/research_aging_service_probe.py`：明确输入路径、SHA、用户源龄及目标整数条件，创建新的忽略目录，冻结112输入及backend/SAM环境后，启动临时loopback服务器。用户本人的源龄按`SourceAge.user`记录，不从文件名填充；第二个省略源龄的会话仍为unknown。

首轮在等待审核阶段因执行环境中断丢失句柄。后续操作系统确认探针/SAM进程已不存在，目录没有完整结束报告；仅保留中断观察与产物，不算服务验收。112输入重新核对不变后才重新运行，并使用`--prior-condition-seen`明确该源/条件已查看、属于开发用途。

第二轮26条HTTP检查成功：原源龄重置、非源龄小数拒绝、生成期间新源构建BUSY、缺审核与错拟合指纹拒绝、目标stage命中、审核注册、条件缓存命中、再次原始GLB/纹理恢复、另一个unknown会话拒绝绝对年龄。一次实际SAM生成、一次目标重建，两次源构建（明确源龄与省略源龄各一次）；worker只加载一次。

新目标PNG及保守皮肤多边形叠加已查看，眼、耳/饰物、发际和口部等区域保留不可用。重新运行时仅在源、PNG与完整fit三项指纹完全一致、PNG/fit字节也一致后，才复用已查看mask，并保存原审核记录hash；没有按年龄条件编号套用旧mask。注册得到5,232个已知和60,304个未知texel，未知RGBA全零；原源位置、法线、三角顺序和UV四类访问器不变，年龄形状仍是静态回退。

结束报告确认原生CPU、阶段索引、下载槽、会话entries/bytes/pins/results归零，worker/launcher退出码0，未强制终止，临时服务器结束，112输入和环境初末一致。详细本机证据目录为`output/research/research-service-20261025/real-second/`。

本机`independent-audit-v3.json`通过，重新核对112冻结输入两轮指纹、16份产物、四类GLB访问器、内嵌PNG、完整来源记录/hash和三指纹审核。10处源龄与用户明确输入一致，79处质量/服务/G3标志关闭，5,232已知及60,304未知texel准确。backend41条/SAM13条完整元数据与冻结记录一致；backend条目包含同一editable项目因路径插入而重复发现，不等于41个不同安装包。
