## 1. 最小资源组合与选型

初始最小组合：人脸 YOLO 权重 + 3DDFA_V2 配套 BFM + 合适时获准使用的 BFM 属性 + WIDER FACE + 一个年龄主数据集 + AFLW2000-3D。FG-NET 是外部同人评价候选；FFHQ-Aging、300W-LP、WFLW 按实际问题再引入。

## 2. BFM 属性怎样转成当前年龄 morph

[官方详情页](https://faces.dmi.unibas.ch/bfm/main.php?nav=1-1-0&id=details)给出完整 BFM 的 53,490 顶点、199 主成分和年龄等属性；[官方 MATLAB 示例](https://faces.dmi.unibas.ch/bfm/content/basel_face_model/downloads/public/BFM_matlab_code.zip)将属性加到标准差单位的 PCA 系数后生成网格。当前 3DDFA_V2 的[模型读取实现](https://github.com/cleardusk/3DDFA_V2/blob/master/bfm/bfm.py)采用裁剪基，默认 shape 40、expr 10。数量、基坐标和缩放不能混同。

R05 应验证下列转换，而不是对两个不同维度的数组直接相加：

1. 固定 `topology_id`、顶点序、裁剪索引、三角面、单位、轴向、shape basis 与 UV 哈希；检查参数是原始系数、标准差单位还是训练标准化后的数值。
2. 若确有完整 BFM 到裁剪网格的可靠对应，先把属性方向转换为完整顶点位移，再通过对应裁剪。公式可写作 `dV = PC × diag(EV) × d_attr`，其中 EV 的实际定义以所取得文件为准。
3. 要返回裁剪低维系数时，采用带正则的最小二乘投影并报告相对残差；不能将近似投影写成精确等价。若系数空间不足但顶点对应可靠，可直接保留当前拓扑的顶点 morph。
4. 没有可靠对应时，停用该属性路线，改为在最终形状空间学习方向。完整 BFM、3DDFA 裁剪版本与 FLAME 不能跨基混训。

官方示例的强度系数并不证明物理意义上的“每岁位移”。绝对年龄必须再做源年龄与尺度校准。BFM 模型数据及派生模型/导出是否允许公开分发，应按实际发行条款核验；GitHub 中的代码许可不能代替这项核验。

## 3. 源年龄、回归和无变化检查

建议第一版允许用户可选填写适用范围内的源年龄，内部记录 `value`、`method=user/estimated/unknown` 与估计依据。没有输入也没有经验证的本地估计器时，静态重建可用，绝对目标年龄能力未就绪；不默认为 45 岁。

简单候选在固定形状空间拟合：

```text
min_(b,d) Σ_i q_i ||β_i - b - d(a_i - μ_train)||² + λ ||d||²
β_target = β_input + s d(a_target - a_source)
```

`μ_train`、尺度及数据统计只由训练集拟合；`λ`、强度 `s` 和质量规则由开发/验证流程选择；测试集不参与。`q_i` 只能来自明确的标签/重建质量依据，不根据最终测试表现反向设置。该方法是横断面群体关联方向，拍摄年代、质量、群体和体重等混杂需要报告。

线性可行后可单列改进实验 `β_target = β_input + m(a_target) - m(a_source)`，其中 `m` 是平滑分段曲线；只选择一种主要改进，不在初版堆叠复杂网络。若客户端仅插值三档采样，非线性函数会有近似误差，需确保源年龄处仍保持原始形状，必要时采用一致的分段函数或额外基准校正，不能假定自动满足。

验收至少覆盖：目标等于源年龄时无变化；20/45/70 及边界附近；中间年龄连续；年龄往返不累积漂移；无非有限值/极端位移；法线/光照正确。另测源年龄 ±3、±5、±10 岁的敏感性，避免把锚点误差归因于形变模型本身。

## 4. 年龄标签与身份划分

[FFHQ-Aging 原作者论文](https://www.ohadf.com/papers/OrElSenguptaFriedShechtmanKemelmacherShlizerman_arxiv2020.pdf)的年龄组是 `0–2、3–6、7–9、10–14、15–19、20–29、30–39、40–49、50–69、70+`。严格范围内可用完整的 20—29、30—39、40—49、50—69 组；70+ 无法仅凭该标签筛出恰好 70 岁。70 端点需要其他精细标签校准，或明确其外推限制。

区间标签采用区间/组别任务或独立的代理标签实验；用中点时必须标有噪声的假设，并与区间方案对照，不能在这份数据上把代理误差写成精确实龄 MAE。UTKFace 同样包含年龄标注误差，需保留其来源说明。

优先采用可信 subject 划分；无 subject 的 UTKFace/FFHQ-Aging 使用精确哈希、近重复审查和合法本地身份嵌入辅助分组，仍只能称“候选身份簇隔离”。时间戳或图片序号不视为人物 ID。若要主张严格独立身份泛化，须有可信 subject 的独立测试支持。

可讨论的默认划分为按组 70/15/15，但实际先尊重官方协议，并在小样阶段冻结比例/分层和种子。FG-NET 若作独立外部测试，就不再用同一批样本选择方向或纹理超参数。所有训练增强、同一原图的合成姿态/镜像保留原始分组。

## 5. 指标必须采用什么口径

| 任务 | 建议冻结的协议 | 常见错误与纠正 |
|---|---|---|
| 检测 | [WIDER 原论文](https://arxiv.org/abs/1511.06523)与官方工具的 Easy/Medium/Hard AP；开发划分用于调参，阶段评价与官方测试职责单列 | Ultralytics mAP50–95 不当作 WIDER 官方 AP；官方测试标注不可用时不能写本地已完成官方测试 |
| 五点 | 固定左右定义、眼中心/眼角、鼻尖、嘴角与可见性；单独 NME 和失败率 | 框 AP 不证明点精度；68→5 不随库默认顺序猜测 |
| 重建 | 按[3DDFA_V2 论文](https://guojianzhu.com/assets/pdfs/3162.pdf)或明确实现固定 2D/3D、68 点/稠密、姿态组和 bbox 归一化 | 不笼统引用“约 3%”；组均值与按样本加权值分开；拟合标注不称扫描真值 |
| 年龄 | 独立本地评价器与校准集；逐岁和区间评价分开；固定目标年龄网格 | 训练损失所用年龄器不能单独证明年龄改进；估计器只是代理，不是事实真值 |
| 身份 | 固定对齐、视角、光照、裁剪和图像尺寸；报告分布和年龄权衡 | 余弦相似度不存在可直接套用的统一达标线；阈值应在独立验证集校准 |
| 消融 | 原始重建、属性方向、回归方向、仅形状、仅纹理、组合；有条件加 SAM 二维对照 | 不用未定义的“直接换脸”作为弱对照；同一照片/年龄/视角保持一致 |
| 统计 | 受试者/候选簇为采样单位；预算允许时至少 3 个训练种子；失败率进入报告 | 同一人多个年龄输出不能当多个独立人物；无可靠身份时明确统计限制 |
| 性能 | 冷启动、预热后推理、端到端、纹理、传输、渲染分别计时 | 当前传帧上限 10 FPS，不承诺 30 FPS 参数更新；画布 FPS 与模型推理 FPS 不混报 |

划分、指标、失败计数、模型选择和统计单位写入 E01。开发可反复看验证结果；正式测试配置冻结后再运行，得到负面结果也照实保留。

## 6. SAM 在 8 GB 显存上的验证顺序

这是未知可行性，不能提前宣布能跑。官方的[旧环境文件](https://github.com/yuval-alaluf/SAM/blob/master/environment/sam_env.yaml)包含 Python 3.6、PyTorch 1.6 等配置；本机 Blackwell 需要验证现代框架与自定义算子组合，照抄旧环境不构成有效方案。

先做最小单次：获准照片 + 本地权重 + 单年龄 + batch=1 + 串行调度。测加载/编译、预热后耗时、进程峰值显存和 OOM；让检测/批量重建/训练避免同时占用显存。FP16/AMP 或算子替代要单独验证兼容和输出质量。

重要的源码限制：[SAM psp.py](https://github.com/yuval-alaluf/SAM/blob/master/models/psp.py)是在完整 decoder 后进行池化。`resize_outputs` 或缩小保存图片不能被当作把生成器改成低分辨率、解决 OOM 的证明。需要更小本地模型时，另立来源/兼容/效果验证，不把不同架构加载同一 checkpoint 当等价。

二维年龄结果贴回三维还要重新检测/对齐、建立投影和可见性 mask、确定不可见区保留基础纹理的策略，检查头发/背景污染和接缝。只展示 SAM 结果图并排不算完成 UV 纹理老化。原始基础纹理必须可恢复。

## 7. 对旧规划的修正结论

| 证据 → 发现 | 实施路径 |
|---|---|
| 当前 `viewer.ts/main.ts` → 普通静态网格不能直接走现有年龄加载路径，健康状态也未消费 readiness | R06/R11 增加显式能力和静态模式；现行 v1 契约不在本轮伪称已升级 |

| WIDER/年龄数据协议 → 指标、标签精度与身份条件各有边界 | D/P/E 阶段分别锁定来源、划分和评价；不把噪声年龄或未知身份包装成真值 |
| SAM 模型/环境源码 → 生成输出、显存和 UV 都需独立验证 | R14 先 POC，T05 做质量改进；保留可用基础模型，缺功能写入符合性差距 |
| 用户本轮明确两人、2027 年 6 月交付 → 有真实月份依据，旧学校周次并未因此被确认 | 总规划采用 5 月底内部目标，R01 再核验具体学校节点、份数与工作量要求 |

本轮未验证实时硬件帧率、模型精度、下载成功率或第三方资产授权状态；上述资料支持任务设计，实际结论由对应任务的本地证据给出。
