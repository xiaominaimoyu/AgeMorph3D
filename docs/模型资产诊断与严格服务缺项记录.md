## 使用和报告语义

在项目根目录、使用现有后端Python3.11环境：

```powershell
& 'backend/.venv/Scripts/python.exe' -B -m agemorph3d.model_diagnostics `
  --detector-manifest data/models/yolov5n05-face/manifest.json `
  --reconstructor-manifest data/models/3ddfa-v2/manifest.json
```

也支持原有`AGEMORPH_DETECTOR_MANIFEST`和`AGEMORPH_RECONSTRUCTOR_MANIFEST`环境变量；显式参数优先。没有配置的角色报告`unconfigured`。命令向stdout输出JSON，退出码0只表示两角色的登记、角色和完整性前置条件已满足，仍需严格加载、依赖检查与算子自检；退出码1表示存在具体阻塞。当前两份真实清单的预期结果就是`blocked`/退出1，不是脚本崩溃。

| 字段 | 含义 |
|---|---|
| `manifest_status/manifest_sha256` | 有界清单读取与schema校验、清单指纹；未配置/缺失/无效/超限/检查中变化分别记录 |
| `registered_license_status` | 清单作者当前登记值；不是独立法律授权判断 |
| `backend_matches_role/artifact_roles_match` | 检测/重建后端及各自必需角色是否对应；重建允许可选UV |
| `artifacts` | 每个角色的缺失、非文件、目录外链接、大小/哈希不符、不可读或检查中变化；不因许可未完成而省略完整性检查 |
| `blocking_reasons` | 登记/角色/完整性等全部已发现的阻塞；不能解释为已检查所有依赖和模型质量 |
| `strict_load_preconditions_met` | 本次登记/角色/完整性快照是否满足加载前置条件；不是就绪、加载或自检结果 |
| `grants_service_readiness/operator_selftests_run/model_inference` | 始终false；不观察或修改其他正在运行的服务 |

清单上限64 KiB，资产只按相对角色路径读取、目录包含校验后分块哈希；大小不符可直接报告，读取最多到声明大小+1。读取前后核对文件状态，结束重读清单，变化即撤销前置条件通过。报告不输出原始清单文本、许可自由文本、URL凭证、私有绝对路径或底层异常。结果仅是检查时快照，不预留加载资格。
