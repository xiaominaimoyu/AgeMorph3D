## 3. 每位学生的11类交付材料

审核文档要求按学生分别准备。下表中的`学生姓名`是命名变量，不创建空白占位文件冒充完成；现有组内任务书是来源文件，不等于两套已签收终稿。

| 序号及规定名称 | 需要实际准备和核验的内容 | 当前状态/主责 |
|---|---|---|
| `1_学生姓名_任务书` | 课题/个人任务与正式版本一致，按学院要求签认 | 已有共同来源文件；逐人正式归档待核，A/B各自 |
| `2_学生姓名_开题报告` | 学生、教师、系主任或材料所述认可签认者的真实签名及评审意见 | 模板/素材已有，个人正式稿及签认待完成 |
| `3_学生姓名_中期报告` | 实际进度、教师签名与评审意见；材料提出意见尽量4—5行 | 个人正式稿待完成，不复制示例评语当作真实意见 |
| `4_学生姓名_工作过程记录本` | 按实际提交/审核先后记录，无空白页；审核“通过/同意”等须由真实审核形成，末次在答辩前 | 从现在持续积累；不在最后一天倒填或伪造日期，A/B各自 |
| `5_学生姓名_毕业设计指导教师评阅表` | 真实教师意见与电子签名，时间依实际流程 | 待教师评阅，学生只准备材料 |
| `6_学生姓名_毕业设计评阅人评阅表` | 时间晚于指导教师评阅表，真实评阅意见与签名 | 待实际评阅 |
| `7_学生姓名_毕业设计答辩评审表` | 答辩组、系主任签名及真实答辩记录；时间晚于评阅人表 | 待实际答辩。若记录单列，按文档改为`7-1_学生姓名_毕业设计答辩评审表`及`7-2_学生姓名_毕业设计答辩记录` |

审核材料还要求电子签名、按标准格式准备而非直接系统导出、电子修改后同步替换纸质袋、核实终稿和原创性声明，并能在30分钟内提供电子材料。这些是交付检查项，不代表现在已经签署、打印或提交。

实际流程顺序为：工作过程记录审核 → 指导教师评阅 → 评阅人评阅 → 答辩评阅。说明书和查重终稿依材料要求在答辩后收口；不能把预答辩草稿时间当作答辩后终稿时间。
