# 源与目标UV联合支持诊断

2026-10-25。已完成三个既有开发源、12个目标、旧版与保守版共24条保存数组诊断。它量化同一UV位置的源/目标可用性，不改颜色、不填未知区，也不将原始源观测当作目标观测。重点源的保守目标仍缺少约76%—77%的源已有观测位置，眼区没有恢复；该结果不是NO_FACE因果证明或纹理质量签收。

## 如何复现与核对

[前瞻协议](joint-uv-support-v1.json)固定四种状态：源与目标都已知、仅源已知、仅目标已知、两者都未知。已知只指现有RGBA的alpha=255；原始源可能含眼镜、遮挡或光照，不是已验证的干净皮肤。API源龄仍为unknown，文件名年龄只作研究标签。

[CLI](../tools/joint_uv_support_probe.py)读取五份协议/报告、三个原始atlas、24份目标samples NPZ和12份旧对应NPZ；同路径去重后39份二进制、52个总输入。输入在新统计前固定hash，并保存八份源码/协议快照和环境。[冻结清单](../output/research/joint-support-20261025/freeze-v1.json)、[运行计划](../output/research/joint-support-20261025/study-plan-v1.json)及[完整结果](../output/research/joint-support-20261025/evaluation/report.json)只保留本机忽略目录。首次真实执行24/24通过，输出只有JSON，没有读取原照片、完整生成图、权重、GLB或保留组评分。

在具备这些既有本机冻结输入的项目根目录，可用新输出目录复算；已有目录会拒绝覆盖：

```powershell
& '.\backend\.venv\Scripts\python.exe' '.\tools\joint_uv_support_probe.py' `
  --root '.' `
  --study-plan 'output/research/joint-support-20261025/study-plan-v1.json' `
  --output-dir 'output/research/joint-support-20261025/replay-local'
```

每条记录保留全atlas、保存的唯一对应域、双眼/鼻/口共六个区域。每区域四态计数相加等于该区域分母，每态七类目标原因相加等于该态计数；两个比例分别用局部源已知和区域总数作分母，零分母保留null。四个目标拟合区域可能重叠，不能相加当作不重叠全脸。

本轮核对保存row/column与旧classification≥2的域、两版UV数组及元数据hash、原始源框元数据、目标自有projection/ROI不变；没有重栅格或重新证明几何、GLB、相机投影。旧区域/全图七类计数逐项匹配原UV报告。协议前曾为schema检查打开一份已审计旧对应NPZ，只查看名称、shape和dtype，未计算联合支持；既有mask、渲染失败及开发观察均已披露，不称盲测。

保守候选总共增加1196/1154/1269/1347个目标支持点，但仅源已知分别减少1196/1154/1267/1346；两种统计不应混为一谈。条件63和70分别另增加2和1个源原本未知位置的目标支持，说明两个支持集合也不完全包含。

四条件的左/右眼“仅源已知”分别为466/480、453/464、451/468、457/474，保守版均与旧版相同；这些保存目标眼区原有源观测全部仍无目标支持。其源内容可能包括眼镜；该数值不授权复制眼镜/源颜色，也不是独立解剖或遮挡标签。

在保存唯一对应域内，保守四目标的“仅源已知”中，31859/31621/31714/31625个分别归入目标mask拒绝，其余为背向或自遮挡；不是测得的真实外部遮挡面积。另两个对照源的旧版“仅源已知/源已知”分别为47.08%—47.80%和49.07%—49.43%，保守版八条记录不变。缺口并非重点源独有，也不能由这些交集独立解释渲染检测失败。

## 验证与后续出口

[35项合成测试](../backend/tests/test_joint_uv_support_probe.py)覆盖四态/重叠分母、非法alpha/非零未知、分区不一致、NPZ分配前边界、元数据绑定、额外输入拒绝、导入源码错位、已有输出保护和末检漂移；完整后端1983项通过，保留一条既有Starlette/httpx警告，Ruff及格式通过。末检每文件最多读取声明长度加1字节，异常膨胀立即拒绝；错误输入整批拒绝，不发布成功子集。

[独立保存数组审计](../output/research/joint-support-20261025/review/independent-audit-v1.json)不导入项目实现，以独立ZIP/NPY解析和计数复算4032个状态/原因单元、288个比例及12组完整差分，全部无差异；52输入、计划/冻结/报告及八快照两轮一致，错误计数和错误hash负控制均检出。它核验保存结果，不重跑模型、投影或独立质量评价。

独立审计首轮在解码前因分发元数据行数不等停止，失败收据保留。原因是生成器导入helper后增加`backend/src`搜索路径，同一editable项目元数据出现重复；38个唯一name/version组合相同。随后不导入helper，按已读生成器路径行为枚举，40行前后完全一致。该更正不涉及结果、分组、输入hash或包版本变更。前端源码没有本批改动，不把此前174项或固定Canary12帧当作本批新运行。

现行[UV未知区规则](uv-registration-v1.json)和[研究处理器规则](research-aging-pipeline-v1.json)明确禁止填色/跨未知补混合；本轮没有引入源回退或更改mask。新的支持修正需要另立有明确观测来源和视觉审查的协议，不能把这份交集表当作可用纹理。后续继续纹理支持、身份/年龄本域校准、独立数据/许可和原稳定浏览器出口；年龄形状、G3、生产和全部质量资格仍未完成。没有Git提交或推送。
