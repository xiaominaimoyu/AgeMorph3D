# 研究年龄处理器与真实生成闭环

本批按[前瞻协议](research-aging-pipeline-v1.json)补独立 `SessionSource/Processor`，服务入口与生产模型就绪逻辑保持。SAM 条件研究可以使用未知源龄；绝对年龄会话仍在缓存及生成之前返回 `SOURCE_AGE_REQUIRED`。文件名中的年龄只属于已查看的开发数据标签，不能填成用户提供的源龄。

实现位于 `backend/src/agemorph3d/research_aging_pipeline.py`。`prepare_source_context` 接收已校验的 `SourceAge`、完整原始拟合、68点坐标地址、共同UV和四项资产指纹，生成有界JSON/base64上下文及原始GLB/纹理。解码限定dtype、shape、长度、拓扑与像素；不使用pickle或压缩归档。

`stage_condition` 只接受20—70整数，使用常驻worker生成1024图，再在该图重新检测和重建。暂存只保存有界不可变字节，默认64MiB、4项、300秒；单项16MiB，注入缓存必须满足预算并匹配索引容量。相同源指纹和条件命中尚未过期的暂存，不再次生成或拟合。

`preview_staged` 提供新PNG、完整拟合字节和该目标自己的68点。`register_reviewed` 要求审核记录同时匹配源、PNG、拟合的三项指纹，遮罩必须为原生1024尺寸、互斥的二值L PNG。缺审核或错配返回 `REVIEW_REQUIRED`，不产生会话结果，也不自动采用旧条件mask。注册采样使用目标自己的投影/ROI/表情；网格和shape仍来自原始源，未知RGBA保持全零，年龄形状路线仍为 `static_fallback`。

单次准入覆盖SAM和CPU拟合/注册；取消等待会排空原生工作，源租约在实际结束后释放。注册原生阶段结束后重新检查TTL和关闭状态，拒绝迟到成功。关闭等待者取消不取消实际清理，worker退出后才释放设备占用。确切已知源龄（包括42.5）先恢复原始字节，其它小数仍拒绝；这项目前由合成输入验证，不把未知源龄的真实条件研究宣称为已知源龄实测。

首轮测试保留于 `output/research/research-processor-20261024/targeted-initial.log`：测试传dict与实现要求校验对象不一致，修正测试接口后继续。独立审查复现并修复关闭期间源龄恢复仍返回成功、取消被后续原生失败覆盖两项竞态；回归也覆盖预算不匹配、租约满容量、重复JSON键、巨大数组声明和真实stdio合成进程超时。合成stdio不等于真实SAM。

真实入口为 `tools/research_aging_pipeline_probe.py`，冻结开发源 `fgnet-006a55` 和共同UV实际SHA，再加载独立CPU检测/重建器与独立CUDA SAM worker。运行后保留新PNG并等待最多180秒的明确审核文件。记录缺审核拒绝、暂存命中、原源几何访问器、未知区、未知绝对年龄缓存拒绝，以及实际进程退出。TTL采用明确的受控时钟偏移，不能写成已等待301秒。

本批首个真实入口在模型加载前因旧保护快照与当前README/忽略文件不同而停止，失败报告保留于 `real-first/report.json`。当前文件已有另一工作流程的交接记录；本轮冻结当前内容并记录与旧快照的差异，不改写或回滚它们。真实研究结果、初末指纹与资源状态在本页后续补实测记录。

第二轮完成真实CUDA SAM生成、目标重建、暂存命中和缺审核拒绝，但首次审核注册返回 `REGISTRATION_FAILED`。保存图/完整拟合的直接复现表明，worker完整ready元数据使GLB重复的scene/root extras超过既有16KiB预算。修复没有扩大导出限制：完整记录保存在返回的 `provenance_json`，GLB嵌入完整记录及worker记录的SHA，并保留PID、加载次数及研究语义。4KiB/20KiB合成ready说明的回归确认完整记录未丢失、两处嵌入哈希一致且GLB仍小于预算。失败报告及底层栈均留存，第二轮实际worker正常退出，105输入和环境初末一致。
