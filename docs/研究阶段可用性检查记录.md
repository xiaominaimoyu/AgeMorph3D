# 研究阶段可用性检查记录

2026-10-28。研究会话页新增“检查待审核阶段”，可在继续标注或提交前显式查询当前阶段是否仍存在。新GET只返回绑定和可用性快照，不下载图像、解码暂存数据、重算源图像指纹、运行模型、续期或保留提交名额。后端2175项、前端292项、类型检查/构建及Ruff通过；Chrome/Edge最终各12项合成操作通过。检查成功不等于后续一定能提交，注册仍按原流程权威复核。

## 接口与操作

按[机器协议](research-stage-availability-v1.json)新增隔离研究接口：

```text
GET /research/sessions/{sid}/stages/{stageid}/status
```

成功返回`status=available`、既有staged五字段和归属正确的preview/fit URL，以及`ttl_extended=false`、`reservation_held=false`和原研究关闭标志。不存在、过期或跨会话阶段走原`STAGE_EXPIRED`；源会话无效走`SESSION_EXPIRED`，错误仍经既有本机中间件安全封装，响应保持no-store。生产app、生产年龄API和模型配置没有新增接线。

在[研究会话页](../frontend/research/session.html)已有待审核目标时点击按钮。没有定时查询，导入草稿也不会自动检查；成功提示“上次检查时阶段可用”，明确不续期、不保留提交名额。阶段过期清当前预览、文件及导入资格，仍保留有效源；源会话过期则按原路径清源。其他错误显示“未核实”，不沿用旧可用提示。检查超时采用专用文字，不误报后台模型仍在运行。

SDK使用原按chunk计数的读取器，响应预算16KiB、超时10秒，核全部五项绑定、整数条件、归属URL、不续期/无保留声明和关闭标志。通过[旧SDK快照对照](../output/research/stage-availability-20261028/bounded-reader-preservation-v1.json)确认：移除唯一新增checkStage方法后，其余SDK文本相同；没有采用已证伪的原生arrayBuffer兼容候选或降低字节边界。

## 缓存与生命周期

[共享AssetCache](../backend/src/agemorph3d/asset_cache.py)仅增加`contains_current`：在原锁下查ID和发布截止时间，允许清理已过期且无租约的项；不复制/读取payload、不取得stage租约、不移动stage缓存LRU、不延长TTL。即使旧下载还持有已过期数据，检查也必须拒绝；原租约继续承担保留字节，直到原持有者释放。原publish/acquire行为不变。

[处理器](../backend/src/agemorph3d/research_aging_pipeline.py)只查该存储状态。[服务](../backend/src/agemorph3d/research_aging_service.py)先核活跃源会话和自身`(session_id, stage_id)`绑定，再查暂存；只临时持有并释放源租约，不占下载槽或原生任务，不重算整个源的字节指纹。此检查不重新证明图像/拟合内容完整性、审核正确或未来可用，不返回资格或预留权利。

[页面](../frontend/research/session.ts)仍用原operation generation和当前stage/session身份阻止旧完成；换条件、换源、清除、取消或离页使未完成查询失效。查询成功不改变已导入草稿和注册按钮的原资格；真正提交仍会再次检查TTL、会话、三指纹和审核遮罩。
