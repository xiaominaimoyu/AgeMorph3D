## 运行方式

使用项目现有Node22.18+、frontend依赖及本机安装的Chrome/Edge；脚本不会安装或更新浏览器、依赖、代理、证书或模型。以下在项目根执行，三个目标路径必须为新路径：

```powershell
& 'D:/JAVA run tools/node.exe' frontend/tests/research-stream-browser.mjs --prepare `
  --output-dir output/research/stream-recheck-reproduction/fixtures
& 'D:/JAVA run tools/node.exe' frontend/tests/research-stream-browser.mjs --freeze `
  --fixtures output/research/stream-recheck-reproduction/fixtures/fixtures.json `
  --plan output/research/stream-recheck-reproduction/plan.json
& 'D:/JAVA run tools/node.exe' frontend/tests/research-stream-browser.mjs --run `
  --plan output/research/stream-recheck-reproduction/plan.json `
  --output-dir output/research/stream-recheck-reproduction/run
```

可用PATH中的`node`替换本机Node路径。freeze默认寻找Windows、Linux、macOS常见的安装路径；其他位置须显式传入`--chrome-executable`及`--edge-executable`。不支持的安装路径会拒绝，不自动下载浏览器。输出只能位于`output/research/`内，拒绝覆盖；普通`npm test`仅运行判定器单测，不自动拉起本脚本。

| 退出码 | 含义 |
| --- | --- |
| 0 | 本次完整合成传输检查通过，仍须另行冻结真实服务及普通图形批次 |
| 1 | 观察完整，但至少一项传输或预期拒绝条件未达标 |
| 2 | 计划/指纹/输出路径不符，或诊断观察、运行与清理不完整；须查看错误或report |

## 检查内容

[协议](research-stream-recheck-v1.json)冻结单写4次、分写4次正向，以及声明超预算、无长度实际超预算、有效前缀后累计超预算、错误媒体、空体、截断、超时、首次读取后主动取消、404研究错误九类负例。合成body为131072字节，正向预算262144、普通负例预算1024；错误响应继续使用SDK原JSON预算。

[运行脚本](../frontend/tests/research-stream-browser.mjs)通过Vite导入当前SDK，在JavaScript中显式调用其内部`bytes`方法；测试的是实际有界读取算法，不是完整公开API或产品页面。正向不替换reader，也不使用原生arrayBuffer、clone、tee、缓存策略变更或定时客户端规避。Node HTTP/1本机服务始终返回no-store；分写正向仅在服务器两次写入间隔20ms，以形成可复验分段响应。

前缀三例在首次实际读取512字节后，才通过测试专用binding通知服务。累计超限例此时发送余体；超时/取消例一直不发余体。这些负例有明确标注的reader观察包装；正向没有此包装。预算仅指应用保留/发布payload，不能推论浏览器内部缓冲或进程RSS有同样上限。

每个唯一请求同时保存服务写入/finish/close、SDK结果、Playwright原请求终态及CDP原请求终态。在关闭context/browser之前收齐，缺失、重复、错归属、终态或错误文本不一致均不能通过；另核实际HTTP/1.1、no-store和关键负例framing。正确payload不豁免原始网络失败，负例原始失败也完整保存。

freeze固定27份来源/配置/依赖元数据、1份合成body、Node和两个浏览器执行文件；run保存来源快照，清理后再核指纹。执行文件pin不等于完整浏览器安装目录或全部DLL证明，依赖元数据也不等于逐字节冻结整个node_modules。运行有单请求宿主观察截止，计划缺源、错误hash、改预算、开放生产标志、错误runtime及输出冲突都在起服务前拒绝。
