# 遮罩编辑器草稿回读记录

2026-10-28。[原生像素编辑器](../frontend/research/mask-editor.html)现可显式回读已导出的草稿及两张遮罩，恢复原生多边形和研究记录，继续撤销、补画及重新导出。当前目标图须先通过原绑定/PNG核验；回读不自动加载文件、准备导出、下载、注册或续期，来源声明不提升人工质量资格。

## 用法与实现

先在编辑器选择会话导出的绑定JSON和目标PNG，按“核对并载入”。展开“回读已导出草稿，继续修改”，选择草稿JSON、配套允许区PNG及遮挡区PNG，再按“清除当前标注并核对回读”。这次显式替换会清除当前多边形、未封闭点列、记录和下载资格，但保留目标图；全部核验成功后才恢复标注。

仅选择文件不会自动应用草稿。恢复后仍要按“核对并准备导出快照”，分别下载三文件，再回研究会话显式核对/提交。失败时画区和记录为空，当前图仍可查看；没有自动修像素或把失败草稿与旧记录混用。

[新协议](mask-editor-resume-v1.json)复用[三文件严格核验](mask-draft-import-v1.json)，[旧导出协议](mask-editor-v1.json)及格式未改。[核心返回值](../frontend/src/research-mask-draft.ts)只增加自有`polygons`字段：通过既有几何验证后，在第一次await前复制每个点。旧消费者的review、PNG、计数语义保持；返回对象没有质量或注册资格字段。

JSON仍限512KiB UTF8/深度32，每PNG限4MiB，原生1024×1024、64区域/每区128点/总4096点。阶段ID、条件、三指纹、目标PNG、两mask原SHA/长度、严格L8解码、重栅格像素及计数均须相同。压缩字节不重编码比较，未知区和遮挡优先语义保持。

[页面实现](../frontend/research/mask-editor.ts)使用单调epoch和当前回读所有权：换文件、清除、换当前目标或离页使旧任务失效，旧finally不能清除新任务状态。回读期间禁用标注/记录/导出控件，同时阻止Canvas事件；文件选择与清除仍可取消旧任务。成功同步恢复多边形、叠加、记录和计数，下载保持禁用，直到重新准备快照。没有localStorage、IndexedDB、cookie、远程上传或自动恢复。

## 本机复现与后续

从项目根运行，依赖现有Node/frontend依赖和安装版Chrome/Edge。每个输出路径必须不存在；命令会启动浏览器和自有loopback页面/探针。

```powershell
& 'D:/JAVA run tools/node.exe' frontend/tests/mask-editor-resume-browser.mjs --prepare `
  --output-dir output/research/mask-editor-resume-reproduction/fixtures
& 'D:/JAVA run tools/node.exe' frontend/tests/mask-editor-resume-browser.mjs --freeze `
  --fixtures output/research/mask-editor-resume-reproduction/fixtures/browser-fixtures.json `
  --plan output/research/mask-editor-resume-reproduction/plan.json
& 'D:/JAVA run tools/node.exe' frontend/tests/mask-editor-resume-browser.mjs --run `
  --plan output/research/mask-editor-resume-reproduction/plan.json `
  --output-dir output/research/mask-editor-resume-reproduction/run
```

本批没有失败测试或失败浏览器重跑。已有历史失败和冻结产物不覆盖，旧导出格式保持。真正人工mask/外观复核、合格观测支持、外部独立/高龄数据、训练重叠、许可、年龄形状及稳定浏览器真实服务出口仍待完成。G3与生产关闭，本轮不执行Git。
