# 遮罩草稿回导与会话核验记录

2026-10-28收口，开发批次于10月27日启动。已在独立研究会话页增加草稿JSON和两张遮罩的显式本地核对，成功后一次性回填研究记录，仍须另按“提交审核并注册纹理”。新增72项、完整前端275项、类型检查和构建通过；Chrome/Edge各17项合成操作通过，4,194,304个实际提交遮罩像素独立复算差0。不运行模型，不授予人工、真实服务或G3质量资格。

## 操作与实现

原编辑器能导出绑定草稿及两张L8 PNG，会话页却只能手选遮罩、手填记录，不能核三文件是否配套。[新协议](mask-draft-import-v1.json)及[校验模块](../frontend/src/research-mask-draft.ts)补齐交接；[旧协议](mask-editor-v1.json)与编辑器导出格式保持不变。显式选文件再核对，不自动加载或恢复历史草稿。

在[研究会话页](../frontend/research/session.html)暂存目标后，选择允许区PNG、遮挡区PNG及草稿JSON，再点“本地核对草稿与两张遮罩”。成功后显示三态计数并填写记录者、来源、方法和版本；核对不发送服务请求、不续期。选中草稿但未核对时不能提交；“移除草稿，改为手动填写”清空导入记录，保留两张mask供原手动流程使用。

`reviewer_kind=human`仅保留来源声明，不证明人工操作或质量正确。本轮human记录明确为合成声明，全部质量、服务、生产与G3标志仍false。阶段TTL和会话归属仍由随后显式提交时的原服务权威核验。

| 核验项 | 规则 |
| --- | --- |
| 预算 | 非空JSON的UTF8不超过512KiB、深度最多32；目标和每张mask各不超过4MiB。文件读取前和核心复制/异步前分别核预算 |
| JSON/绑定 | 拒绝重复键及转义别名、额外/缺失字段、错误状态/坐标/关闭标志、记录与计数；当前stage_id、条件及三指纹逐字段相同，再核目标PNG |
| PNG | 核上传原字节长度/SHA、CRC、块顺序、1024×1024、非交错8位L8、解压长度及二值像素；新增有界解码支持过滤器0—4 |
| 像素 | 按既有原生中心点及遮挡优先规则重栅格，与两图逐像素相同，计数和未知区一致；拒绝空允许区及全图放行 |
| 压缩 | 解码原始PNG后比较像素，不要求重新deflate产生相同字节；接受与草稿原字节声明匹配的不同压缩编码 |
| 原子性 | 成功才发布全部记录与自有字节，失败不留半填字段或旧导入资格，可保留有效源/阶段 |
| 生命周期 | generation、独立epoch、阶段/目标/File身份在发布前复核；换文件清导入字段，改记录使核对失效，换源/阶段/条件、取消、过期、离页清导入资格 |
| 注册 | 使用已验证字节新建File，不重读所选磁盘File；异步mask预检后、POST前再核当前导入身份，过时操作拒绝发送 |

独立源码审查发现注册前的异步窗口：提交后的mask解码期间，迟到change可使导入失效而旧快照仍发送。已在首次浏览器冻结前补`ensureCurrent`及导入身份末检；真实延迟测试确认变化后无POST。取消旧File读取后再导入，新记录也不会被旧完成覆盖。

& 'D:/JAVA run tools/node.exe' frontend/tests/mask-draft-import-browser.mjs --freeze `
  --fixtures output/research/mask-draft-import-reproduction/fixtures/browser-fixtures.json `
  --plan output/research/mask-draft-import-reproduction/plan.json

  --plan output/research/mask-draft-import-reproduction/plan.json `
