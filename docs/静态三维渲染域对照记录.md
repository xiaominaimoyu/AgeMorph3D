# 静态三维渲染域对照记录

2026年10月23日，本批在实际查看器中捕获了10份原始静态模型和37份SAM注册纹理模型，共376帧，形成296组目标与同源静态基线的配对。身份和年龄各218帧有效、158帧NO_FACE，145组成对评分有效。完整分项G3、年龄形状、真实年龄精度、身份质量和生产能力仍未签收；本批只研究固定几何上纹理、覆盖、材质、背景和视角对评价的影响。

前一批[真实年龄域诊断](年龄评价器真实域诊断记录.md)用原始源照片作为条件偏差基线。它没有测量从照片到三维渲染的域变化，因此不能代替本批完整静态3D基线。

## 范围与前瞻冻结

依据[渲染域协议](render-domain-v1.json)，仅复用已查看的10个开发源及其37份N4注册目标，不生成新SAM图，不重新拟合，不打开保留组模型输出。10份资产的API源龄全部保持`unknown/null`；其中8个文件名研究年龄仅用于研究标签误差，另2个未知标签保持空值。原始基线没有目标年龄条件，保留全部既有未知区与透明支持；本批完整性指静态资产到实际画面的比较链路。

37个目标保留8个同龄SAM控制、23个其他条件及6个未知源龄条件。直接加载全部GLB，避开时间线中原始锚点优先规则，避免同龄SAM控制被原始源纹理替换。`fgnet-062a45`的同龄控制复用45岁结果，只算一次。

前瞻[独立协议审查](../output/research/render-domain-20261023/protocol-review.json)提出两项澄清，已在新结果前登记[澄清记录](../output/research/render-domain-20261023/protocol-clarification.json)：BLEND只统一透明与深度标志，不等于完整CanvasTexture连续采样路径；几何数组之外，还核对变换和材质/贴图状态。同源目标与原始源的纹理覆盖显著不同，光照也没有消除，配对差异不能只归因于年龄颜色。

## 实际捕获与独立产物检查

[捕获脚本](../frontend/tests/render-domain-capture.mjs)使用真实`FaceViewer`，通过隔离虚拟页面和只允许固定资产的本地服务读取自包含GLB。没有修改生产页面、接口或能力。固定1024×1024、DPR1、studio灯光、solid模式，关闭网格、对比、自动旋转和阻尼；保留实际sRGB输出、ACESFilmic曝光1.05、四盏灯及雾。相机FOV36、near0.05、far100，目标`(0,-0.05,0)`；正面位置`(0,0.03,4.9)`，侧面`(4.9,0.03,0)`。

MASK保持原始`transparent=false, alphaTest=0.5, depthWrite=true`；BLEND统一为`true, 0, false`，两臂均`premultipliedAlpha=false, opacity=1`。保留原GLB贴图、过滤和UV，不补未知区域，不改几何或重新估计源龄。与交互研究的CanvasTexture相比，本批没有关闭原GLB的mipmap或改成LinearFilter，因此只验证这套固定材质对照。

实际环境为Node24.14.1、Chrome156.0.8078.48、Three revision186。浏览器的unmasked renderer记录为ANGLE／SwiftShader Vulkan，属于本机软件渲染证据，不是多设备GPU、人工视觉质量或产品浏览器验收。

376帧全部捕获成功。逐GLB验证位置、法线、有序索引和UV数组哈希及内嵌PNG；逐帧再次核对数组、实际相机、世界变换、其余材质参数和贴图状态。目标与基线每一组的运行时不变量一致，相机允许1e-9数值容差。PNG来自实际`exportPNG()`渲染后的canvas编码，采用正常顶部起始方向。此前196份`raw-export.png`是内嵌纹理图集，不能当作这些渲染画面。

独立产物审计重新哈希并解码全部376份PNG，大小均为1024×1024、alpha全部不透明，四角符合固定黑白背景；重核296组成对运行时状态、94份资产和15个冻结输入。13个无关修改/生产边界文件仍与基线相同。审计复核保存的状态记录，没有独立重跑浏览器、模型或视觉质量判断。浏览器、Vite和资产服务器全部关闭，无外部浏览器请求及页面错误。

## 评分方法与解释边界

[评价工具](../tools/render_evaluator_probe.py)将本批PNG作为新的渲染域请求，重新运行固定CPU YuNet/SFace；MiVOLO使用单独CPU环境，复用这些新渲染框及状态。它不把渲染图伪装成N0原照片，不复用原照片框。裁剪仍为向下/向上取整、边界裁切、零padding、无关键点形变，人体通道使用原处理器的归一化黑色占位，不输出性别。

身份与年龄分别保留376个帧请求和296个配对请求。身份配对需要两侧embedding；年龄四项指标需要两侧估计；年龄预测失败时仍可保留有效的身份配对。NO_FACE、对齐/特征失败、输入漂移及其他失败均保留分母；不因侧面失败改成更易检测的镜头。

每配置按同龄、其他条件、未知源龄分别汇总，共24项；先在源内平均，再对有效源均权。身份与年龄使用各自完整配对集合，四项年龄指标共享源向量bootstrap。1000次重采样的单位是源，固定seed及分层key；8项原始渲染年龄误差仅使用已知研究标签，同时保留10个请求和2个未知标签。条件偏差是有符号量，可能相互抵消；目标年龄始终是请求条件，不能当作生成图真实年龄。

输入、源码、模型和环境在推理前及全部汇总后复核。晚发生的图像漂移会永久清空对应结果并重算依赖统计；元数据、模型或环境漂移阻止成功发布。评分前的独立代码审查要求增加捕获报告与精确协议/N0/N4/原始资产的关联，防止同名旧产物被误用。

### 失败定位与下一步

`fgnet-004a63`原始基线正面4/4有检测，四个SAM目标全部8配置均NO_FACE，共32/32。其原始观察支持为42056/45355=0.92726，目标仅8511—8874个支持texel，覆盖0.18765—0.19566；其余9个源的目标为0.36682—0.46707。既有目标mask审查为此源设置了全眼带眼镜不确定排除，包含部分无遮挡皮肤；几何和同源坐标仍一致。

这些元数据把优先排查点指向眼部排除与可见支持，尚未通过新图像/对应关系复核确认因果。下一批先输出该源与对照源的目标自有投影、可见/遮挡/未知区域和眼带排除诊断，区分真实遮挡与过宽的不确定区；重新检查对应关系后再决定是否需要新的注册候选。保留原N4/本批全部证据，不补造未知纹理、不填写默认源龄、不改镜头或检测阈值去追求评分通过。侧面评价、人工接缝/遮挡质量、年龄形状、外部数据和高龄覆盖、训练重叠、用途与完整服务链继续单列。
