# 静态渲染身份参考值适用性记录

2026-10-27。已实现[保存特征诊断CLI](../tools/render_identity_reference_probe.py)，固定原照片域参考值`0.30832315136297866`，对八个开发源的原始静态三维渲染与原照片进行同人及有向异人比较。512个请求中344个可评分、168个保留失败；四种正面配置各8个同人比较均未拒识，四种侧面配置各仅2—4个同人比较可评分，其中各2个被拒识。该参考值不能据此成为通用渲染身份阈值，`quality_threshold=null`，G3和生产能力继续关闭。

## 方法与来源边界

按[固定协议](render-identity-reference-v1.json)读取九类冻结JSON（本轮协议及八类既有元数据）与CLI、测试、标准库助手三份源码，共12项精确输入。旧原照片报告、参考值报告与验证收据、旧渲染报告与收据、捕获报告、源重置报告和N0清单分别绑定；照片与渲染的模型指纹、运行环境必须一致。该关联核验不等于重跑旧模型或递归核验全部上游文件。

仅选择N0中八个已知研究标签、彼此不同身份的开发源。原始静态资产必须绑定源重置声明的GLB、atlas及source_frame，每个所选帧的配置、图像指纹、observed图像指纹和来源检查还须与旧捕获一致。源重置的研究标签及来源完整核对，API源龄仍为unknown/null；文件名年龄不写成用户源龄。

每个配置有8个渲染：各与自己的确切源照片构成8个同人比较，与其他7个源照片构成56个有向异人比较。反向比较另计；同一身份的bootstrap副本不构成异人比较。八配置分别汇总，不把多个视角当作独立人群。阈值完全沿用冻结原照片报告，不计算新阈值曲线、不重选或校准渲染阈值；`cosine >= reference`时接受。

全部旧捕获含47个资产、376帧；本轮选择64个原始静态帧，其中43个既有特征成功、21个NO_FACE。另16个外部源原始帧及296个SAM目标帧排除于新配对与评分，137个保留组图像仅核排除元数据。旧渲染JSON本身含SAM特征记录，本轮会解析其库存与来源，但这些记录不进入身份真值、统计或重采样集合。没有打开照片、PNG、GLB、权重或保留组特征，没有新模型推理、浏览器捕获、训练或服务启动。

这里使用的是**2026-10-23旧查看器、SwiftShader捕获**的保存特征。旧捕获的BLEND配置仅切换原GLB的alpha材质标志，没有覆盖完整CanvasTexture采样/过滤路径；名称不表示当前连续纹理显示已经验证。该结果不能验证当前查看器、普通GPU或稳定浏览器真实会话出口。八张源照片已参与参考值的开发数据，旧画面和分数也已查看；本轮是回顾性诊断，不是独立验证。

共64个同人请求为43有效/21失败，448个异人请求为301有效/147失败；这是库存计数，不合并为跨配置人群错误率。八张参考照片均成功，因此所列缺失均来自既有渲染帧失败。侧面条件FMR为0不能掩盖大量未检测结果，也不能单独证明身份保持；检测、姿态、材质、透明与纹理覆盖均可能影响该诊断，未证明其中任何一项是唯一原因。

每配置执行1000次完整八身份有放回抽样，失败身份仍参与抽样。同人单位权重为身份出现次数`m_i`，有向异人单位权重为`m_i*m_j`且`i != j`；同一抽样同时计算条件FMR/FNMR及两类请求缺失界，共六指标。seed、排序、插值和完整1000个可空重复值的紧凑JSON SHA由协议固定。

八配置共48份bootstrap指标摘要。四种侧面配置的条件FMR及FNMR分别保留105、20、98、3个null重复值；其余指标均无null。区间只对非null重复值取2.5/97.5百分位，另显式报告有效/null数量，不重抽、不丢弃null后伪称1000次有效。完整数组SHA同时覆盖null的位置。区间仅描述这些已曝光身份在一个固定参考值下的抽样不确定性，不包含阈值拟合不确定性、缺失校正、训练重叠或独立人群推断。
