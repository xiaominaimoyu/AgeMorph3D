## 1. 研究性质与设计

### 1.1 性质

- **可行性/探索性研究。** 评价者人数 10—20 由任务书规定（`docs/毕业设计要求与交付清单.md` 第 29 行；`docs/AgeMorph3D_项目计划.md` 第 54 行），不是按功效反推出来的。本研究的目的是：在固定人数下，以事先写定的方法估计各条件的主观评分及其不确定性，并对一个主要比较做一次事先设定的检验。结果不能推广为人群层面的质量验收，也不能替代协议里尚未签收的年龄/身份客观指标（协议第 49、55、56 行）。
- **研究对象是系统输出，不是评价者。** 评价者对数据集人脸经系统处理后的渲染图打分；不采集评价者本人的人脸（§0 P2）。
- **术语**：20/45/70 等是**生成器目标条件**，不是生成结果的年龄真值（协议第 30 行）；本文所有“目标年龄”都指目标条件。

### 1.2 条件（自变量）

每个身份生成下列刺激，均为同一渲染器、同一固定视角下的三维模型静态渲染图（正面 + 约 30° 侧面拼成一张，视角和分辨率在冻结时写定）：

| 代号 | 条件 | 说明 |
|---|---|---|
| C0 | 同龄对照 | 完整系统，目标条件 = 源研究标签年龄（对应协议第 30 行的 `SAM(s)` 同龄对照，用来测“只经过处理、不改年龄”的漂移） |
| C1 | 仅纹理 | 静态源形状 + 目标条件纹理（SAM 纹理回贴） |
| C2 | 仅形状 | 年龄形状变化 + 源纹理 |
| C3 | 形状 + 纹理 | 完整系统（本课题的主张对象） |

- 每个身份取两个目标条件 T1、T2：从 {20, 45, 70} 中取与源标签年龄**相差最大**的两个（相差相同时取一大一小）。规则只看源标签，不看生成效果。
- 每个身份共 7 个刺激：C0 ×1 + (C1, C2, C3) × (T1, T2)。
- **默认 8 个身份 → 56 个正式刺激。**
- **条件集合要在冻结前确认（§10 第 2 项）。** 仓库记录显示生产形状仍是静态回退、年尺度未通过（`docs/毕业设计要求与交付清单.md` 第 23 行）。如果到 S6 阶段（2027-04-19—05-16，规划 v2 第 57 行）形状路线仍未验收，C2/C3 无法成立，必须在招募前改条件集合并出新版本，不能在看到评分后再改。

### 1.3 设计

完全交叉：每位评价者对全部 56 个刺激打分（被试内设计）。分两部分：

- **A 部分（单刺激评分）**：屏幕左侧固定放“参照”（该身份的源图，经 FFHQ 对齐裁剪），右侧放刺激；每题先只显示这两张图，答完 D5 后再显示“目标年龄：X 岁”及 D1—D4（§3.2，用来减少锚定）。评 4 个 Likert 维度 + 1 个感知年龄（§3）。共 63 题 = 56 正式 + 4 重复 + 3 指令题。
- **B 部分（二选一偏好）**：同一身份、同一目标条件下 C3 与 C1 左右并排，问“哪一张更像参照人物在 X 岁时的样子？”，强制二选一。共 8 × 2 = 16 对，左右位置平衡（§5.4）。
- A 部分先做，B 部分后做（B 会暴露成对关系，放后面避免影响 A）。
- 正式题前 3 道练习题，用协议开发组身份（协议第 9、19 行）生成，不计分。
- 预计用时：A 约 25 分钟，B 约 3 分钟，说明与练习约 5 分钟，合计约 35 分钟；A 部分每块之间可休息。用时以预试（§9）实测为准。

## 2. 样本量依据（10—20 名评价者）

### 2.1 推荐目标人数

**推荐：有效评价者 16 人**（10—20 之内的偶数，便于 B 部分左右成对平衡）。最低可接受 10 人；上限 20 人。目标人数在冻结时写定，招募到目标即停止，**不做中期分析、不按结果加招**（§7.3）。

### 2.2 主要比较的检测能力（评价者层面的配对比较）

主要终点按评价者汇总成一个配对差值 d_r（§6.1），分析单位 n = 有效评价者人数。下表是双侧 α = 0.05、功效 80% 时可检出的最小标准化效应量 dz（= 差值均值 / 差值标准差），按配对 t 检验的非中心 t 分布精确计算：

| 有效评价者 n | 10 | 12 | 14 | 16 | 18 | 20 |
|---|---|---|---|---|---|---|
| 最小可检出 dz（80% 功效） | 0.996 | 0.889 | 0.810 | 0.749 | 0.701 | 0.660 |

主要检验用 Wilcoxon 符号秩检验（口径见 §6.1）。下表是**连续、无并列的理想化估计**：差值服从正态、取连续值，因此不会出现并列或 0，p 值按无并列时的精确分布计算（每格 20 000 次；n = 20 时 10 000 次；种子 20261116）。真实数据中 d_r 落在 1/16 分的网格上，几乎必然有并列，且常有 0（见下文网格化补充），实际功效会略低：

| n | dz = 0.5 | dz = 0.8 | dz = 1.0 | dz = 1.2 |
|---|---|---|---|---|
| 10 | 0.280 | 0.597 | 0.786 | 0.914 |
| 15 | 0.412 | 0.803 | 0.938 | 0.986 |
| 16 | — | 0.820 | 0.947 | — |
| 20 | 0.541 | 0.906 | 0.985 | 0.999 |

与同条件下配对 t 检验的功效（n = 10, dz = 1.0 时 0.803；n = 15, dz = 0.8 时 0.821）相差很小，符合 Hodges & Lehmann（1956）的结论：正态下 Wilcoxon 相对 t 检验的渐近相对效率为 3/π ≈ 0.955，对任何连续分布不低于 0.864。

**网格化补充（贴近真实数据形态）**：把差值取整到 1/16 分网格（16 个刺激的平均分之差只能取这些值），用 §6.1 规定的正态近似加连续性校正，每格 20 000 次（种子 20261117，`wilcoxon_check.py`）：

| n | 均值 0.375、标准差 0.5（dz = 0.75） | 均值 0.25、标准差 0.5（dz = 0.5） |
|---|---|---|
| 10 | 0.498 | 0.243 |
| 16 | 0.773 | 0.436 |
| 20 | 0.867 | 0.536 |

在 n = 16、均值 0.375、标准差 0.5 的设定下，样本中出现并列的比例为 0.9996，出现 0 的比例为 0.4591，与 Sentinel 的复现（0.9995、0.46）一致。同口径对照：理想化设定（连续、无并列、精确 p）下 n = 16、dz = 0.75 的 Wilcoxon 功效模拟为 0.769（20 000 次，种子 20261121，`wilcoxon_check.py`），网格化后为 0.773，两者在模拟误差内相同。也就是说，按 §6.1 口径处理后，并列和 0 对功效的影响很小；16 人在 dz = 0.75 时的功效约 0.77。（r2 写的“理想化表格中约 0.80”不是同口径的数：约 0.80 对应 §2.2 配对 t 检验表（n = 16 时 dz = 0.749 达 80%；dz = 0.75 时 t 检验功效 0.801）；0.820 是上方理想化 Wilcoxon 表中 n = 16、dz = 0.8 的值（t 检验同点为 0.848）。r3 曾把 0.820 写成 t 检验表的值，r4 已改正；0.801、0.848 按非中心 t 分布重算，0.820 用独立模拟复核为 0.8199，标准误 0.0027。）

**怎么读**：16 人时只有在 dz ≈ 0.75 以上（大效应）才有约 80% 把握检出。dz 换算成评分点数要看差值标准差：**假设**评价者层面差值的标准差为 0.5 分（5 点量表上，16 个刺激平均后的差值），dz = 0.75 对应约 0.37 分。这个标准差**没有任何既有数据支持**，只是示意；预试只用来检查流程，不用来改这个数字或改样本量。若真实效应小（dz ≈ 0.5），16 人的功效只有约 0.4—0.5，结论应写成“未检出差异”，不能写成“没有差异”。

**多重比较**：主要终点只有一个，不做校正。若导师要求把身份保持也列为共同主要终点（§10 第 3 项），两者用 Holm 校正，相当于对最小 p 值用 α = 0.025；此时最小可检出 dz 为 0.843（n = 16）、0.876（n = 15）、0.739（n = 20），同法计算。

**可达到的最小 p 值**：按 §6.1 的正态近似加连续性校正，全部差值为正且无并列时，双侧 p 值为 0.036（n = 6）、0.014（n = 8）、0.0059（n = 10）、0.00048（n = 16），所以 10 人以上不存在“人太少根本不可能显著”的问题；问题在于功效低。

### 2.3 信度（ICC）的精度

ICC 的精度主要取决于**被评对象（刺激）数**，评价者数 k 是每个对象的重复次数。本设计每个维度有 56 个刺激 × k 名评价者。

**(a) Bonett（2002）近似**：给定计划 ICC ρ、评价者数 k、刺激数 n，95% CI 的期望总宽度约为
w ≈ √8 · z₀.₉₇₅ · (1 − ρ)(1 + (k − 1)ρ) / √(k(k − 1)(n − 1))。
Bonett 文中的例子（ρ = 0.85、k = 4、w = 0.2 需 19.2 个对象）已用同一代码复现为 19.15。按单评分者 ICC 计算，n = 56 时：

| 计划 ICC ρ | k = 10 | k = 15 | k = 16 | k = 20 |
|---|---|---|---|---|
| 0.3 | 0.204 | 0.188 | 0.186 | 0.180 |
| 0.5 | 0.217 | 0.206 | 0.205 | 0.201 |
| 0.6 | 0.202 | 0.194 | 0.193 | 0.190 |
| 0.7 | 0.173 | 0.167 | 0.166 | 0.165 |
| 0.8 | 0.129 | 0.126 | — | 0.124 |

反过来，要让 w ≤ 0.2，ρ = 0.5 时需 66（k = 10）/ 57（k = 20）个刺激；要求放宽到 w ≤ 0.3 时只需 30 / 26 个。56 个刺激对应 ρ 约 0.5 时 w ≈ 0.2，即单评分者 ICC 的 95% CI 大约是“点估计 ± 0.1”。

**(b) Walter, Eliasziw & Donner（1998）近似**（检验 H₀: ρ ≤ ρ₀ 对 H₁: ρ = ρ₁，单侧 α = 0.05，功效 80%）：
n = 1 + 2(z₁₋α + z₁₋β)² k / [(ln C₀)² (k − 1)]，C₀ = (1 + kθ₀)/(1 + kθ₁)，θ = ρ/(1 − ρ)。
（原文中 n 表示重复数、k 表示对象数，这里按本设计改写为 k = 评价者数、n = 刺激数。）

| ρ₀ → ρ₁ | k = 10 | k = 16 | k = 20 |
|---|---|---|---|
| 0.5 → 0.75 | 13.8 | 12.8 | 12.5 |
| 0.5 → 0.7 | 22.8 | 21.0 | 20.4 |
| 0.4 → 0.6 | 26.4 | — | 22.9 |

所以 56 个刺激远多于“区分差/中等信度”所需。

**(c) 模拟核对**（两因素随机模型，评价者方差占总方差 10%，每格 2000 次，种子 20261116；CI 用 McGraw & Wong 1996 的 F 分布方法）：

| 设置 | 单评分者 ICC(A,1) CI 中位宽度 | 覆盖率 | 平均 ICC(A,k) CI 中位宽度 |
|---|---|---|---|
| n = 56, k = 10, ρ = 0.5 | 0.225 | 0.952 | 0.077 |
| n = 56, k = 15, ρ = 0.5 | 0.213 | 0.952 | 0.051 |
| n = 56, k = 20, ρ = 0.5 | 0.206 | 0.949 | 0.038 |
| n = 56, k = 10, ρ = 0.3 | 0.206 | 0.950 | 0.153 |
| n = 24, k = 10, ρ = 0.5（若只有 24 个刺激） | 0.331 | 0.956 | 0.117 |
| 5 点量表离散化，n = 56, k = 10, 潜变量 ρ = 0.5 | 0.222 | （离散后真值不同，不算覆盖率） | 0.091 |

模拟宽度和 Bonett 近似一致（ρ = 0.5、k = 10 时 0.225 对 0.217），覆盖率接近名义 95%。

### 2.4 假设与局限

1. 评价者是方便样本（校内成年志愿者），不是随机样本；结果只代表这群评价者。
2. 主要分析在评价者层面汇总，**对刺激（身份）的推广性有限**：只有 8 个身份。身份层面的敏感性分析见 §6.4。
3. dz 换算用的差值标准差 0.5 分是假设，没有先验数据。
4. 功效模拟假设差值正态；ICC 模拟假设两因素随机模型、无评价者 × 刺激交互、评价者方差占 10%，这些都是设定值，不是估计值。
5. Bonett 和 Walter 公式都是近似式。Walter 等（1998）以及综述 PMC10981208 推导的是**单因素随机效应模型**下的 ICC；Bonett（2002）定义了模型 1（单因素随机）、模型 2（两因素随机）和模型 3（两因素混合），Table I 的标题是“Accuracy of sample size approximation (α = 0.05; w = 0.2, models 2 and 3)”。这是 2026-11-21 对照 ResearchGate 上的全文 PDF 核实的。但 Bonett 的精确区间只用 MS_B/MS_E 构造，不含评价者均方，对应的是不计评价者系统偏差的一致性型 ICC。本方案的 ICC(A,1) 是**两因素随机、绝对一致型**，套用这些公式只是近似，最终以 §2.3 (c) 的两因素模拟为准；本设计的 ICC 跨条件合并计算，数值受刺激异质性影响（§4.4）。
6. 刺激来自已被项目接触的数据（FG-NET）或与 SAM 同源的数据（FFHQ）时，有乐观偏差，须在报告中写明。

## 4. 信度：ICC

### 4.1 模型选择

| 项 | 选择 | 理由 |
|---|---|---|
| 模型 | **两因素随机效应**（Shrout & Fleiss 1979 的 ICC(2,·)；McGraw & Wong 1996 记作 ICC(A,·)） | 设计完全交叉（每位评价者评全部刺激）；评价者被视为从“可能的成年评价者”总体中抽出，希望结论推广到其他评价者，所以评价者效应取随机 |
| 类型 | **绝对一致（absolute agreement）** | 量表有固定锚点，“3 分”应对所有人意味着同样的程度；评价者整体偏严或偏松也算不一致。一致性型 ICC(3,·)/ICC(C,·) 忽略这种系统偏差，只作敏感性报告 |
| 主报告 | **ICC(2,1) = ICC(A,1)**：单个评价者的信度 | 回答“换一个评价者，分数可信吗” |
| 同时报告 | **ICC(2,k) = ICC(A,k)**：k 名评价者平均分的信度 | 刺激层面的条件比较用的是平均分；k 为实际有效评价者数 |
| 敏感性 | ICC(3,1)、ICC(3,k)（双向混合、一致性） | 看评价者系统偏差的影响 |

### 4.2 计算口径

- 每个维度 D1—D5 分别计算；对象为 56 个正式刺激，列为有效评价者。重复题、指令题、练习题不进入 ICC。
- 点估计与 ICC(A,1) 的 95% CI 按 McGraw & Wong（1996）的均方公式和 F 分布区间计算；ICC(A,k) 的区间按 pingouin 0.7.0 的做法，由 ICC(A,1) 区间端点经 Spearman–Brown 换算。参考实现：Python `pingouin.intraclass_corr`（0.7.0 输出中的 `ICC(A,1)`、`ICC(A,k)` 行）或 R `irr::icc(model = "twoway", type = "agreement", unit = "single"/"average")`。Metric 已用模拟数据核对自写公式与 pingouin 0.7.0 输出一致（§1.5）。报告时写明软件和版本。
- 需要完整矩阵。缺失的格子不插补：ICC 只用对 56 个刺激全部作答的有效评价者计算，并写明用了几人。

### 4.3 解释阈值（Koo & Li 2016）

ICC < 0.5 差；0.5—0.75 中等；0.75—0.9 好；> 0.9 优秀。按 Koo & Li 的建议，**以 95% CI 落在哪个区间来解释，而不是只看点估计**。例如 ICC(A,1) = 0.62、95% CI 0.51—0.72，写作“中等”；若 CI 跨两档（如 0.45—0.68），写作“差到中等”。

### 4.4 局限

- 56 个刺激跨越不同条件和目标年龄，条件之间的真实差异会抬高刺激间方差，从而抬高 ICC；因此 ICC 描述的是“这批刺激上的评价一致性”，不能直接推广到单一条件内部。作为补充，按条件分别计算 ICC(A,1)（每个条件 16 个刺激，C0 只有 8 个，区间会很宽，只作描述）。
- Likert 是有序数据，ICC 把它当等距数据处理；模拟显示 5 级离散化对区间宽度影响不大（§2.3 (c)），但仍作为局限写明。
- D5（感知年龄）是数值数据，ICC 最适用。另报告：每个刺激的评价者感知年龄均值与目标条件的平均绝对偏差（单位：岁），以及评价者两两之间的平均绝对差。这些都是**偏差**，不是年龄 MAE（§3.3）。

## 5. 盲测顺序随机化

### 5.1 去标识/盲测要求

- 刺激文件在评价者界面上只显示随机刺激编号（如 `S017`），不含条件名、身份编号或目标条件以外的任何信息；文件名在生成后统一重命名，条件—编号对照表单独保存，由不参与现场组织的一方（建议学生 A 生成、学生 B 主持现场）持有，分析前不打开。
- 评价者只用编号 `R01`、`R02`……标识，按入组顺序分配；撤回或被排除者的编号不重用，补招者用下一个未用编号（R01—R24 已预先冻结，§5.2）。编号与姓名的对照只记在同意书一侧，与评分数据分开存放（§0 P8）。评分数据因此是**去标识**的，不称匿名（§0 P3）。
- 主持人不提示任何条件信息，不回答“哪张是新方法”。

### 5.2 种子

- 每位评价者的种子：`seed(R) = int.from_bytes(SHA-256("agemorph3d-mt4-v1:" + R)[:8], "big")`，例如 R01 的种子为 `18125267619951040259`。
- 随机数发生器：NumPy `Generator(PCG64(seed))`。NumPy 不保证不同版本下随机流完全一致，所以**以冻结时实际生成的顺序文件为准**：冻结时一次性生成 **R01—R24** 的全部顺序（与 §7.3 的入组上限 24 人一致；附录 A 的 `freeze_orders()` 生成），保存为 `order-v1.json` 并记录其 SHA-256、Python 与 NumPy 版本；评价时只读这个文件，不在现场重新生成。

### 5.3 A 部分的区组随机流程

1. 每个身份的 7 个刺激先随机打乱，再按轮换模式 `[(i+0)%4, (i+1)%4, (i+2)%4, (i+3)%4, (i+0)%4, (i+1)%4, (i+2)%4]`（i 为身份序号）分到 4 个区组，保证每个区组恰好 14 个刺激、每个身份在每块出现 1—2 次。
2. 每块内部随机排列，用拒绝抽样保证**同一身份不连续出现**（含跨块边界）。第 5 步插入重复题时也执行同一约束：插在第 4 块块首时，要和第 3 块的最后一题比对（r3 补上；r2 代码漏了这一比对，4 位编号 R0001—R3000 中有 78 人违例，r3 代码为 0；R0001—R20000 也为 0）。
3. 从第 1 块随机抽 4 个刺激作为**重复题**，插入第 4 块的随机位置（与原题间隔至少一整块，且不与同一身份相邻；每道重复题最多尝试 1000 个随机位置，仍找不到时程序报错停止，不静默放宽约束），用于评估评价者自身一致性。
4. 第 2、3、4 块各随机插入 1 道**指令题**（注意力检查，§5.5）：插入时该块有 14 题，插入位置为从 1 起算的**第 4—13 位**（代码 `rng.integers(3, 13)` 给出 0 起索引 3—12）。第 4 块随后再插入 4 道重复题，指令题可能后移，最终在第 4 块内位于第 4—17 位（R01—R24 自检实测范围正好是第 4—17 位；第 2、3 块实测第 4—13 位）。
5. 合计 63 题：56 正式 + 4 重复 + 3 指令。

参考实现见附录 A。用 8 个占位身份 `ID01`—`ID08` 自检：R01—R24 每人 63 题、56 个正式刺激各出现一次、任意相邻两题（含跨块边界、含重复题）身份不同，均通过；另用 4 位编号 R0001—R10000 做压力测试，没有违例；R01 前 6 题为 `ID08-C1-T1, ID01-C3-T2, ID03-C1-T1, ID02-C1-T1, ID04-C2-T1, ID05-C3-T2`（占位编号，仅用于核对实现；真实编号在用户本机替换）。

### 5.4 B 部分的左右平衡

- 16 对（8 身份 × 2 目标条件）的出现顺序**每位评价者单独随机**，种子为 `seed(R + ":B-order")`；偶数号评价者不复用奇数号的顺序（r1 参考代码里 R01 与 R02 的出现顺序相同，r2 已改）。
- 左右位置**按评价者成对精确平衡**：奇数号评价者（R01、R03……）随机安排 8 对 C3 在左、8 对 C3 在右；紧随的偶数号评价者（R02、R04……）取其镜像。所以每位评价者内部 8/8 平衡，每两位评价者合起来每一对的左右也平衡。左右安排的种子为 `seed(R_odd + ":B")`（偶数号取镜像，所以与前一位奇数号共用这一种子）。
- 这也是目标人数建议取偶数的原因（§2.1）。若最终有效人数为奇数，最后一人内部仍是 8/8 平衡。

## 6. 事先设定的分析方法

所有分析在条件对照表解盲后、按本节**原样**执行；任何偏离都记入“偏离记录”（§9.3），并在论文中说明。

### 6.0 数据格式（本机保存）

- 评分长表 `responses.csv`（每行一题）：`rater_code, part(A/B), block, position, trial_type(TRIAL/REPEAT/ATTN/PRACTICE), stimulus_code, D5_age, D1, D2, D3, D4, rt_ms`；B 部分另有 `pair_code, c3_side(L/R), choice(L/R)`。不含姓名、学号、联系方式。
- 条件对照表 `stimulus_key.csv`：`stimulus_code, identity_code, condition(C0—C3), target(T1/T2/S), target_age`，分析前单独保管（§5.1）。
- 两个文件都只在用户本机，不进 box、不进 Git、不交给任何机器人（§0 P7）。

### 6.1 主要终点（唯一）

- **终点**：D1 年龄符合度，C3（形状 + 纹理）对 C1（仅纹理）。
- **评价者层面汇总**：对每位有效评价者 r，m_r(C) = 该评价者对条件 C 的 16 个刺激（8 身份 × T1/T2）的 D1 平均分；d_r = m_r(C3) − m_r(C1)。分析单位是评价者，避免把同一人的多次评分当成独立样本。
- **检验（唯一权威口径）**：Wilcoxon 符号秩检验，双侧，α = 0.05，**一律用带并列校正和连续性校正的正态近似**，不论有无并列、n 多大都不切换算法。
  - **权威软件与命令**：Python 3.13.5 + **SciPy 1.18.1**，`scipy.stats.wilcoxon(d, zero_method="wilcox", correction=True, method="asymptotic", alternative="two-sided")`。算法：剔除 d_r = 0 的评价者；对 |d_r| 取平均秩；方差按并列校正 n(n+1)(2n+1)/24 − Σ(t³ − t)/48；z = (T⁺ − n(n+1)/4 − 0.5·sign)/σ；p = 2·(1 − Φ(|z|))。报告中写明 SciPy 版本；若本机版本不同，先用附录 C 的核对脚本确认结果与上述公式一致再使用。
  - **不用 SciPy 默认值**：SciPy 1.18.1 默认 `method="auto"`、`correction=False`，会随数据切换算法。以下按 `scipy/stats/_wilcoxon.py` 源码核对：n（含 0 的差值总数）> 50 时一律用正态近似；n ≤ 50 时，无并列且无 0 用精确分布；有并列**或有 0**，且 n（含 0）≤ 13 时用置换检验；其余情况用正态近似，且默认不做连续性校正。因此**必须显式写出上面的参数**。
  - **为什么选这个口径**：(a) d_r 是 16 个刺激平均分之差，只能取 1/16 的倍数，并列几乎必然（模拟比例 0.9996），无并列精确分布不再成立；(b) 这一口径对任何 n、任何并列和 0 的情况都给出唯一结果；(c) 它与 **R 4.6.x 或更早版本**的 `wilcox.test(d, mu = 0, exact = FALSE, correct = TRUE)` 算法相同（去 0 后重新排秩），可以用第二种软件交叉核对；更新的 R 版本要先核对。已核 R 源码（GitHub 镜像 `wch/r-source`，`src/library/stats/R/wilcox.test.R`，2026-11-21）：`tags/R-4-6-0` 和 `R-4-6-branch` 仍执行 `x <- x[x != 0]`；`trunk`（R-devel）在 2026-06-02 的提交 `93180d638a`（“Do not remove zeroes for approximate one-sample inference”）之后改为保留 0（Pratt 方法），均值减 k(k+1)/4，方差减 k(k+1)²/16（k 为 0 的个数）。所以有 0 时 R-devel 的 p 值会和本口径不同（审核意见给的例子是 0.0325 对 0.0381）；(d) 精确的条件置换检验也可行，但需要自写代码、学生难以独立复核，故不作为主口径。代价是在 n 较小时近似较粗、略偏保守。
  - **实测核对**（本机 SciPy 1.18.1，`wilcoxon_check.py`）：随机生成 2000 组 1/16 网格差值（n = 6—20，含并列和 0），上述命令与按 R 有并列时算法（去 0、平均秩、并列校正方差、连续性校正 0.5）手算的 p 值最大差 3.3 × 10⁻¹⁶；同一组 16 个差值，本口径 p = 0.0213，SciPy 默认（auto、无连续性校正）p = 0.0199，证明命令里的参数确实改变了算法。box 上没有安装 R，R 一侧是按其算法手算，不是在 R 里运行的结果。
- **效应量（必须报告，不能只报 p 值）**：
  - **Hodges–Lehmann 估计**（Hodges & Lehmann 1963）：全部 n 个 d_r（**含 0**）两两（含自身）的 Walsh 平均数 (d_i + d_j)/2（i ≤ j，共 M = n(n+1)/2 个）的中位数。
  - **HL 的 95% CI（有并列时同样适用）**：把 M 个 Walsh 平均数排序，取 [W₍k₎, W₍M+1−k₎]，其中 k − 1 是满足 P(T⁺ ≤ k − 1) ≤ 0.025 的最大整数，P 按无并列时 T⁺ 的精确零分布计算（n = 8、10、12、16、20 时 k = 4、9、14、30、53，n = 16 时 M = 136）。并列只会让若干 Walsh 平均数相等，算法照常执行；但并列时名义 95% 覆盖率只是近似，报告中注明。参考实现见附录 C 的 `hl_ci()`。n 太小时不存在满足条件的 k（95% 区间要求 n ≥ 6，因为 n = 5 时 P(T⁺ ≤ 0) = 1/32 > 0.025），此时只报 HL 点估计，区间写“样本太少，无法给出 95% 区间”，函数返回 NaN。已测 n = 1—6：n ≤ 5 返回 NaN 区间，n = 6 时 k = 1。全部差值为 0 时，SciPy 返回 p = NaN，报告写“全部差值为 0，未做检验”。**不用** R `wilcox.test(..., conf.int = TRUE)` 给出的区间作为权威值：R 在 exact = FALSE 时用正态近似反解区间，结果会与本法略有不同，只可作参考。
  - 配对秩二列相关 r_rb = (T⁺ − T⁻)/(T⁺ + T⁻)，T⁺、T⁻ 为剔除 0 后正、负差值的平均秩之和（与检验用同一组秩）；
  - 描述性的 d 均值、95% t 区间和 dz；以及 d_r > 0 的评价者比例。
- **检验与 HL 区间不一致时（事先规定）**：**假设检验的结论只看 §6.1 主检验的 p 值**，HL 估计和区间只作效应量估计，不用来改写显著与否。两者不一致时如实同时报告，并写明原因：两者算法不同（检验用正态近似加连续性校正，区间用 Walsh 平均数的秩次），而且网格数据上 Walsh 平均数大量重合，区间端点常常**恰好等于 0**。规定的写法：
  - p < 0.05 但区间含 0（多数是端点恰为 0）：写“主检验 p = …（< 0.05），差异有统计学意义；HL 估计 …，95% CI [0, …]，下限恰为 0，效应大小的不确定性较大”。效应为负（HL 估计 < 0）时对称处理，写“95% CI […, 0]，上限恰为 0，效应大小的不确定性较大”。不得因为区间含 0 而改称“不显著”。
  - p ≥ 0.05 但区间不含 0：写“主检验未检出差异（p = …）；HL 区间 […] 未含 0，与检验结论不一致，原因是两种算法不同”。不得因此改称显著。
  - 模拟核对（n = 16、标准差 0.5、1/16 网格，每格 20 000 次，种子 20261121）：均值 0.2 时，p < 0.05 且区间含 0 的比例为 4.70%（其中端点恰为 0 的占 4.66%），与审核意见的约 4.8% 一致；均值 0.375 时为 4.68%；均值 0 时为 1.27%。p ≥ 0.05 但区间不含 0 的比例都 ≤ 0.06%。
- **解释**：显著且 HL 估计 > 0，写“在本批评价者和刺激上，完整系统的年龄符合度评分高于仅纹理”；显著但 HL 估计 < 0（C3 更低），写“在本批评价者和刺激上，完整系统的年龄符合度评分低于仅纹理”，如实报告，不改称不显著，不事后更换终点、检验或方向；不显著写“未检出差异”，并给出 HL 的 95% CI，不写“没有差异”或“两者相当”。不论结果如何，都不写成年龄准确率或 G3 质量通过（协议第 49、110 行）。

### 6.2 次要终点

**S 组（Holm 校正，族内 6 项，族错误率 0.05）**。所有 Wilcoxon 检验和 HL 估计都**沿用 §6.1 的唯一口径**（同一命令、同一参数、同一 HL 区间算法）。

| 编号 | 终点 | 方法 |
|---|---|---|
| S1 | D2 身份保持，C3 对 C1 | 同 §6.1 |
| S2 | D3 真实感，C3 对 C1 | 同 §6.1 |
| S3 | D4 无伪影程度，C3 对 C1 | 同 §6.1 |
| S4 | B 部分：评价者选 C3 的比例 p_r | 对 p_r − 0.5 做 Wilcoxon 符号秩检验；另报总体选择比例和按评价者的分布 |
| S5 | D5 感知年龄偏差：评价者层面平均 \|感知年龄 − 目标条件\|，C3 对 C1 | 同 §6.1；另报带符号偏差（看偏老还是偏年轻） |
| S6 | D1 年龄符合度，C3 对 C2 | 同 §6.1 |

**F 组（多条件总体比较）**：对 D1—D4 分别做 Friedman 检验（C1、C2、C3 三个条件，评价者为区组），效应量 Kendall’s W = χ²_F / [n(k − 1)]（k = 3）。4 个 Friedman 检验之间用 Holm 校正；只有校正后显著的维度才做三对两两 Wilcoxon（沿用 §6.1 口径），三对之间再用 Holm 校正。Friedman 检验用 `scipy.stats.friedmanchisquare`（SciPy 1.18.1，χ² 近似，含并列校正）。F 组与 S 组中重复的比较（如 D1 的 C3 对 C1）以 S 组和主要终点为准，F 组只作补充。

次要终点只作支持性证据；主要终点不显著时，不能拿次要终点里显著的项来改写结论。

### 6.5 缺失值处理

- 界面设为每题必答，正常情况下没有题目级缺失；缺失只来自技术故障（图片未显示、程序崩溃）。中途退出按 MU-2 r3.1 第 45 行（“退出后将按同意书删除您的全部评价数据”）视同撤回同意，按下文和 E6 处理，不当作缺失。
- 不做任何插补。
- 评价者层面均值用该评价者实际作答的题目计算；某个条件少于 12/16 题有效时，该评价者不进入涉及该条件的比较，并报告人数。
- ICC 只用完整作答 56 个正式刺激的评价者（§4.2）。
- CLMM 使用全部已有观测（隐含随机缺失假设），在报告中写明。
- **撤回同意（与 MU-2 r3.1 第 2.7 节同一口径）**：撤回随时可以，不设期限（MU-2 第 151 行；PIPL 第十五条第一款）。另设“分析排除截止点”，日期【待用户/导师决定】，候选为“解盲前”或“论文定稿前”（MU-2 第 152 行）。截止点只决定撤回者的数据能否仍从分析中排除，不限制撤回权利。
  - **截止点之前撤回**：删除其全部相关数据（评分、作答用时、是/否题、编号与姓名对照等），不进入任何分析，报告中只计撤回人数（MU-2 第 153 行）。这样的人不计入有效人数，按 E6 计数；若发生在解盲之前，可按 §7.3 补招；解盲之后不补招。
  - **截止点之后撤回**：仍删除其尚未删除的原始评分、对照条目及其他可识别信息（MU-2 第 154 行；PIPL 第四十七条第一款第（三）项）。已定稿或已公开的汇总结果不再改动（MU-2 第 154 行；PIPL 第十五条：“个人撤回同意，不影响撤回前基于个人同意已进行的个人信息处理活动的效力”）。这样的人仍计入已锁定分析集的有效人数，报告中另列人数。他们不触发补招，因为截止点在两个候选下都不早于解盲，此时补招都会发生在解盲之后（见 §7.3）。原始数据删除后，任何新增或重做的分析都不再包含此人，结果中要写明所用人数。
  - **两个候选对统计的影响（只列事实，不作选择）**：
    - **解盲前**：与 §7.2“在打开条件对照表之前判定排除”自然对齐，分析集在解盲时锁定，§6 的事先规定分析只按锁定的分析集算一次。为使“已定稿的汇总”有明确所指，解盲后应立即一次性跑完 §6 全部事先规定的分析，并保存只含汇总的结果文件及其 SHA-256（不含个人数据）。之后的撤回只删除原始数据，不改这些结果。代价是：解盲后撤回者的贡献保留在汇总结果中。
    - **论文定稿前**：解盲后、定稿前撤回的人，其数据从分析集中剔除，要用剩余评价者把 §6 全部重算，并在论文中同时报告重算前后的 n、主检验 p 值、HL 估计与区间、ICC 和变化。重算时主检验口径（§6.1 命令、参数和 HL 区间算法）、排除规则和 Holm 族都不变，只是 n 减少。重算后有效人数若 < 10，按 §7.3 只作描述性报告。这段时间不补招（补招会发生在解盲后、看过结果之后）。代价是：解盲后结果可能变动，而且剔除并非随机，若撤回与评分倾向有关，会带来偏倚，需在论文中说明。

## 7. 排除规则（事先定义）

### 7.1 规则

| 编号 | 规则 | 判定时点 |
|---|---|---|
| E1 | 入组资格：未满 18 周岁；课题组成员（两名学生、指导教师）；看过开发阶段输出或刺激的人；参加过预试的人；未签署知情同意（含观看含他人面部图像刺激的知情确认，§0 P5） | 入组前，不入组、不计数 |
| E2 | 注意力检查：3 道指令题中错 ≥ 2 道。一道题算错 = D1—D4 中任一项不等于 2（D5 不参与判定，避免数字误输入） | 收齐数据后、解盲前 |
| E3 | 完成过快：A 部分正式题用时的中位数 < 4 秒/题（每题有 5 项作答，4 秒内无法认真看完两张图） | 收齐数据后、解盲前；阈值在预试后、冻结前最后确认一次 |
| E4 | 未完成：56 个正式题有效作答 < 90%（即 < 51 题） | 收齐数据后、解盲前 |
| E5 | 评分无方差：D1—D4 中有 ≥ 2 个维度在 56 个正式题上全部同一分（标准差为 0） | 收齐数据后、解盲前 |
| E6 | 撤回同意（含中途退出，§6.5） | 任何时点都可撤回；数据均删除。截止点（【待用户/导师决定】，候选解盲前或论文定稿前）之前撤回的，不进入任何分析，不计入有效人数；截止点之后撤回的，已定稿或已公开的汇总不再改动，仍计入锁定时的有效人数（§6.5；MU-2 r3.1 第 152—154 行） |

不作为排除理由（只进敏感性分析）：只错 1 道指令题、重复题不一致、自述认出参照人物。

### 7.2 执行方式

- E2—E5 只用不需要条件信息的质控量（指令题、用时、完成度、方差）判定，**在打开条件对照表之前完成**，由脚本自动计算并保存判定记录。
- 报告排除流程：联系 → 同意 → 完成 → 按 E2/E3/E4/E5/E6 各自排除人数（一人符合多条时按编号顺序只记第一条；E6 只计截止点前撤回的人）→ 有效人数；另列截止点后撤回的人数（这些人仍在有效人数内，§6.5）。
- **分析集锁定**：E2—E5 判定完成、打开条件对照表时，分析集锁定。截止点若定在解盲前，锁定后不再增减；若定在论文定稿前，锁定后只会因截止点前的撤回而减少，按 §6.5 重算并报告，不会增加。

### 7.3 补招与停止

- 被排除的评价者由新招募者补足，直到有效人数达到冻结时写定的目标（推荐 16），或到 S6 评价窗口结束（2027-05-16，规划 v2 第 57 行），或入组总数达到上限（建议 24，§10 第 4 项）。
- 不做中期分析；补招决定只依据有效人数，不看任何条件间结果。
- 补招只在解盲前进行：解盲之前的撤回（E6）和排除（E2—E5）可以补招。解盲之后不论撤回发生在截止点前后，都不补招，也不重新开放招募，以免看过结果后再加人（§2.1“不按结果加招”）。截止点之后撤回的人仍计入有效人数（§6.5），本来就不需要补招。
- 若最终有效人数 < 10，按 §6 照常计算，但只作描述性报告，并在论文中写明未达到任务书的 10 人下限；是否另行补做由用户和导师决定。

```python
"""MT-4 盲测顺序参考实现（只用占位编号自检；真实刺激编号只在用户本机替换）。"""
import hashlib, json, sys
import numpy as np

PREFIX = "agemorph3d-mt4-v1"
CONDS = ["C0", "C1", "C2", "C3"]          # C0 同龄对照；C1 仅纹理；C2 仅形状；C3 形状+纹理

def rater_seed(code: str) -> int:
    return int.from_bytes(hashlib.sha256(f"{PREFIX}:{code}".encode()).digest()[:8], "big")

def stimuli(ids):
    # 每个身份 7 个刺激：C0(同龄) + C1..C3 × 两个目标条件 T1/T2
    out = []
    for i in ids:
        out.append((i, "C0", "S"))
        for c in CONDS[1:]:
            for t in ("T1", "T2"):
                out.append((i, c, t))
    return out

def no_adjacent(seq, prev=None):
    last = prev
    for s in seq:
        if last is not None and s[0] == last[0]:
            return False
        last = s
    return True

def schedule(code: str, ids):
    rng = np.random.Generator(np.random.PCG64(rater_seed(code)))
    blocks = [[] for _ in range(4)]
    for n, i in enumerate(ids):                       # 1) 身份内打乱后按轮换模式分块：每块恰好 14 个
        items = [s for s in stimuli([i])]
        items = [items[j] for j in rng.permutation(len(items))]
        pattern = [(n + p) % 4 for p in (0, 1, 2, 3, 0, 1, 2)]
        for s, b in zip(items, pattern):
            blocks[b].append(s)
    order, prev = [], None
    for b in blocks:                                  # 2) 块内拒绝抽样：同一身份不相邻（含跨块边界）
        for _ in range(10000):
            cand = [b[j] for j in rng.permutation(len(b))]
            if no_adjacent(cand, prev):
                break
        else:
            raise RuntimeError("no valid order")
        order.append(cand); prev = cand[-1]
    rep = [order[0][j] for j in rng.choice(len(order[0]), size=4, replace=False)]  # 3) 第 1 块抽 4 个做重复题
    final = []
    for bi, blk in enumerate(order):
        blk = [("TRIAL",) + s for s in blk]
        if bi in (1, 2, 3):                           # 4) 第 2—4 块各插 1 道指令题：插入前 0 起索引 3..12，即 1 起第 4—13 位
            blk.insert(int(rng.integers(3, 13)), ("ATTN", f"A{bi}"))
        if bi == 3:                                   # 5) 重复题插入第 4 块随机位置（指令题可能因此后移）
            for r in rep:                             # 重复题不与同一身份相邻
                for _ in range(1000):
                    pos = int(rng.integers(0, len(blk) + 1))
                    nb = blk[max(pos - 1, 0):pos + 1]
                    if pos == 0:                      # 插在块首时，还要和第 3 块最后一题比对（跨块边界）
                        nb = [final[-1][-1]] + nb
                    if all(len(x) < 4 or x[1] != r[0] for x in nb):
                        break
                else:
                    raise RuntimeError(f"{code}: 1000 次内找不到不与同一身份相邻的重复题位置")
                blk.insert(pos, ("REPEAT",) + r)
        final.append(blk)
    return final

def part_b_sides(code: str, n_pairs: int = 16):
    # 左右：奇数号评分者随机 8 左 8 右；偶数号取前一号的镜像，成对精确平衡（种子 seed(R_odd + ":B")）
    # 出现顺序：每位评分者单独打乱（种子 seed(R + ":B-order")），偶数号不复用奇数号的顺序
    num = int(code[1:])
    base = f"R{num - 1:0{len(code) - 1}d}" if num % 2 == 0 else code
    rng_side = np.random.Generator(np.random.PCG64(rater_seed(base + ":B")))
    sides = rng_side.permutation([0] * (n_pairs // 2) + [1] * (n_pairs // 2))   # 1 = C3 在左；第 k 个元素对应 pair_code k
    if num % 2 == 0:
        sides = 1 - sides
    rng_order = np.random.Generator(np.random.PCG64(rater_seed(code + ":B-order")))
    pair_order = rng_order.permutation(n_pairs)
    return pair_order.tolist(), sides.tolist()

def freeze_orders(ids, codes, path):
    """生成并保存全部评价者的顺序（A 部分 + B 部分），返回文件 SHA-256。正式冻结时 codes = R01—R24。"""
    data = {"prefix": PREFIX, "python": sys.version.split()[0], "numpy": np.__version__, "ids": list(ids), "raters": {}}
    for code in codes:
        order, sides = part_b_sides(code)
        data["raters"][code] = {"A": schedule(code, ids), "B_pair_order": order, "B_c3_left": sides}
    raw = json.dumps(data, ensure_ascii=False, indent=1).encode()
    with open(path, "wb") as f:
        f.write(raw)
    return hashlib.sha256(raw).hexdigest()

def check_rater(code, ids):
    """自检一位评价者：63 题、56 个正式刺激各一次、全序列（含跨块边界）同一身份不相邻、指令题位置口径。"""
    sch = schedule(code, ids)
    flat = [t for b in sch for t in b]
    trials = [t for t in flat if t[0] == "TRIAL"]
    assert len(flat) == 63 and len(trials) == 56 and len(set(trials)) == 56
    assert no_adjacent([t[1:] for t in flat]), code
    attn = [(bi, p + 1) for bi, b in enumerate(sch) for p, t in enumerate(b) if t[0] == "ATTN"]
    assert all(4 <= p <= 13 for bi, p in attn if bi in (1, 2)) and all(4 <= p <= 17 for bi, p in attn if bi == 3)
    return sch, attn

if __name__ == "__main__":
```

```python
"""MT-4 r4：核对主要检验口径（SciPy asymptotic+correction 与 R wilcox.test 公式一致）及 HL 区间算法。"""
import numpy as np, scipy, json
from scipy import stats

def r_style(d):
    """按 R wilcox.test(exact=FALSE, correct=TRUE) 的公式手算：去 0、平均秩、并列校正方差、连续性校正 0.5。"""
    d = np.asarray(d, float); d = d[d != 0]; n = len(d)
    r = stats.rankdata(np.abs(d)); V = r[d > 0].sum()
    _, t = np.unique(r, return_counts=True)
    z = V - n * (n + 1) / 4
    sigma = np.sqrt(n * (n + 1) * (2 * n + 1) / 24 - (t ** 3 - t).sum() / 48)
    z = (z - np.sign(z) * 0.5) / sigma
    return 2 * stats.norm.sf(abs(z))

def primary_p(d):
    return stats.wilcoxon(d, zero_method="wilcox", correction=True, method="asymptotic",
                          alternative="two-sided").pvalue

def signed_rank_null_cdf(n):
    """无并列时 T+ 的精确零分布（动态规划），返回 P(T+ <= t)。"""
    M = n * (n + 1) // 2; c = np.zeros(M + 1); c[0] = 1
    for i in range(1, n + 1):
        c[i:] = c[i:] + c[:-i].copy()
    return np.cumsum(c) / 2 ** n

def hl_ci(d, conf=0.95):
    """HL 估计 = 全部 n 个差值（含 0）的 Walsh 平均数中位数；
    CI = [W_(k), W_(M+1-k)]，k-1 为满足 P(T+ <= k-1) <= (1-conf)/2 的最大整数（无并列精确零分布）。
    n 太小（95% 时 n <= 5）时不存在这样的 k：区间返回 NaN、k 返回 None，报告写“样本太少，无法给出 95% 区间”。"""
    d = np.asarray(d, float); n = len(d)
    if n == 0:
        return float("nan"), float("nan"), float("nan"), None, 0
    i, j = np.triu_indices(n)
    W = np.sort((d[i] + d[j]) / 2); M = len(W)
    cdf = signed_rank_null_cdf(n)
    ok = np.where(cdf <= (1 - conf) / 2)[0]
    if ok.size == 0:
        return float(np.median(W)), float("nan"), float("nan"), None, M
    k = int(ok.max()) + 1
    return float(np.median(W)), float(W[k - 1]), float(W[M - k]), k, M

out = {"scipy": scipy.__version__, "numpy": np.__version__}

for _ in range(2000):

                    for m in ("auto", "asymptotic")}
out["example_p"]["auto_default_correction_False"] = float(stats.wilcoxon(ex, zero_method="wilcox").pvalue)
out["example_HL"] = hl_ci(ex)
out["k_for_n"] = {n: hl_ci(np.arange(1, n + 1))[3] for n in (8, 10, 12, 16, 20)}
# 不同 n 下全部为正且无并列时的最小 p（所选渐近法）
out["min_p_all_positive"] = {n: float(primary_p(np.arange(1, n + 1))) for n in (6, 8, 10, 16)}
# 1/16 网格 + 所选方法下的功效（补充，近似真实数据形态）
pw = {}
for n in (10, 16, 20):
    for mu, sd in ((0.375, 0.5), (0.25, 0.5)):
        R = 20000
        D = np.round(rng.normal(mu, sd, (R, n)) * 16) / 16
        p = np.array([primary_p(x) if np.any(x != 0) else 1.0 for x in D])
        pw[f"n{n}_mu{mu}_sd{sd}"] = round(float(np.mean(p < 0.05)), 3)
        if n == 16 and mu == 0.375:
            out["tie_prob_n16"] = round(float(np.mean([len(np.unique(np.abs(x[x != 0]))) < np.sum(x != 0) for x in D])), 4)
            out["zero_prob_n16"] = round(float(np.mean([np.any(x == 0) for x in D])), 4)
out["grid_power_asymptotic"] = pw
# r3 新增（独立种子，不影响上面各项结果）
rng3 = np.random.default_rng(20261121)
out["hl_ci_small_n"] = {n: hl_ci(np.arange(1, n + 1) / 16) for n in range(1, 7)}
# 理想化（连续、无并列、精确 p）n=16、dz=0.75，与 §2.2 原表同口径
D = rng3.standard_normal((20000, 16)) + 0.75

disc = {}
for mu in (0.0, 0.2, 0.375):
    D = np.round(rng3.normal(mu, 0.5, (20000, 16)) * 16) / 16
    sig = in0 = sig_in0 = sig_lo0 = ns_ex0 = 0
    for x in D:
        p = primary_p(x) if np.any(x != 0) else 1.0
        _, lo, hi, _, _ = hl_ci(x)
        s_ = p < 0.05; c0 = lo <= 0 <= hi
        sig += s_; sig_in0 += s_ and c0; sig_lo0 += s_ and (lo == 0 or hi == 0); ns_ex0 += (not s_) and not c0
    disc[f"mu{mu}"] = {"p_lt_0.05": round(sig / 20000, 4), "p_lt_0.05_and_CI_contains_0": round(sig_in0 / 20000, 4),
                       "p_lt_0.05_and_CI_endpoint_exactly_0": round(sig_lo0 / 20000, 4),
                       "p_ge_0.05_and_CI_excludes_0": round(ns_ex0 / 20000, 4)}
out["test_vs_hl_ci_discordance_n16_sd0.5"] = disc
json.dump(out, open("wilcoxon_check.json", "w"), indent=1)
```
