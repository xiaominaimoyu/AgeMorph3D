### 2.3 字体方案（本机字体，不用远程 Web 字体）

中文与西文的**首选（海报印刷，以及导出给评委的 PDF）**为 **Source Han Sans SC（思源黑体）或 Noto Sans SC**，二者均为 SIL Open Font License，可嵌入 PDF 与海报出品文件。MU-1 列举的「黑体 / 微软雅黑 / Source Han Sans SC / Noto Sans SC」中，微软雅黑是方正商业字体，课堂投影若学校模板已经指定，可以沿用，但**不得作为海报或导出 PDF 的主字体**。本模板**不使用苹方**：苹方只授权在 Apple 平台使用，且 MU-1 并未列入。西文与数字优先用同一 OFL 字体的拉丁部分；等宽路径、接口、错误码、顶点计数用 Consolas / Cascadia Mono / JetBrains Mono / 等宽（嵌入 PDF 时确认许可，或改用 OFL 等宽如 JetBrains Mono）。数字用 `tabular-nums`。年龄范围写作 `20—70`。现场 PowerPoint 编辑可用已安装的 OFL 字体；不要依赖远程 Web 字体。

**16:9 幻灯片字号（磅 pt；1 pt = 1/72 in）。** 正文不要小于 16 pt，图注与页脚不要小于 12 pt（页码可 10–11 pt）。

## 3. 人像与数据使用规则（必须写进母版备注）

规划 MU-4 的验收写有「有获准的人像样例」。用户已于 2026-11-21 经 Atlas 确认：答辩幻灯片与海报的**课题演示人像样例**使用 scikit-image 自带的 `astronaut` 照片。本规格只给出选用说明与图注要求，**不嵌入、不生成该图像**；学生自行从 scikit-image 取出或使用仓库 B0 记载的本机样例路径，放入相应图位。

**禁止：**

- 使用 AgeDB（含官方包、非官方转存、文件名中带人名的任何截图或拼图）。
- 使用 FG-NET、WIDER FACE、AFLW2000-3D、UTKFace、FFHQ、FFHQ-Aging 或其他数据集中的人脸，包括论文里常见的「效果对比拼接」。
- 使用未授权的网络人像、同学或导师生活照（除非另行取得书面同意并限定答辩使用）。
- 把演示头模截图不加标注地当作「真实重建结果」。
- **禁止用 AI 生成的人脸或插图充当占位或结果**（包括扩散模型、人脸生成器，以及来源不明、疑似合成的「网图」）。占位必须是抽象剪影或几何线框，不能用生成脸「充样本」。

**允许：**

- **课题输入与重建演示**使用已确认的 `astronaut` 样例（不是灰色剪影）。取图方式：`skimage.data.astronaut()`，或仓库 B0 记载的本机文件（如 `data/samples/astronaut.png`）。该图为 **512×512** 的彩色方图，排版时保持 1:1，不要拉伸。
- **署名与许可（以 scikit-image 文档为准，并与 B0 登记对照）**：scikit-image 将 `skimage.data.astronaut()` 说明为美国宇航员 Eileen Collins 的彩色照片，下载自 NASA Great Images 数据库，并写明 “No known copyright restrictions, released into the public domain”（无已知版权限制，已进入公有领域）。仓库 `docs/B0模型验证与复现.md` 第 25 行登记的是同一张 scikit-image v0.25.2 样例，写「NASA 来源和 public domain 状态」，未写出人物姓名；答辩图注采用 scikit-image 的完整表述，并保留 B0 的使用边界。图注固定写法示例：
  「样例：scikit-image `skimage.data.astronaut()`，NASA 照片，拍摄对象为宇航员 Eileen Collins；无已知版权限制，已进入公有领域。仅作本地非商业毕设演示，不作训练数据。**不暗示 NASA 或照片中人物认可本项目。** 此图不是 AgeDB 或其他课题数据集中的人脸。」
- 灰色剪影、几何头线框、或矩形框（填充 `#D0D5DE`，边框 1 pt `#8B96AC`，文字 `#1B2433`，约 10.58:1）仅用于**不展示该样例的位置**：作者证件照槽、无人脸/空镜、示意图中的抽象头像。不要用灰色块去替代已确认的 astronaut 输入图。
- 程序化演示头模（`demo-head.ts`）的界面截图，必须加 45° 斜线底纹或明显标签：「程序化演示头模，非照片重建，不是对容貌的预测」。不要把演示头模或 astronaut 说成真实用户照片。
- 只显示检测框、五点、网格线框或无纹理/中性材质的 canonical 网格时，仍可降低可识别性；若画面中出现 astronaut 原图，必须带上款署名。
- 其他成年人人像样例仍须另行取得明确授权，不得用课题数据集人脸替换 astronaut。

请把上述规则写在 PPT 母版的备注页（Notes）和海报图注中，避免组员从数据目录误贴图。

## 5. 能力边界（结果页必须遵守）

以仓库代码为准（与 MU-1 一致），答辩口头与幻灯片不得夸大。

**可以放在「结果」页的内容（须注明工程证据，G1 未签收）：**

- 本机静态路径：照片或拍照 → `POST /api/reconstruct` → YOLO5Face（`detector.py`）→ 3DDFA_V2 + BFM（`tddfa.py`）→ `static_mesh.py` canonical GLB（38,365 顶点、76,073 面）→ `GET /api/assets/{mesh_id}/mesh.glb` → `viewer.ts` 查看 → 前端本地导出 PNG / GLB。
- 凡结果页图注须写：「**真实模型证据来自研究链或离线验证，严格服务尚未验证**」（依据 `docs/验收矩阵.md` 第 46 行：研究链成立，严格服务 G1 未通过；`README.md` 第 79 行：真实 CPU 模型曾生成静态 GLB 并在独立本地资产预览服务中查看，**不验证严格服务的真实模型成功推理**）。
- 界面或网格**截图必须来自学生本人在本机的实际运行**，不得用他人截图、合成图、AI 生成图或从网络下载的效果图顶替。主工作台须按提交 `10f1918` 的桌面单屏拍摄（见 §6.4）：宽度 ≥1024px，一次纳入顶栏与三栏，不要用长滚动或窄屏布局作主图。
- 可选原照片 UV（`uv_texture.py`）只能标「原照片投影，不是年龄纹理」，且结果能力仍为 `age_morph=false`、`age_texture=false`。
- 失败恢复：`NO_FACE`、`MULTI_FACE`、`MODEL_NOT_READY` 等（人像用占位）。
- 演示头模只能作为「界面能力检查」，必须带斜线底纹与「非照片重建」标签，不能当作重建精度结果。

**不得放在「结果」页主槽，只能标「研究中」并放到方法图辅栏、总结「未完成」或备用页：**

- 生产年龄形变、`POST /api/aging`（固定 503 `MODEL_NOT_READY`）、`years_calibrated=false`、`static_fallback`。
- 年龄纹理 / SAM 研究链、研究会话页、重点帧 `NO_FACE` 一类研究观察。不得把研究纹理图当作「老化效果展示」。
- 正式训练指标、WIDER / AFLW / AgeDB 评测数字（正式三组为 0，评测未开始）。
- 实时链路可作为「方法：代码已接入，G2 未签收」出现，不得写成已通过的正式实时结果。

**不得在任何页写成「当前系统已采用」：** YOLO26n-face、MICA + FLAME、后端 `POST /api/export/gltf` 与 `/api/export/image`。这些只进「计划中」或「与任务书差异（待确认）」备用页。
